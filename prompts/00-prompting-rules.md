# 通用 Agent 提示词规则

每次任务都必须明确：角色、当前阶段、目标、输入文件准确路径、允许修改的文件、禁止事项、输出路径、通过标准和停止条件。

通用约束：
1. 先读取指定文档和实际代码，再下结论。
2. 区分事实、推断、建议和未知；引用具体路径、章节、函数、接口或 Spec ID。
3. 不得虚构文件、来源、命令执行结果、测试证据或外部资料。
4. 不得擅自扩大需求、改变已批准的技术决策或改动范围。
5. 发现文档冲突时暂停，不得自行选择一份作为真相。
6. 冲突解决后，修改对应权威源文件，并同步所有受影响文档；记录决策、原因、日期和影响。
7. 未经人工批准，不执行破坏性操作、生产操作、权限/数据策略变更或重大架构变更。
8. 输出必须写入指定文件，并汇报修改文件、验证结果、未解决问题和下一步。
9. 未执行的检查写 NOT RUN；环境阻塞写 BLOCKED。
10. 阶段通过必须满足 workflow 中的门禁，不能仅凭 Agent 自评宣布通过。
