## 1. 页面目标

- 首屏回答「这是什么地点、类型是什么、上级在哪、关联哪些人物与势力」。
- 关系双向可达：人物页 ↔ 地点页；地点页 ↔ 势力页。
- 编辑同页内联；关联人物的备注与关联势力的备注可编辑并保留。
- 删除有下级或被引用地点必须阻止并列出引用位置。
- 本版不做地点图片、地点不引用体系、不做地点大事记（需求未要求）。

## 4. 字段与展示规则

| 字段 | 必填 | 多值 | 展示 | 编辑 |
|---|---|---|---|---|
| 名称 | 是 | 否 | H1；同作品唯一；英文不区分大小写 | 文本输入 |
| 类型 | 否 | 否 | 文本；空「—」；自由输入 | 文本输入 + 已有值建议 |
| 上级 | 否 | 否 | 完整路径链接；顶层「顶层地点」 | TreeSelect（可搜索、可清空；禁用自身/后代） |
| 下级地点 | 系统 | 多 | 子节点链接 + 类型 + 人物/势力数 | 通过新建/移动维护 |
| 关联人物 | 否 | 多 | 头像 40px、姓名链接、境界、势力、备注 | 多选 CharacterSelect + 每项备注 |
| 关联势力 | 否 | 多 | 势力链接 + 备注 | 多选 FactionSelect + 每项备注 |
| 简介 | 否 | 否 | 正文保留换行 | Textarea |
| 待校对 | 系统 | 否 | Badge；确认后消失 | 确认按钮 |
| 创建/更新时间 | 系统 | 否 | 侧栏；`YYYY-MM-DD HH:mm` | 只读 |

- 关联人物备注可选；没有备注显示「—」；备注只属于该关系，不写到人物简介。
- 关联势力备注可选；双向展示：地点页显示人物/势力，势力页/人物页显示地点（FR-14/FR-35）。
- **本版不做地点图片**（FR-16）；不出现上传入口。
- **地点不引用体系**；不出现体系字段。
- **不做地点大事记**；需求未要求，避免擅自增加。

### 4.1 摘要条

| 指标 | 计算 |
|---|---|
| 下级地点 | 直接子节点数 |
| 关联人物 | 人物→地点关系数（去重） |
| 关联势力 | 地点→势力关系数（去重） |

- 数值等宽；无图表。
- 摘要条可点击滚动到对应区块（可选增强，不新增页面）。

### 4.2 关联人物表

- 列：缩略图、姓名（链接 PG-03）、境界、势力、备注。
- 每页 20；人数多时分页；排序按姓名。
- 空状态：「还没有关联人物」+「编辑关联」。
- 备注可空；编辑时使用「关系备注」输入，不修改人物本身。

### 4.3 关联势力列表

- 每行：势力名（链接 PG-05）、类型/上级（可选）、备注。
- 空状态：「还没有关联势力」+「编辑关联」。

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 编辑 | 主按钮（查看态） | 内联编辑：名称、上级、类型、简介、关联人物/备注、关联势力/备注 |
| 保存 | 主按钮（编辑态） | 校验 → 保存 → Toast「已保存」→ 查看态 |
| 取消 | 次按钮 | 有修改 → 确认放弃 |
| 确认已校对 | 次按钮 | 取消 Badge；同步 |
| 更多 → 删除地点 | 危险操作 | 引用检查 → 确认/阻断 |
| 下级/人物/势力链接 | 链接 | 跳转对应详情 |

- 每屏最多 1 个实心主按钮；删除收进「更多」。
- 不提供地点图片上传、地点大事记、体系引用入口。

## 6. 交互细节

### 6.1 查看态

1. 加载：标题/摘要/下级/关联人物/关联势力 Skeleton。
2. 首屏展示名称、类型、上级、摘要（FR-16）。
3. 点击人物/势力/下级 → 对应详情；关系双向可达。
4. 待校对确认：Badge 消失；失败保留。
5. 关联人物表分页；备注完整显示（过长 2 行 + Tooltip）。

### 6.2 内联编辑

1. 点击「编辑」→ 名称、上级、类型、简介、关联人物/势力变为控件。
2. 上级树选择：禁用自身/后代；清空 = 顶层；保存后树/人物/势力/检索同步。
3. 关联人物：多选（当前作品人物），每项可填备注；移除关系只删除关系，不删除人物。
4. 关联势力：多选（当前作品势力），每项可填备注；移除关系不删除势力。
5. 保存：名称唯一/上级合法/引用属于当前作品；成功 Toast；失败字段级错误。
6. 取消：有修改 → 确认放弃；无修改直接退出。
7. 并发冲突 → ConflictDialog；保留输入；不自动合并。
8. 未保存离开 → DirtyGuard。

### 6.3 删除

1. 「更多」→「删除地点」。
2. 引用检查：下级地点、人物→地点关系、地点→势力关系、导入校对记录。
3. 有引用 → ReferenceDialog 720px；按类型分组；每条可跳转；主操作禁用。
4. 无引用 → ConfirmDialog「删除地点「X」？」+「将进入回收站，可在 8 秒内撤销」。
5. 成功 → 返回 PG-06；Toast + 撤销。
6. 恢复时父级已删 → 阻止并提示「请先恢复上级地点」。
7. 失败 → Alert + 重试。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Loading | 标题/摘要/下级/关联 Skeleton |
| Empty（下级/关联人物/关联势力） | 分组空状态 + 编辑入口 |
| Success | Toast「已保存」/「已确认校对」/「已移入回收站」 |
| Error（加载） | 页面错误 + 重试/返回地点列表 |
| Error（保存） | 字段级错误；保留输入 |
| Conflict | ConflictDialog；保留输入 |
| Deleted/NotFound | 「内容不存在或已删除」+ 返回地点列表 |
| Disabled | 保存中禁用；被引用删除禁用 |
| Pending | Badge + 确认按钮 |
| Network | 顶部 Alert + 重试；未保存编辑保留 |

## 8. 校验与边界

- 名称必填、同作品唯一；英文大小写视为重复。
- 上级不能为自身/后代（EX-18）；上级属于当前作品。
- 关联人物/势力必须属于当前作品；重复选择去重；备注可选。
- 删除有下级或任一关联时阻止；引用位置可跳转。
- 恢复时父级缺失阻止。
- 本版无地点图片、无地点大事记、无体系字段（不得擅自增加）。
- 字段超长 → 字段级错误；上限由 P4 确认。
- 权限不足 N/A。

## 9. 响应式

| 宽度 | 布局 | 摘要条 | 关联人物表 |
|---|---|---|---|
| ≥1280 | 主栏 760 + 侧栏 320 | 3 列 | 全列 |
| 1024–1279 | 侧栏移到底部 | 3 列（可换行） | 横向滚动；备注可隐藏 |
| <1024 | 最小 1024，横向滚动 + 提示 | 3 列 | 横向滚动 |

- 关系备注不因窄屏丢失；允许横向滚动或换行。
- 不显示图片区域（本版无地点图片）。

## 10. 可访问性

- 标题 H1；区块 H2；摘要条使用标签 + 数值。
- 关联人物表 `scope="col"`；姓名链接键盘可达；备注有列头。
- 上级/下级/人物/势力链接完整；不使用纯图标跳转。
- 内联编辑字段有标签；错误 `aria-describedby`；保存/取消顺序固定。
- 待校对 Badge 有文字；确认按钮有明确名称。
- 加载 `aria-busy`；错误 `role="alert"`；对话框焦点陷阱。
- 对比度按 design-system §8。

## 11. 视觉与原型

- 以列表/表格表达关系；不使用地图或关系图谱。
- 摘要条 3 列；关联人物行 44px；下级地点行 36px；侧栏 320px。
- 原型未覆盖；视觉 Token 与 `#faction` 一致（标题、摘要条、关系分组、侧栏）。
