## 1. 页面目标

- 每本作品一套体系；类别由用户自定义（最多 10 类，含内置「境界」）。
- 内置「境界」自动创建、名称固定、必开、不可停用/删除；自定义类别可新增、改名、停用、删除。
- 类别类型「普通 / 纪元」创建后不可更改；纪元节点只排序，不做日期计算。
- 节点最多两级；同级可排序；节点改名同步到人物引用与检索。
- 停用/删除类别或删除节点前必须检查引用；有引用时阻止并列出数量与位置。
- 配置后人物表单立即生效；停用类别从表单隐藏但保留数据。

## 4. 字段与展示规则

### 4.1 类别列表

| 字段 | 规则 |
|---|---|
| 名称 | 同作品唯一；英文不区分大小写；内置「境界」固定置顶、不可改名 |
| 类型 | 「普通」或「纪元」；创建后不可更改；以 Badge 标识 |
| 状态 | 启用 / 已停用；内置不可停用 |
| 节点数 | 该类全部节点数（含子层级）；等宽数字 |
| 被引用数 | 引用该类节点的人物数（去重）；等宽数字 |
| 上限 | 最多 10 类（含内置）；达到 10 时「新增类别」禁用 + 原因 |
| 排序 | 内置置顶；其他按创建时间/名称稳定排序；不提供拖拽 |

### 4.2 类别操作

| 操作 | 规则 | 失败/边界 |
|---|---|---|
| 新增类别 | 名称必填/唯一；类型单选（普通/纪元）；创建后不可改类型 | 超过 10 类、重名、空名 → 阻止 |
| 改名 | 名称必填/唯一；改名后人物引用处、检索结果同步 | 重名/空名 → 阻止 |
| 停用 | 先查引用；无引用才可停用；停用后人物表单不显示、不可选；数据保留；可重新启用 | 有引用 → ReferenceDialog 阻止；内置不可停用 |
| 启用 | 已停用类别可重新启用；人物表单立即出现 | 无失败场景 |
| 删除 | 先查引用；无引用才可删除；弹窗说明其下 N 个节点一并删除；整组进回收站，可整组恢复 | 有引用 → ReferenceDialog 阻止；内置不可删除 |

- **内置「境界」**：自动创建、名称固定、必开、不可停用/删除；只能改名？需求明确「名称固定」，因此连改名也不可（PG10-Q1）。
- 停用/删除类别的引用检查包括：人物对该类别任一节点的引用；停用不删除数据。
- 删除类别时，类别与全部节点作为一组进入回收站；回收站显示为一条类别项，其下节点不单独列出。

### 4.3 节点树

| 字段 | 规则 |
|---|---|
| 层级 | 每类最多两级：主层级 + 子层级；子层级数量可配 |
| 名称 | 同一类别 + 同一父级下唯一；英文不区分大小写 |
| 排序 | 同级手动排序；上移/下移按钮；不拖拽 |
| 引用数 | 引用该节点的人物数；删除前必须为 0 |
| 纪元节点 | 类型为「纪元」时，可填起始/结束年份文本；只排序，不做日期计算、不校验年份 |
| 普通节点 | 名称 + 可选说明？需求只要求名称；不擅自增加说明字段（PG10-Q2） |
| 操作 | 新增主层级、新增子层级、改名、删除、上移/下移 |
| 删除 | 被引用 → 阻止 + 列出人物；无引用 → 确认 → 软删除 |
| 恢复 | 类别或父级缺失 → 阻止并提示先恢复（PG-12） |

### 4.4 人物表单联动

- 每个启用类别在人物表单/详情出现一个 0..1 节点选择；顺序按类别列表顺序，内置境界在前。
- 停用类别不显示；未启用类别不存在。
- 类别或节点改名后，人物详情、列表、检索结果同步。
- 删除节点/类别后，人物引用被阻止，因此正常入口不会产生悬空引用。

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 新增类别 | 主按钮 | CreateCategoryDialog（560px）：名称 + 类型 |
| 新增主层级 | 主按钮（右栏） | CreateNodeDialog：名称（+ 纪元起止文本） |
| 新增子层级 | 次操作（节点行菜单） | CreateNodeDialog，父级预填当前节点 |
| 改名类别/节点 | 次操作 | RenameDialog；唯一性校验 |
| 停用/启用类别 | 次操作（更多菜单） | 停用前引用检查；启用直接生效 |
| 删除类别/节点 | 危险操作（更多菜单） | 引用检查 → 确认 → 回收站 |
| 上移/下移 | 次操作 | 保存同级顺序；不改变引用 |

- 每屏最多 1 个实心主按钮：「新增类别」；右栏「新增主层级」用描边主按钮。
- 内置类别不显示停用/删除；改名也不显示。

## 6. 交互细节

### 6.1 新增类别

1. 点击「新增类别」→ Dialog：
   - 名称（必填；同作品唯一；英文大小写不敏感）
   - 类型 Radio：「普通」/「纪元」；说明「创建后不可更改」
2. 保存 → Toast「类别已创建」；类别列表刷新并选中；右栏空节点状态 +「新增主层级」。
3. 达到 10 类 → 主按钮禁用 + Tooltip「最多 10 类（含内置境界）」。
4. 取消：不创建。

### 6.2 类别改名

1. 右栏「改名」→ RenameCategoryDialog。
2. 校验唯一/非空；保存 → Toast；人物表单/检索同步。
3. 内置「境界」不显示改名入口（名称固定）。

### 6.3 停用类别

1. 类别更多菜单「停用」→ 先请求引用检查。
2. 有引用 → ReferenceDialog「无法停用：仍有 N 人引用该类别」+ 按人物列出位置 + 链接。
3. 无引用 → ConfirmDialog「停用类别「X」？停用后人物表单不再显示该字段，已有数据保留，可重新启用。」
4. 确认 → 状态「已停用」；Toast；人物表单立即隐藏。
5. 内置类别无停用入口；直接 API 调用由服务端拒绝。

### 6.4 删除类别

1. 更多菜单「删除」→ 引用检查。
2. 有引用 → ReferenceDialog 阻止。
3. 无引用 → ConfirmDialog「删除类别「X」及其下 N 个节点？整组进入回收站，可整组恢复。」
4. 确认 → 类别与节点从列表/表单/检索隐藏；Toast「已移入回收站」+ 撤销。
5. 回收站中显示为一条类别项；恢复时整组恢复；节点不单独列出。

### 6.5 节点操作

1. 新增主层级：Dialog 名称（+ 纪元起止文本，仅纪元类型）；保存后追加同级末尾。
2. 新增子层级：节点行菜单 → 父级预填；最多两级，子节点不能再新增下级（选项禁用 + 说明）。
3. 改名：Dialog；唯一性校验（同类别+同父级）；保存后同步。
4. 删除：引用检查；有引用 → ReferenceDialog 列出人物；无引用 → ConfirmDialog「删除节点「X」？进入回收站，可撤销。」
5. 上移/下移：即时保存；Toast「已调整顺序」；不改变引用。
6. 纪元节点：起止年份文本可空；不做日期计算、不校验格式；排序只按手动顺序。

### 6.6 空状态

- 某类别无节点：右栏「还没有节点」+「新增主层级」+「从固定模板导入」。
- 无自定义类别：仅显示内置「境界」；「新增类别」仍可用。
- 类别停用：右栏显示「该类别已停用」+ 启用按钮；节点仍可查看（只读）？建议可查看，不参与表单；本设计允许查看与启用，不允许新增节点。见 PG10-Q3。
- 加载/错误：左栏类别 Skeleton；右栏节点 Skeleton；错误 + 重试。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Loading | 类别列表 + 节点树 Skeleton |
| Empty（类别无节点） | 右栏空状态 + 新增主层级 |
| Empty（无自定义类别） | 仅内置境界；新增类别可用 |
| Success | Toast「已创建/已保存/已停用/已启用/已移入回收站/已调整顺序」 |
| Error（加载） | 页面错误 + 重试 |
| Error（保存） | Dialog 字段级错误；保留输入 |
| Disabled | 10/10 新增禁用；内置停用/删除隐藏；有引用删除禁用；停用类别新增节点禁用 |
| Pending | 人物引用待校对不直接影响本页；节点本身无待校对（导入后人物待校对） |
| Network | 顶部 Alert + 重试；保留输入 |

## 8. 校验与边界

- 类别名称同作品唯一；英文不区分大小写；空名阻止。
- 最多 10 类（含内置）；超过阻止。
- 类别类型创建后不可改；不提供类型编辑入口。
- 节点名称同类别+同父级唯一；空名阻止；最多两级。
- 停用/删除类别或删除节点前必须引用检查；有引用阻止（EX-14/EX-16）。
- 删除类别必须弹窗说明节点一并删除；整组进回收站（FR-21/AC-13）。
- 恢复节点时类别/父级缺失阻止（EX-15）。
- 内置「境界」不可停用/删除/改名；服务端兜底。
- 停用类别后人物表单不显示；数据保留；不可引用。
- 字段长度上限由 P4 数据模型定义；UI 字段级错误。
- 权限不足 N/A。

## 9. 响应式

| 宽度 | 左栏 | 右栏 | 节点行 |
|---|---|---|---|
| ≥1280 | 280px | 剩余宽度 | 名称 + 引用 + 排序 + 菜单 |
| 1024–1279 | 240px | 剩余宽度，横向滚动 | 引用/排序可收进菜单 |
| <1024 | 240px | 最小 1024，横向滚动 + 提示 | 同 1024 |

- 左右栏不上下堆叠（保持类别与节点的上下文）；窄屏允许横向滚动。
- 类别列表不改为下拉选择。

## 10. 可访问性

- 类别列表使用 `listbox`/按钮组；当前类别 `aria-selected="true"`。
- 节点树使用 `role="tree"`/`treeitem` + `aria-expanded`；Tab 可达；Enter 打开菜单或重命名。
- 上移/下移按钮有 `aria-label="上移节点：帝境"`；禁用时说明首/末位置。
- 类型 Badge 有文字；状态不只靠颜色。
- Dialog 焦点陷阱；引用列表链接可键盘访问。
- 加载 `aria-busy`；错误 `role="alert"`；Toast `aria-live`。
- 对比度按 design-system §8。

## 11. 视觉与原型

- 原型 `#system`：展示内置境界、自定义类别、停用类别、节点树、引用数、上移/下移、空类别节点。
- 视觉基线：左栏 280px；类别项 64px；节点行 36px；引用数右对齐等宽；内置 Badge 中性色。
- 不使用图形化体系树/关系图；不使用图标替代类型文字。

## 12. 验收标准

- [ ] 内置「境界」自动存在、名称固定、必开、不可停用/删除/改名。
- [ ] 新增自定义类别，类型普通/纪元创建后不可改；最多 10 类；重名阻止。
- [ ] 新增类别后人物表单立即出现对应字段；停用后隐藏且数据保留。
- [ ] 建立两级节点；同级可上移/下移；名称同父唯一。
- [ ] 类别/节点改名后人物详情、列表、检索同步。
- [ ] 停用/删除被引用类别被阻止并列出引用；删除类别整组进回收站并可整组恢复。
- [ ] 删除被引用节点被阻止；无引用删除可撤销。
- [ ] 纪元节点可填起止文本，只排序不计算。
- [ ] 加载/空/错误/10 类上限/停用状态完整；无英文堆栈。
