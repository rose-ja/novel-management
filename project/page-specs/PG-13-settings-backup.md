## 1. 页面目标

- 提供一键导出全量数据 zip；可选是否包含回收站数据（默认包含）。
- 展示最近 3 份自动快照的时间、大小、路径、来源动作、状态。
- 提供 CLI 恢复命令模板与注意事项；本版不在页面内上传恢复。
- 显示版本、数据目录、最近导出/恢复时间；不重复提供危险删除/清空入口（FR-58/需求「危险操作不在设置页重复提供入口」）。
- 导出失败不提供残缺 zip；恢复失败不覆盖现有数据。

## 4. 字段与展示规则

### 4.1 导出

| 字段 | 规则 |
|---|---|
| 导出范围 | 全部作品、图片、关系、体系、榜单、大事记；不包含快照文件 |
| 回收站 | Checkbox「包含回收站数据」，默认勾选；导出包可含/不含 |
| 文件名 | 含日期时间，例 `novel-settings-20261107-1432.zip`；展示可复制 |
| 大小 | 1 位小数 + 单位；完成后显示 |
| 生成时间 | `YYYY-MM-DD HH:mm` |
| 操作 | 「下载 zip」+「复制文件路径」；路径中间省略，Tooltip 全路径 |
| 失败 | Alert 说明原因（磁盘不足/权限/中断）+ 重试；不提供残缺 zip |
| 重复点击 | 生成中按钮禁用 + loading；不可重复生成 |
| 成功 | 卡片展示文件信息；Toast「导出包已生成」；不自动下载（用户点击） |

### 4.2 快照

| 字段 | 规则 |
|---|---|
| 时间 | `YYYY-MM-DD HH:mm` |
| 大小 | 1 位小数 + 单位 |
| 来源动作 | 恢复 / 导入 / 删除作品 / 清空回收站 / 永久删除 |
| 状态 | 成功 / 失败；失败也可显示，便于排查 |
| 路径 | 等宽；中间省略；点击复制；不提供下载（Should 未纳入） |
| 保留 | 最近 3 份；自动清理旧快照；不做手动删除 |
| 空状态 | 「还没有快照」+ 说明「恢复、导入、删除作品、清空回收站前会自动创建」 |
| 页面内操作 | 只读列表；不提供手动创建/下载（Should） |

### 4.3 CLI 恢复

| 字段 | 规则 |
|---|---|
| 命令模板 | `./scripts/restore.sh /path/to/<export>.zip`；按实际脚本路径/参数调整（P4 定义） |
| 复制 | 一键复制命令；Toast「已复制」 |
| 说明 | 恢复前校验版本与完整性；自动快照；失败不覆盖现有数据 |
| 注意事项 | 1) 确认版本兼容；2) 保留快照；3) 恢复后 Smoke Test（启动、切换作品、检索、详情、图片） |
| 页面内恢复 | 不做上传/执行；只提供命令说明 |

### 4.4 系统信息

| 字段 | 规则 |
|---|---|
| 版本 | `v1.0.0` 或构建号；等宽 |
| 数据目录 | 路径；中间省略 + 复制；不暴露敏感完整路径？本地单用户可显示；按需求「数据目录」可显示 |
| 最近导出 | `YYYY-MM-DD HH:mm` 或「—」 |
| 最近恢复 | `YYYY-MM-DD HH:mm` 或「—」 |
| 服务监听 | 显示 `127.0.0.1`；不显示公网地址/端口调试信息 |

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 导出全量数据 | 主按钮 | 打开 ExportDialog；选择是否包含回收站 → 生成 |
| 生成导出包 | 主按钮（Dialog） | 提交 → 进度 → 成功卡片 |
| 下载 zip | 次按钮（成功卡片） | 浏览器下载；失败提示 |
| 复制路径 | 图标/文字按钮 | 复制到剪贴板；Toast |
| 复制恢复命令 | 图标/文字按钮 | 复制；Toast |
| 查看快照 | 只读 | 不提供下载/删除 |
| 危险操作 | 不在本页 | 回收站/作品菜单处理 |

- 每屏最多 1 个实心主按钮：「导出全量数据」。
- 导出生成中禁用重复提交；Dialog 可关闭但任务继续？建议关闭仅隐藏进度，任务继续并 Toast；或禁止关闭直到完成（PG13-Q1）。

## 6. 交互细节

### 6.1 导出流程

1. 点击「导出全量数据」→ ExportDialog（560px）：
   - 说明导出范围；
   - Checkbox「包含回收站数据」（默认勾选）；
   - 主按钮「生成导出包」；次按钮「取消」。
2. 确认 → Dialog 转为进度：收集数据 → 打包图片 → 生成清单；显示阶段 + 进度。
3. 成功 → 结果卡片（文件名、大小、时间）：「下载 zip」「复制文件路径」；Toast。
4. 失败 → Dialog/页面 Alert 显示原因 + 重试；不提供残缺 zip；可重新生成。
5. 取消 → 关闭；不生成。
6. 重复点击 → 禁用；服务端去重/幂等。

### 6.2 快照

1. 页面加载 → 快照列表 Skeleton → 表格；无快照空状态。
2. 路径复制 → Toast；不打开文件管理器（浏览器无法可靠做到）。
3. 快照失败 → 行内状态「失败」+ Tooltip 原因；不提供重试（手动触发不允许）。
4. 快照保留最近 3 份；旧快照自动清理，页面不提供删除。

### 6.3 CLI 恢复

1. 复制命令 → 在终端执行；页面不轮询状态。
2. 恢复失败 → 用户按 CLI 输出处理；页面「最近恢复」可能不变；不显示堆栈。
3. 恢复后刷新页面 → 系统信息更新；数据完整。
4. 本版不做页面内恢复，避免误操作与权限问题。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Empty（无快照） | 快照空状态 + 说明 |
| Loading（快照列表） | 3 行 Skeleton |
| Loading（导出） | 进度条 + 阶段文字；按钮禁用 |
| Error（导出） | Alert + 重试；不提供残缺 zip |
| Success（导出） | 文件卡片 + 下载/复制 |
| Disabled | 无作品时导出禁用 + 原因；生成中禁用 |
| Network | 顶部 Alert + 重试；不进入离线模式 |
| Snapshot failure | 行状态失败；Tooltip 原因 |

- 无作品时可导出？没有数据可导出 → 禁用 + 原因「暂无作品数据」。
- 快照路径可能较长；表格中间省略，复制/ Tooltip 显示全路径。

## 8. 校验与边界

- 导出范围固定全量；不提供按作品/按类型导出（需求未要求）。
- 回收站 Checkbox 默认勾选；两种导出包都必须可恢复（AC-12）。
- 导出文件名含日期时间；不含空格/特殊字符；重复生成不覆盖旧文件（由实现命名策略保证）。
- 恢复不通过页面执行；CLI 校验版本/完整性/磁盘；失败不覆盖现有数据（EX-24）。
- 快照失败阻止破坏性操作（EX-23）；本页只展示状态。
- 不提供手动创建/下载快照（Should 未纳入基线）。
- 不显示敏感信息/堆栈；本地路径可显示但不可注入。
- 权限不足 N/A；本版无用户/权限。

## 9. 响应式

| 宽度 | 内容 | 快照表 | 命令块 |
|---|---|---|---|
| ≥1280 | 最大 960px | 全列 | 单行，横向滚动 |
| 1024–1279 | 全宽 - 40px | 横向滚动 | 横向滚动 |
| <1024 | 最小 1024，横向滚动 + 提示 | 横向滚动 | 横向滚动 |

- 命令块允许多行换行；不截断命令。
- 路径列可省略中间，但复制按钮始终可见。

## 10. 可访问性

- 导出 Checkbox 有可见标签与说明；Dialog 标题明确「导出全量数据」。
- 进度 `role="progressbar"` + `aria-valuetext` 阶段；完成后 `aria-live` 播报。
- 复制按钮有 `aria-label="复制快照路径"` / `"复制恢复命令"`；Toast 反馈。
- 快照表 `scope="col"`；失败状态有文字，不只靠颜色。
- 命令块 `pre/code`，可选中复制；提供显式复制按钮。
- 加载 `aria-busy`；错误 `role="alert"`。
- 对比度按 design-system §8。

## 11. 视觉与原型

- 页面为设置型长页，区块清晰、留白适中；不使用卡片堆叠。
- 快照表 44px 行高；路径等宽；命令块浅灰底 + 1px 边框。
- 危险操作不在本页；不显示红色大面积按钮。
- 原型未覆盖；Token 与 `#system`/`#trash` 一致。

## 12. 验收标准

- [ ] 一键导出全量 zip；弹窗询问是否包含回收站，默认包含。
- [ ] 导出包文件名含日期时间；完成后提示下载/路径；失败不提供残缺 zip。
- [ ] 含/不含回收站两种导出包均可在空环境恢复（与 AC-12 联动）。
- [ ] 快照列表显示最近 3 份的时间、大小、路径、来源、状态；路径可复制。
- [ ] 页面提供 CLI 恢复命令与注意事项；不提供页面上传恢复。
- [ ] 快照失败/导出失败/网络中断有中文提示与下一步。
- [ ] 无作品时导出禁用 + 原因；生成中不可重复提交。
- [ ] 页面不重复提供删除/清空回收站入口。
- [ ] 系统信息显示版本、数据目录、最近导出/恢复时间。
- [ ] 加载/空/错误状态完整；无英文堆栈、无占位文本。
