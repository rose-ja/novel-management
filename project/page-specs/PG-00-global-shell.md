## 1. 页面目标

- 让用户始终知道「当前在哪本作品、在哪个页面」。
- 提供唯一的一套侧栏导航与作品切换入口，避免页面内重复导航。
- 统一处理作品创建/编辑/删除、未保存离开、引用阻断、并发冲突、网络错误与 Toast。
- 不增加仪表盘、通知中心、帮助中心、调试入口或用户/权限入口。

### 2.1 顶栏

- 固定 64px；底部 1px `--color-border-subtle` + 2px `--gradient-mist`。
- 左：Logo 28px + 产品全名「小说设定管理系统」14px/600；不可点击跳转首页（避免与默认检索冲突）。
- 中左：作品切换器，36px 高，最大 320px；显示当前作品名，超出省略。
- 右：「本机 · 127.0.0.1」状态胶囊；仅展示，不可点击；不使用通知/帮助/设置图标。
- 无登录头像、无通知徽标、无全局新建按钮。

### 2.2 侧栏

- 固定 232px（1024–1279 为 208px）；背景 `--color-bg-subtle`；右侧 1px 描边。
- 分组：
  - 资料：检索、人物、势力、地点、榜单、体系。
  - 工具：导入、回收站、设置/备份。
- 导航项 40px；图标 18px + 文字 14px；选中项浅绿底 + 左侧 3px 主色条 + 深绿文字。
- 当前页 `aria-current="page"`；不在当前作品的页面仍可达（回收站/设置）。
- 无二级折叠菜单；详情页用面包屑返回。
- 底部：版本号 12px tertiary + 「数据仅存本机」12px；不提供调试入口。

### 2.3 内容区

- 由各页面渲染；壳层只负责滚动区域与最大宽度。
- 主内容区独立滚动；顶栏/侧栏固定；不出现双滚动条。
- 页面横向内边距按断点：32/24/20px；内容最大 1200px。

## 4. 内容字段与展示规则

### 4.1 作品切换器

| 字段 | 展示规则 |
|---|---|
| 当前作品名 | 触发按钮内，14px/500；最长 20 个中文字符，超出 `…`；Tooltip 显示全名 |
| 作品列表 | 菜单宽 320px；每项显示作品名 + 简介首行（可选）；当前项勾选 + 浅绿底 |
| 作品数量 | ≤10 本；≥8 本时显示搜索框（Should，未纳入 Must 验收） |
| 操作 | 每项 hover 显示「编辑」「删除」IconButton；菜单底部「新建作品」 |
| 排序 | 最近使用优先（Should）；默认按创建时间倒序 |
| 空状态 | 菜单内显示「还没有作品」+「新建作品」 |
| 本机状态 | 顶栏右侧胶囊，绿点 + 「本机 · 127.0.0.1」；不展示完整路径 |

### 4.2 作品表单

| 字段 | 规则 |
|---|---|
| 作品名称 | 必填；去首尾空格；全局唯一；英文不区分大小写；1–100 字符（上限由 P4 数据模型最终确认） |
| 简介 | 可选；纯文本；保留换行；最多 2,000 字符（软提示，不硬截断） |
| 创建后 | 自动生成内置「境界」类别；进入 PG-10 并显示一次性提示 |
| 编辑后 | 顶栏、页面副标题、导出清单同步；不改作品 ID |
| 删除 | 输入完整作品名称确认；自动快照；整本进回收站；可撤销 |

## 5. 主操作 / 次操作

| 位置 | 操作 | 类型 | 结果 |
|---|---|---|---|
| 作品菜单底部 | 新建作品 | 主操作（菜单级） | 打开 WorkCreateDialog |
| 作品项 hover | 编辑 | 次操作 | 打开 WorkEditDialog |
| 作品项 hover | 删除 | 危险次操作 | DeleteWorkDialog（输入名称 + 快照） |
| 顶栏 | 本机状态 | 静态 | 无点击行为 |
| 侧栏 | 导航 | 导航 | 切换页面；有未保存修改时拦截 |

- 不在顶栏放「新建人物」「导入」等页面级主操作；这些入口属于对应页面。
- 删除当前作品后：自动切换到另一本；无其他作品则进入无作品空状态。

## 6. 交互细节

### 6.1 切换作品

1. 点击作品切换器 → 菜单打开，焦点进入当前项。
2. 选择其他作品：
   - 无未保存修改 → 立即切换；Toast「已切换到《X》」；当前页面数据刷新；检索关键词保留但结果重新请求。
   - 有未保存修改 → DirtyGuardDialog「放弃未保存的修改？」→ 放弃并切换 / 继续编辑。
3. 点击外部或 Esc → 关闭；焦点回到触发按钮。
4. 作品列表加载失败 → 菜单内 Alert「作品列表加载失败」+ 重试；不把缓存数据当作当前作品。

### 6.2 删除作品

1. DeleteWorkDialog 宽度 560px。
2. 标题「删除作品《X》？」；说明「将整本作品及其全部内容移入回收站；删除前会自动创建快照。」
3. 输入框标签「输入作品名称以确认」；输入不匹配时主按钮禁用。
4. 主按钮「删除作品」danger；次按钮「取消」。
5. 提交中：按钮 loading、输入禁用、不可 Esc 关闭。
6. 成功：Toast「已移入回收站」+「撤销」8s；当前作品处理见 5。
7. 快照失败：Dialog 内 Alert「快照创建失败，未执行删除」+ 重试；作品保留。

### 6.3 无作品状态

- 检索页（PG-01）显示页面级空状态：标题「先创建一本作品」；说明；主操作「新建作品」。
- 侧栏内容页（人物/势力/地点/榜单/体系/导入）显示「请先新建作品」+「新建作品」；不显示空白表格。
- 回收站可访问（空状态）；设置/备份可访问（导出按钮禁用 + 原因「暂无作品数据」）。
- 不隐藏侧栏、不改变导航结构。

### 6.4 未保存离开（DirtyGuard）

- 触发：详情内联编辑、体系节点编辑、导入向导进行中。
- 拦截动作：侧栏跳转、切换作品、返回列表、关闭 Drawer、打开其他实体。
- 文案：「放弃未保存的修改？」；说明「离开后本次修改不会保留。」
- 按钮：「继续编辑」（主）/「放弃并离开」（danger 文字）。
- 选择放弃 → 恢复原值；选择继续 → 留在当前页。
- 本版无自动保存/草稿恢复；进程中断后仅已保存数据保留。

### 6.5 并发冲突

- 保存时 `updated_at` 不一致 → ConflictDialog（560px）。
- 文案：「数据已被其他页面修改」；说明「为避免覆盖，请刷新后重新编辑。你的输入已暂存在当前页面。」
- 按钮：「刷新并重试」（主）/「取消」。
- 不自动合并、不静默覆盖；刷新后保留用户输入直到再次保存或离开。

### 6.6 引用阻断

- 删除/停用/缩容前引用检查失败 → ReferenceDialog（720px）。
- 标题「无法删除/停用/缩容：仍被引用」；按类型分组列出引用；每条可跳转。
- 主操作禁用；只提供「关闭」；跳转前若有未保存修改先 DirtyGuard。
- 不显示内部 ID；引用数量与位置必须可定位。

### 6.7 网络中断

- 任一请求失败且服务不可达 → 页面顶部 Alert（danger）：「无法连接本地服务，请确认 Docker 容器正在运行」+「重试」。
- 内容区保留已有数据或显示错误状态；输入与未保存编辑保留。
- 不进入离线模式；不自动轮询重试；用户手动重试。

### 6.8 Toast

- 底部居中；成功 4s；错误 6s；撤销 8s；hover/focus 暂停。
- 同时最多 3 条；撤销 Toast 同时最多 1 条。
- 不把字段错误放进 Toast。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Empty（无作品） | 检索页空状态；内容页「请先新建作品」；回收站空状态；设置导出禁用 |
| Loading（作品列表） | 菜单内 3 行 Skeleton；顶栏保持当前作品名 |
| Error（作品列表） | 菜单内错误 + 重试；顶栏保留上次已知名称 |
| Success（切换） | Toast + 页面刷新；不跳转无关页面 |
| Disabled | 删除确认未输入名称时禁用；无作品时导出禁用 |
| Network | 顶部 Alert + 重试；不阻塞导航（回收站/设置可继续） |

## 8. 校验与边界

- 作品名称：空、重复、超长、仅空格 → 字段级错误；英文大小写视为重复。
- 删除确认：必须输入完整作品名称；粘贴带首尾空格时自动 trim 后比较。
- 作品切换：不保留另一作品的检索结果；不跨作品引用。
- 页面/实体不存在：显示「内容不存在或已删除」+「返回检索」；不显示堆栈。
- 权限不足：N/A（单用户、无登录）。
- `<1024px`：显示非阻断提示「本系统按桌面端设计，建议使用 1024px 以上窗口」；布局保持最小 1024px，允许横向滚动；不新增移动导航。

## 10. 可访问性

- Skip Link 首个 Tab 可聚焦，跳至 `main`。
- 作品切换器是 `button` + `aria-haspopup="menu"` + `aria-expanded`；菜单项可用 ↑↓/Enter/Esc。
- 当前导航项 `aria-current="page"`；图标按钮有 `aria-label`。
- Dialog：`role="dialog" aria-modal="true"` + 标题；焦点陷阱；关闭后恢复触发点。
- 删除确认的输入与主按钮禁用关系可被屏幕阅读器理解（`aria-describedby` 说明）。
- Toast `aria-live="polite"`；错误 `assertive`。
- 本机状态胶囊不是交互控件，不使用 button。
- 焦点环 2px；对比度按 design-system §8。

## 12. 验收标准

- [ ] 任何页面都能看到当前作品名，并能打开作品切换器。
- [ ] 切换作品后数据完全隔离；检索不返回其他作品。
- [ ] 新建作品后自动进入体系页，并提示内置「境界」已创建。
- [ ] 删除作品必须输入名称确认，且快照失败时阻止删除。
- [ ] 有未保存修改时，切换作品/离开页面被拦截，可选择放弃或继续。
- [ ] 引用阻断、并发冲突、网络中断均有中文提示与下一步。
- [ ] 无作品时检索页有新建入口；内容页不出现空白表格。
- [ ] 无占位文本、无调试入口、无未完成按钮。
- [ ] 1024/1280/1440 三档布局正确；<1024 出现提示且无移动导航。
