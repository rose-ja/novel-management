## 1. 页面目标

- 用单棵树呈现「万族 → 族 → 分支」的势力层级，默认展开两级。
- 支持按节点名称搜索并定位，自动展开祖先；不隐藏层级。
- 新建节点使用页内内联表单（遵循 FR-09「新建/编辑使用内联表单」），不新增独立编辑页。
- 列表一眼看出节点名称、首领、直属成员数、下级分支数、待校对状态。
- 支持 1000 节点规模；树加载与搜索定位不阻塞页面。

## 4. 字段与展示规则

| 字段 | 展示规则 | 数据来源 |
|---|---|---|
| 节点名称 | 14px/500；链接到 PG-05（`/factions?id=<id>`）；命中搜索词高亮 | 势力 |
| 展开/收起 | 有下级时显示箭头；无下级占位；默认展开两级 | 树结构 |
| 首领 | 显示人物名（链接 PG-03，`/characters?id=<id>`）；空显示「—」 | 势力→人物 |
| 直属成员 | 该节点直接归属人物数；等宽数字 | 人物归属 |
| 下级分支 | 直接子节点数；等宽数字 | 势力树 |
| 待校对 | Badge「待校对」；`review_status=pending` 时显示，确认后刷新 `review_status`/`reviewed_at` 并消失 | 势力 DTO |
| 上级路径 | 搜索命中时可在行内显示路径（可选，避免拥挤） | 势力树 |
| 新建上级 | 树选择；可空（顶层）；禁止选择自身/后代（新建时无自身） | 势力树 |

**搜索与定位**：

- 输入节点名称，300ms debounce；匹配节点高亮并自动展开祖先。
- 无匹配显示「没有匹配的势力节点」+ 清除搜索。
- 搜索不改变树结构，不打开详情；点击节点才进入 PG-05（`/factions?id=<id>`）。
- 「待校对」筛选请求参数 `review_status=pending`；节点 DTO 返回 `review_status`、`reviewed_at`。
- 「展开全部/收起全部」只影响当前树展示，不改变默认展开级别。

**排序**：

- 树按同级 `sort_order` / 名称稳定排序；本页不提供排序控件。
- 新建节点默认追加到同级末尾；移动父级在 PG-05 编辑中完成。

**分页**：树不分页；节点总数显示在页头；1000 节点用虚拟滚动/懒展开（实现层决定，UI 保持流畅）。

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 新建势力节点 | 主按钮 | 展开内联新建面板；焦点进入「上级」或「名称」 |
| 保存节点 | 主按钮（面板） | 校验 → 保存 → 树刷新并选中新节点；Toast「势力节点已创建」 |
| 取消 | 次按钮 | 有输入 → 确认放弃；无输入直接收起 |
| 节点名称 | 链接 | 进入 PG-05（`/factions?id=<id>`） |
| 展开/收起 | 次操作 | 展开/收起子树 |
| 搜索/待校对/重置 | 次操作 | 过滤/定位；不改变数据 |

- 新建后是否进入详情：建议保存后停留树并选中节点（PG04-Q1）；用户可点击进入详情。
- 行内不提供编辑/删除；这些操作在详情页完成，避免树内误触。

## 6. 交互细节

1. 新建：点击主按钮 → 面板展开；上级选择默认空（顶层），也可在详情页「新建下级」预填父级（如实现，不新增页面）。
2. 名称校验：必填、同作品唯一、英文不区分大小写；保存中禁用；错误贴近字段。
3. 取消：面板内有输入 → Dialog「放弃未保存的修改？」；无输入直接收起。
4. 保存成功：Toast；树刷新；自动展开父级并选中新节点；滚动到可见。
5. 树点击：整行可点击；展开按钮点击不触发进入详情（阻止冒泡）。
6. 搜索：命中节点高亮；若目标在折叠分支内，自动展开祖先；滚动到第一个命中。
7. 加载：树 8 行 Skeleton；搜索框可用。
8. 空树：显示「还没有势力节点」+「新建第一个节点」+「从固定模板导入」。
9. 切换作品：清空树与搜索；重新加载；无作品显示 PG-00 无作品状态。
10. 从详情返回：保留展开状态、搜索、滚动位置。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Empty（无节点） | 树区域空状态 + 新建/导入 |
| Empty（搜索无结果） | 「没有匹配的势力节点」+ 清除搜索 |
| Loading | 树 8 行 Skeleton；按钮可用 |
| Error | 树区域错误 + 重试；保留搜索 |
| Success | 树 + 计数；新建后选中节点 |
| Editing（内联新建） | 面板展开；树仍可见；底部保存/取消 |
| Disabled | 保存中禁用；被引用删除不在此页出现 |
| Network | 顶部 Alert + 树错误；不进入离线模式 |

## 8. 校验与边界

- 名称必填、同作品唯一；英文大小写视为重复（FR-48）。
- 上级必须属于当前作品；新建可为空；不能选择自身/后代（新建时无自身，编辑在 PG-05）。
- 删除只在 PG-05；有下级节点或人物归属成员时阻止；首领人物、地点关联不阻止，随势力删除隐藏或自动解除；导入校对状态不是引用关系，不参与删除判定。
- 移动成环：在 PG-05 编辑上级时禁用自身/后代选项（EX-18）。
- 空树不显示空白表格；无权限 N/A。
- 1000 节点下树流畅；不因展开全部卡死（实现可用虚拟滚动/懒展开）。
- 不显示内部 ID/堆栈。

## 9. 响应式

| 宽度 | 树 | 行内容 | 新建面板 |
|---|---|---|---|
| ≥1280 | 全宽（最大 1200） | 名称 + 首领 + 计数全显示 | 两列（上级/名称）+ 简介整行 |
| 1024–1279 | 全宽，横向 20px | 首领/计数可缩略；Tooltip | 单列 |
| <1024 | 最小 1024，横向滚动 + 提示 | 同 1024 | 单列 |

- 深层层级通过缩进表达；过深时允许横向滚动，不折叠成面包屑路径（避免丢失层级）。
- 树行不改为卡片。

## 10. 可访问性

- 树使用 `role="tree"` / `role="treeitem"`，`aria-expanded`；或使用嵌套列表 + 展开按钮（二选一，实现统一）。
- Tab 可达每个节点与展开按钮；Enter 打开详情；空格切换展开。
- 搜索高亮使用 `<mark>`；不只靠颜色。
- 新建立即校验错误通过 `aria-describedby` 关联。
- 计数列有表头/标签；不使用纯图标表达数量。
- 加载 `aria-busy`；错误 `role="alert"`。
- 对比度按 design-system §8。

## 11. 视觉与原型

- 树是页面主体；表头/工具栏简洁；不使用连接线装饰，靠缩进与展开箭头表达层级。
- 默认展开两级；选中/命中行浅绿；待校对 Warning Badge。
- 新建面板白底 + 1px 边框 + 12px 圆角，不使用大抽屉（遵循内联表单）。
