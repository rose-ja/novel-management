## 1. 页面目标

- 首屏回答「这是什么势力、上级是谁、首领是谁、有多少成员」。
- 清楚展示下级分支、成员（仅直属/含下级）、关联地点、简介与势力大事记。
- 首领与成员来自引用自动推导，不在势力内复制人物文本。
- 编辑同页内联；上级变更即移动节点，必须禁止移动到自身/后代。
- 删除被引用势力必须阻止并列出引用位置。

## 4. 字段与展示规则

| 字段 | 必填 | 多值 | 展示 | 编辑 |
|---|---|---|---|---|
| 名称 | 是 | 否 | H1 24px；同作品唯一；英文不区分大小写 | 文本输入 |
| 上级 | 否 | 否 | 完整路径链接（`/factions?id=<id>`）；顶层显示「顶层势力」 | TreeSelect（可搜索、可清空；禁用自身/后代） |
| 首领 | 否 | 0..1 | 人物名链接（`/characters?id=<id>`）；空显示「—」 | CharacterSelect（当前作品；可清空） |
| 成员 | 系统推导 | 多 | 人物归属自动出现；不在势力内手工编辑 | 只读；通过人物编辑换势力 |
| 下级分支 | 系统 | 多 | 直属子节点链接（`/factions?id=<id>`）+ 首领 + 计数 | 通过新建/移动节点维护 |
| 关联地点 | 否 | 多 | 地点链接（`/locations?id=<id>`）+ 备注；双向展示 | 多选 TreeSelect + 备注 |
| 简介 | 否 | 否 | 正文保留换行 | Textarea |
| 势力大事记 | 否 | 多 | 时间线；时间标签 + 内容 | 添加/编辑/删除 |
| 待校对 | 系统 | 否 | Badge；`review_status=pending` 时显示，确认后刷新 `review_status=confirmed` / `reviewed_at` 并消失 | 确认按钮，调用 `POST /factions/{id}/review` |
| 创建/更新时间 | 系统 | 否 | 侧栏；`YYYY-MM-DD HH:mm` | 只读 |

- **势力不引用体系**（FR-24）；表单不得出现境界/星命/圣体等体系字段。
- 名称改名后，人物详情、地点关系、检索结果自动同步。
- 成员表不展示简介/大事记，避免页面过长。

### 4.1 摘要条

| 指标 | 计算 | 空值 |
|---|---|---|
| 首领 | 0..1 人物 | 「未设置」+ 编辑入口 |
| 直属成员 | 直接归属该节点的人物数 | `0` |
| 含下级成员 | 整棵子树人物数（去重） | `0` |
| 下级分支 | 直接子节点数 | `0` |

- 数值使用等宽数字；点击成员数切换成员区筛选（可选增强，不新增页面）。
- 摘要条不是仪表盘，不使用图表。

### 4.2 成员区

- 默认「仅直属」；切换「含下级」后显示整棵子树，每行显示所属分支路径。
- 列：缩略图 40px、姓名（链接 `/characters?id=<id>`）、境界、势力路径（含下级时）、所在榜单（最多 1 条，其余 `+N`）。
- 空状态：直属为空 → 「暂无直属成员」+「去人物列表添加」；含下级为空 → 「暂无下级成员」。
- 成员来自人物归属，不在此处直接添加/移除；避免复制关系。
- 分页：每页 20；含下级人数多时保持分页。

### 4.3 势力大事记

- 字段与交互同人物大事记：时间标签自由文本、内容必填、手动排序、添加/编辑/删除。
- 删除使用行内轻确认 + Toast 撤销（PG03-Q1 同一模式）。
- 空状态：「还没有势力大事记」+「添加第一条」。

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 编辑 | 主按钮（查看态） | 内联编辑：名称、上级、首领、简介 |
| 保存 | 主按钮（编辑态） | 校验 → 保存 → Toast「已保存」→ 查看态 |
| 取消 | 次按钮 | 有修改 → 确认放弃 |
| 确认已校对 | 次按钮 | 调用 `POST /factions/{id}/review`；成功后刷新 `review_status`/`reviewed_at`，取消 Badge；同步列表/检索 |
| 添加大事记 | 次按钮 | 行内新增 |
| 更多 → 删除势力 | 危险操作 | 引用检查 → 确认/阻断 |
| 下级/首领/成员/地点/榜单 | 链接 | 打开对应详情 |

- 每屏最多 1 个实心主按钮；「更多」菜单收纳删除。
- 「新建下级」不单独设主按钮；在编辑上级/新建节点流程中完成（不新增页面）。

## 6. 交互细节

### 6.1 查看态

1. 加载：标题/摘要/成员表/关系区 Skeleton；文字优先。
2. 首屏展示名称、上级、首领、成员计数（FR-11）。
3. 点击上级/首领/下级/成员/地点 → 对应详情；链接可达。
4. 切换「仅直属/含下级」：成员表刷新；保留分页重置到第 1 页；URL 可保存状态（可选）。
5. 待校对确认：调用 `POST /factions/{id}/review`，成功后刷新 `review_status`/`reviewed_at`、Badge 消失；失败保留。
6. 大事记删除：行内确认 + Toast 撤销。

### 6.2 内联编辑

1. 点击「编辑」→ 名称、上级、首领、简介变为控件；成员/关系/大事记保持只读。
2. 上级树选择：禁用自身与全部后代；选项显示完整路径；清空 = 移到顶层。
3. 首领选择：搜索当前作品人物；显示势力/境界摘要；可清空。
4. 保存：校验名称/唯一/上级合法性；成功 Toast；树、人物页、地点页、检索同步。
5. 取消：有修改 → 确认放弃；无修改直接退出。
6. 并发冲突：保存/删除时实体 `version` 与请求头 `If-Match` 不一致 → ConflictDialog；页面只提示版本冲突，不展示 `version`、`updated_at` 等内部字段；保留输入；不自动合并。
7. 未保存离开：侧栏/切换作品/打开其他实体 → DirtyGuard。

### 6.3 删除

1. 「更多」→「删除势力」。
2. 入向引用检查：下级节点、人物归属成员（人物）阻止删除。
3. 出向关系/附属数据：首领人物、地点关联不阻止删除，删除时隐藏或自动解除；导入校对状态不是引用关系，不参与删除判定；页面以说明文案提示，不列为阻断项。
4. 有入向引用 → ReferenceDialog 720px，按类型分组；引用项在回收站时显示「回收站中」徽标 +「查看回收站」定位链接；主操作禁用；可跳转。
5. 无入向引用 → ConfirmDialog「删除势力「X」？」+「将进入回收站，可在 8 秒内撤销」。
6. 成功 → 返回 PG-04；Toast + 撤销。
7. 恢复时父级已删 → 阻止并提示「请先恢复上级势力」（在 PG-12 处理）。
8. 失败 → Alert + 重试。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Loading | 标题/摘要/成员/关系 Skeleton |
| Empty（成员/下级/地点/大事记） | 分组空状态 + 下一步入口 |
| Success | Toast「已保存」/「已确认校对」/「已移入回收站」 |
| Error（加载） | 页面错误 + 重试/返回势力列表 |
| Error（保存） | 字段级错误；保留输入 |
| Conflict | ConflictDialog；保留输入 |
| Deleted/NotFound | 「内容不存在或已删除」+ 返回势力列表 |
| Disabled | 保存中禁用；被引用删除禁用 |
| Pending | Badge + 确认按钮 |
| Network | 顶部 Alert + 重试；未保存编辑保留 |

## 8. 校验与边界

- 名称必填、同作品唯一；英文大小写视为重复。
- 上级不能为自身/后代（EX-18）；上级必须属于当前作品。
- 首领必须是当前作品人物；成员由人物归属决定，不能手工添加。
- 势力不引用体系；表单不出现体系字段（FR-24）。
- 删除仅被「下级节点」「人物归属成员」阻止；首领人物、地点关联不阻止，随势力删除隐藏/自动解除；导入校对状态不参与删除判定；引用位置可跳转（FR-38）。
- 恢复时父级缺失阻止（EX-15）。
- 字段超长 → 字段级错误；最终上限由 P4 确认。
- 权限不足 N/A。

## 9. 响应式

| 宽度 | 布局 | 摘要条 | 成员表 |
|---|---|---|---|
| ≥1280 | 主栏 760 + 侧栏 320 | 4 列 | 全列 |
| 1024–1279 | 侧栏移到底部 | 2×2 | 横向滚动；榜单列可隐藏 |
| <1024 | 最小 1024，横向滚动 + 提示 | 2×2 | 横向滚动 |

- 成员表操作/链接不因窄屏隐藏；允许横向滚动。
- 摘要条不改为图表。

## 10. 可访问性

- 标题 H1；区块 H2；摘要条使用定义列表/标签 + 数值，不只靠视觉。
- 成员表 `scope="col"`；行链接可键盘访问；分页有 `aria-label`。
- 上下级关系链接完整；不使用只有图标的跳转。
- 内联编辑字段有标签；错误 `aria-describedby`；保存/取消顺序固定。
- 待校对 Badge 有文字；确认按钮有明确名称。
- 加载 `aria-busy`；错误 `role="alert"`；对话框焦点陷阱。
- 对比度按 design-system §8。

## 11. 视觉与原型

- 原型 `#faction`：展示面包屑、摘要条、下级分支、成员表、地点关系、势力大事记、待校对 Badge。
- 视觉基线：摘要条 4 列等宽；成员行 44px；下级分支列表行 36px；侧栏 320px。
- 不使用关系图谱；不使用大面积卡片阴影。

## 12. 验收标准

- [ ] 首屏展示名称、上级、首领、直属/含下级成员数、下级分支数。
- [ ] 成员由人物归属自动推导；切换仅直属/含下级正确。
- [ ] 编辑同页内联；上级变更时可禁用自身/后代；保存后树/人物/地点/检索同步。
- [ ] 势力表单无体系字段；首领为当前作品人物，可清空。
- [ ] 删除仅被「下级节点」「人物归属成员」阻止并列出引用位置；出向关系自动解除；无引用删除后可撤销。
- [ ] 恢复时父级已删被阻止并提示先恢复父级。
- [ ] 大事记可增删改；地点关系含备注且双向可达。
- [ ] 待校对 Badge 可确认，调用 `POST /factions/{id}/review`，确认后 `review_status/reviewed_at` 刷新并同步。
- [ ] 加载/空/错误/并发冲突状态完整；无英文堆栈。
