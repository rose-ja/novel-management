## 1. 页面目标

- 用固定席位表表达「席位号即名次」；空席必须可见，不能隐藏。
- 支持指派、移动到空席、与目标席位交换、移出榜单；同一人物同榜仅 1 席。
- 支持扩容与缩容；缩容仅当尾部席位全空，否则阻止并列出占用人。
- 人物详情展示所在榜单与名次；双向可达。
- 删除整张榜单进回收站；恢复时若原席位人物已删，阻止并提示先恢复人物。

## 4. 字段与展示规则

| 字段 | 展示规则 | 编辑 |
|---|---|---|
| 榜单名称 | H1 24px；同作品唯一 | 编辑名称（Dialog/内联，PG09-Q1） |
| 席位数 | 1–200；摘要与表头显示 | 扩容/缩容 Dialog |
| 席位号 | 1..N；等宽数字；固定升序；前 3 席可用主色数字（不额外装饰） | 不可编辑 |
| 人物 | 头像 40px + 姓名链接 PG-03（`/characters?id=<id>`）；空席「虚位以待」 | 指派/调整/移出 |
| 待校对 | 人物 Badge「待校对」随人物显示；榜单本身也可有 Badge；`review_status=pending` 时显示，确认后刷新 `review_status`/`reviewed_at` | 确认，调用 `POST /rankings/{id}/review` |
| 境界/势力 | 人物当前境界 + 所属势力；空显示「—」；只读 | 随人物同步 |
| 备注 | 席位备注，可空；可写「并列」；不参与排序 | 行内编辑（可选）或调整弹窗 |
| 已占 / 空席 | 摘要数字；已占 = 非空席位数 | 随席位变化 |
| 操作 | 已占：调整席位 / 移出榜单；空席：指派 | 行菜单/按钮 |
| 删除榜单 | 整张进回收站 | 更多菜单 |

**席位规则（FR-18）**：

- 每席 0..1 人物；允许空缺；同一人物同榜仅 1 席；可上多榜。
- 调整仅支持「移动到空席」或「与目标席位交换」；不提供插入/整体下移。
- 不做并列建模；备注可写「并列」。
- 席位号即名次；不支持并列名次、并列席位号。

### 4.1 跳至席位

- 输入 1..N 的整数；越界提示「请输入 1–N 的席位号」。
- 保持每页 50 席；席位表请求固定 `page_size=50`，不提供每页条数切换。
- 跳席页码按 50 计算：`page = floor((seat_no-1)/50)+1`；滚动到该行并高亮 2s，焦点进入该行。
- 空席也可跳转；跳转后显示「指派」按钮。

### 4.2 搜索在榜人物

- 可选辅助：在当前榜单内按姓名/别名过滤；不改变席位号。
- 若实现全榜过滤，结果仍保留席位号与所在页；不提供「搜索后隐藏空席」。
- 本版不做榜单内复杂筛选；全局检索在 PG-01。

### 4.3 扩容 / 缩容

| 操作 | 规则 | 失败 |
|---|---|---|
| 扩容 | 当前 N + 新增数 ≤200；新增席为空 | 超过 200 → 阻止 + 提示 |
| 缩容 | 目标 N < 当前；仅当第 N+1..当前 席位全空 | 尾部有人 → ReferenceDialog 列出占用人（席位号 + 姓名 + 链接） |
| 结果 | Toast「已扩容至 N 席」/「已缩容至 N 席」；表格刷新；当前页合法 | 保留输入；不改变席位数 |

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 扩容 | 主按钮（页头） | CapacityDialog 增加席位数 |
| 指派 | 主按钮（空席行） | AssignCharacterDialog；选择人物 → 保存 |
| 调整席位 | 次操作（行菜单） | AdjustSeatDialog：目标空 → 移动；目标占 → 交换 |
| 移出榜单 | 危险次操作（行菜单） | RemoveSeatDialog 确认；Toast 撤销 |
| 缩容 | 次操作（更多/页头菜单） | CapacityDialog；尾空才可 |
| 删除榜单 | 危险操作（更多） | ConfirmDialog → 回收站 |
| 确认已校对 | 次按钮（待校对） | 调用 `POST /rankings/{id}/review`；成功后刷新 `review_status`/`reviewed_at`，取消 Badge |
| 跳转/搜索/翻页 | 次操作 | 不改变数据 |

- 每屏最多 1 个实心主按钮：「扩容」或空席「指派」二选一，页头保留「扩容」为主，空席指派用描边按钮。
- 删除收进「更多」，不与扩容并列。

## 6. 交互细节

### 6.1 指派人物

1. 点击空席「指派」→ AssignCharacterDialog（560px）。
2. 搜索当前作品人物（姓名/别名/称号）；结果行显示头像、姓名、势力、境界。
3. 选中后显示「将指派到第 N 席」；主按钮「指派到第 N 席」。
4. 若该人物已在本榜其他席 → 阻止：「该人物已在第 N 席，请先移出或与目标席位交换。」；提供跳转到该席。
5. 成功：席位更新；Toast「已指派」；人物详情名次同步。
6. 取消：不改变。

### 6.2 调整席位

1. 已占席位行菜单「调整席位」→ AdjustSeatDialog（560px）。
2. 输入目标席位号；实时显示：
   - 空席：`第 8 席为空 → 移动到第 8 席`
   - 已占：`第 8 席为「姜黎」→ 与第 8 席交换`
3. 目标为当前席位 → 禁用 + 提示「已在第 N 席」。
4. 确认 → 两席更新（交换时原子）；Toast「已调整席位」；人物详情同步。
5. 失败：越界/同榜重复；并发时实体 `version` 与请求头 `If-Match` 不一致 → ConflictDialog（页面只提示版本冲突，不展示内部字段）；保留输入；不改变。
6. 取消：不改变。

### 6.3 移出榜单

1. 行菜单「移出榜单」→ RemoveSeatDialog：「将「人物名」移出第 N 席？该席变为空席。」
2. 确认 → 席位变空；Toast「已移出」+「撤销」；人物详情不再显示该榜。
3. 取消：不改变。

### 6.4 备注

- 备注可写「并列」等说明；不参与排序；不改变席位号。
- 行内编辑：点击备注单元格 → 行内输入 + 保存/取消；或纳入调整弹窗（PG09-Q2）。
- 备注可为空；空显示「—」；不复制人物简介。

### 6.5 删除榜单

1. 「更多」→「删除榜单」→ ConfirmDialog「删除榜单「X」？整张榜单将进入回收站，可在 8 秒内撤销。」
2. 成功 → 返回 PG-08；Toast + 撤销。
3. 恢复时若原席位人物已删除 → 阻止并提示「请先恢复原席位人物」（PG-12）。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Loading | 标题/摘要/席位表 Skeleton |
| Empty（全空席） | 席位表仍显示空席 + 指派；顶部提示「全部席位为空」 |
| Empty（无人物可选） | AssignCharacterDialog 空状态「当前作品还没有人物」+ 去新建 |
| Success | Toast「已指派」/「已调整席位」/「已移出」/「已扩容」/「已缩容」 |
| Error（加载） | 页面错误 + 重试/返回榜单列表 |
| Error（保存） | 弹窗内错误；保留输入 |
| Conflict | ConflictDialog；保留输入；不自动合并 |
| Deleted/NotFound | 「内容不存在或已删除」+ 返回榜单列表 |
| Disabled | 提交中禁用；跳转/指派在加载中禁用；缩容尾有人禁用 |
| Pending | Badge + 确认按钮 |
| Network | 顶部 Alert + 重试；未保存编辑保留 |

## 8. 校验与边界

- 席位号 1..N；越界阻止（EX-20）。
- 同一人物同榜第二席阻止（EX-19）。
- 缩容仅尾部全空；否则 ReferenceDialog 列出占用人（EX-17）。
- 扩容 ≤200；超过阻止。
- 移动/交换必须原子；以 `version` + `If-Match` 防并发覆盖，失败不产生半更新。
- 人物被删除后，榜单席位显示「人物已删除」占位？需求要求恢复时阻止，但日常人物删除被榜单引用会被阻止（FR-07/EX-14），因此正常入口不会出现空引用。若并发/异常出现，显示「人物不可用」+ 提示恢复/重新指派，不显示死链。
- 备注不参与排序；不建并列席位。
- 权限不足 N/A。
- 性能：席位表 50 行/页；500 行以内轻量；首屏 ≤2s；不使用图表。

| 宽度 | 表格 | 摘要 | 弹窗 |
|---|---|---|---|
| ≥1280 | 全列；席位号等宽 | 3 列 | 560px |
| 1024–1279 | 横向滚动；备注列可隐藏 | 3 列 | max 视口 - 40px |

- 空席行不折叠；允许横向滚动查看操作列。
- 跳至席位输入不隐藏。

## 10. 可访问性

- 表格 `scope="col"`；席位号列有明确表头；行链接/按钮键盘可达。
- 空席「虚位以待」是文本，不只靠虚线；指派按钮有 `aria-label="指派第 N 席"`。
- 调整席位弹窗说明目标状态（空/已占）用文字；焦点进入目标席位输入。
- 交换操作在确认前明确目标人物名；避免误操作。
- 加载 `aria-busy`；错误 `role="alert"`；Toast `aria-live`。
- 席位号等宽数字，便于读屏与扫读。
- 对比度按 design-system §8；空席文字对比度不低于 4.5:1（#7C8F84 on #F6F9F7 约 3.4:1 — 仅用于辅助文本，关键「指派」用主色文字）。**修正**：空席提示文字使用 `--color-text-secondary` `#4B6055`，确保可读；虚线仅作辅助。

## 11. 视觉与原型

- 原型 `#ranking`：展示席位表、空席、前 3 席、行菜单、扩容/更多、跳至席位、分页。
- 视觉基线：席位表行高 44px；空席底色 `#F6F9F7`；席位号等宽；已占行白底；备注列宽 120px。
- 不使用奖杯图标、排行榜大卡片或渐变名次条。

## 12. 验收标准

- [ ] 创建 100 席榜单；席位 1–100 固定升序；空席可见。
- [ ] 指派、移动到空席、交换均可用；同一人同榜第二席被阻止；可上多榜。
- [ ] 扩容成功；尾部有人时缩容被阻止并列出占用人。
- [ ] 移出榜单后席位变空；人物详情名次同步。
- [ ] 跳至席位按每页 50 席计算页码并高亮；请求固定 `page_size=50`；越界提示。
- [ ] 删除榜单整张进回收站；恢复时原人物已删被阻止。
- [ ] 待校对 Badge 可确认（`POST /rankings/{id}/review`），刷新 `review_status/reviewed_at`；人物详情与榜单双向可达。
- [ ] 加载/空/错误/冲突状态完整；无英文堆栈；无死链。
