## 1. 页面目标

- 用单棵树呈现「星域 → 星城 → 秘境」的地点层级，默认展开两级。
- 支持节点名称搜索定位、类型筛选、待校对视图中快速找到未确认节点。
- 新建节点使用页内内联表单（遵循 FR-13「新建/编辑使用内联表单」），不新增独立页面。
- 列表一眼看出名称、类型、上级、关联人物数、关联势力数、待校对状态。
- 本版不做地点图片；不引用体系。

## 4. 字段与展示规则

| 字段 | 展示规则 | 数据来源 |
|---|---|---|
| 名称 | 14px/500；链接到 PG-07（`/locations?id=<id>`）；命中搜索词高亮 | 地点 |
| 类型 | 自由文本；显示节点类型；空显示「—」 | 地点 |
| 上级 | 搜索/查看时可显示路径；树缩进表达层级 | 地点树 |
| 直接下级数 | 箭头与子节点数量；无下级不显示箭头 | 地点树 |
| 关联人物 | 该地点关联人物数；等宽数字 | 人物→地点 |
| 关联势力 | 该地点关联势力数；等宽数字 | 地点→势力 |
| 待校对 | Badge「待校对」；`review_status=pending` 时显示，确认后刷新 `review_status`/`reviewed_at` 并消失 | 地点 DTO |
| 新建上级 | 树选择；可空（顶层）；禁止选择自身/后代（新建时无自身） | 地点树 |
| 新建类型 | 自由文本 + 已有值建议；允许新值；可空 | 地点 |

**搜索与筛选**：

- 节点名称搜索：300ms debounce；命中高亮并展开祖先；无匹配提示 + 清除。
- 类型筛选：只显示该类型节点及其祖先链；不隐藏祖先（否则层级断裂）。
- 待校对：只看未确认节点及其祖先链；请求参数 `review_status=pending`；DTO 返回 `review_status`、`reviewed_at`。
- AND 组合；活跃筛选 chip 可单独移除；重置清空。
- 搜索/筛选不改变树结构；点击节点进入 PG-07（`/locations?id=<id>`）。

**排序**：树按同级 `sort_order` / 名称稳定排序；本页不提供排序控件；新建默认追加同级末尾；移动父级在 PG-07 编辑中完成。

**分页**：树不分页；页头显示节点总数；1000 节点用虚拟滚动/懒展开（实现层决定）。

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 新建地点节点 | 主按钮 | 展开内联新建面板；焦点进入上级/名称 |
| 保存节点 | 主按钮（面板） | 校验 → 保存 → 树刷新并选中；Toast「地点节点已创建」 |
| 取消 | 次按钮 | 有输入 → 确认放弃；无输入直接收起 |
| 节点名称 | 链接 | 进入 PG-07（`/locations?id=<id>`） |
| 展开/收起/搜索/筛选 | 次操作 | 过滤/定位；不改变数据 |

- 行内不提供编辑/删除；在详情页完成。
- 新建后停留树并选中节点（PG06-Q1）；用户可点击进入详情。

## 6. 交互细节

1. 新建：点击主按钮 → 面板展开；上级默认空（顶层）；名称、类型、简介。
2. 名称必填、同作品唯一；类型可空或自由输入；已有类型作为建议（不强制）。
3. 保存：校验 → 成功 Toast；树刷新；自动展开父级并选中；滚动到可见。
4. 取消：有输入 → Dialog「放弃未保存的修改？」；无输入直接收起。
5. 树点击：整行可点击；展开按钮阻止冒泡，不进入详情。
6. 搜索命中：展开祖先并滚动到第一个命中；高亮匹配词。
7. 加载：树 8 行 Skeleton；搜索/筛选可用。
8. 空树：「还没有地点节点」+「新建第一个地点」+「从固定模板导入」。
9. 切换作品：清空树/搜索/筛选；重新加载；无作品显示 PG-00 状态。
10. 从详情返回：保留展开状态、搜索、筛选、滚动位置。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Empty（无节点） | 空状态 + 新建/导入 |
| Empty（搜索/筛选无结果） | 「没有匹配的地点节点」+ 清除筛选 |
| Loading | 树 8 行 Skeleton；按钮可用 |
| Error | 树区域错误 + 重试；保留搜索 |
| Success | 树 + 计数；新建后选中 |
| Editing（内联新建） | 面板展开；树可见；保存/取消 |
| Disabled | 保存中禁用 |
| Network | 顶部 Alert + 树错误；不进入离线模式 |

## 8. 校验与边界

- 名称必填、同作品唯一；英文大小写视为重复（FR-48）。
- 上级必须属于当前作品；新建可空；不能选择自身/后代（编辑在 PG-07，EX-18）。
- 类型自由文本，不限制为固定枚举；空值允许；重复类型可存在。
- 删除只在 PG-07；有下级地点、人物关联、势力关联时阻止，不得级联解除。
- 本版不做地点图片、地点不引用体系（FR-16/FR-24）。
- 空树不显示空白表格；无权限 N/A。
- 1000 节点下树可用；不显示内部 ID/堆栈。

## 9. 响应式

| 宽度 | 树 | 行内容 | 新建面板 |
|---|---|---|---|
| ≥1280 | 全宽（最大 1200） | 名称 + 类型 + 人物/势力数 | 两列（上级/名称/类型）+ 简介整行 |
| 1024–1279 | 全宽，横向 20px | 人数/势力数可缩略；Tooltip | 单列 |
| <1024 | 最小 1024，横向滚动 + 提示 | 同 1024 | 单列 |

- 深层层级通过缩进表达；过深允许横向滚动，不折叠为面包屑。

## 10. 可访问性

- 树使用 `role="tree"` / `treeitem` + `aria-expanded`（或嵌套列表 + 展开按钮，全站统一）。
- Tab 可达节点与展开按钮；Enter 打开详情；空格切换展开。
- 搜索高亮 `<mark>`；类型筛选有可见标签。
- 计数列有标签；不只靠图标。
- 加载 `aria-busy`；错误 `role="alert"`。
- 对比度按 design-system §8。

## 11. 视觉与原型

- 树为页面主体；不使用连接线装饰；缩进 + 箭头表达层级。
- 默认展开两级；命中/选中行浅绿；待校对 Warning Badge。
- 新建面板白底 + 1px 边框 + 12px 圆角，不使用大抽屉（遵循内联表单）。

## 12. 验收标准

- [ ] 可建立「星域 → 星城 → 秘境」三级；默认展开两级。
- [ ] 节点名称搜索可定位并展开祖先；无匹配有提示。
- [ ] 类型筛选可用已有类型；只显示匹配节点及祖先链。
- [ ] 行显示名称、类型、关联人物数、关联势力数、待校对 Badge；待校对按 `review_status=pending` 筛选。
- [ ] 新建节点为页内内联表单；名称必填/唯一；类型自由输入；保存后选中节点。
- [ ] 取消有输入时确认放弃；保存失败保留输入。
- [ ] 点击节点进入 PG-07（`/locations?id=<id>`）；展开按钮不误触详情。
