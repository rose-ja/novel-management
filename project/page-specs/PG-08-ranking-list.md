## 1. 页面目标

- 在当前作品内浏览全部榜单，快速看到席位数、已占/空席、前三席人物与待校对状态。
- 新建榜单并设定初始席位数（1–200，默认 100）；创建后进入详情。
- 榜单名称同作品唯一；删除整张榜单进回收站。
- 列表不展示完整席位表；席位维护在 PG-09。

## 4. 字段与展示规则

| 列 | 字段 | 展示规则 | 数据来源 |
|---|---|---|---|
| 榜单名称 | 名称 | 14px/500；链接 PG-09（`/rankings?id=<id>`）；同作品唯一；超长省略 | 榜单 |
| 待校对 | `review_status` / `reviewed_at` | Badge「待校对」；`review_status=pending` 时显示，确认后刷新并消失 | 榜单 DTO |
| 席位数 | capacity | 等宽数字；1–200 | 榜单 |
| 已占 | occupied | 等宽数字；= 非空席位数量 | 席位 |
| 空席 | empty | `席位数 - 已占`；等宽数字 | 席位 |
| 前三席 | 1–3 席 | 有则显示 `1 姓名 · 2 姓名 · 3 姓名`；空席显示「—」；最多 1 行 | 席位 |
| 更新时间 | updated_at | `YYYY-MM-DD HH:mm`；可排序 | 系统 |
| 操作 | 查看 / 删除 | 删除需确认 + 快照（如涉及）；整张进回收站 | 操作 |

**搜索/筛选/排序**：

- 搜索榜单名称，300ms debounce；不触发全局检索。
- 待校对 Checkbox；请求参数 `review_status=pending`；榜单 DTO 返回 `review_status`、`reviewed_at`；AND 组合。
- 排序：更新时间（默认倒序）/ 名称；不含席位数字段排序。
- 重置清空筛选，恢复默认排序。

**分页**：每页 20；显示总数；翻页保留筛选/排序。

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 新建榜单 | 主按钮 | 打开 CreateRankingDialog（560px）：名称 + 席位数（1–200，默认 100） |
| 创建榜单 | 主按钮（Dialog） | 校验 → 创建 → Toast → 进入 PG-09 |
| 榜单名称/查看 | 链接 | 进入 PG-09（`/rankings?id=<id>`） |
| 删除榜单 | 危险次操作（行菜单） | ConfirmDialog → 整张进回收站 + Toast 撤销 |
| 筛选/排序/分页 | 次操作 | 刷新列表 |

- 榜单列表不提供批量删除。
- 删除入口收进「更多」菜单；不提供「清空席位」批量操作（需求未要求）。

## 6. 交互细节

1. 新建 Dialog：
   - 名称必填、同作品唯一、英文不区分大小写。
   - 席位数 1–200，默认 100；数字输入 + 范围提示；越界字段错误。
   - 成功：Toast「榜单已创建」；进入 PG-09；席位全部为空。
   - 失败：保留输入；按钮恢复可用。
2. 删除：ConfirmDialog「删除榜单「X」？整张榜单将进入回收站，可在 8 秒内撤销。」；成功 Toast + 撤销；恢复时若原席位人物已删，在 PG-12 阻止。
3. 空列表：「还没有榜单」+「新建第一张榜单」+「从固定模板导入」。
4. 加载：表头 + 6 行 Skeleton；新建按钮可用。
5. 错误：表体 Alert「榜单列表加载失败」+ 重试；保留筛选。
6. 切换作品：清空列表/筛选/排序；重新请求；无作品显示 PG-00 状态。
7. 从详情返回：保留筛选/排序/页码。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Empty（无榜单） | 空状态 + 新建/导入 |
| Empty（筛选无结果） | 「没有符合筛选的榜单」+ 清除筛选 |
| Loading | 表头 + 6 行 Skeleton |
| Error | 表体错误 + 重试 |
| Success | 表格 + 总数 + 分页 |
| Disabled | 创建中禁用；删除确认中禁用 |
| Pending | Badge「待校对」 |
| Network | 顶部 Alert + 表体错误；不进入离线模式 |

## 8. 校验与边界

- 名称必填、同作品唯一；英文大小写视为重复（FR-48）。
- 席位数 1–200；默认 100；越界阻止（EX-20）。
- 删除被引用榜单？榜单不是被引用方，删除整张进回收站；恢复时若席位人物已删，阻止（FR-20）。
- 空列表不显示空白表格；无权限 N/A。
- 不显示内部 ID/堆栈。
- 列表性能按 AC-24；缩略图不适用于本页（前三席只显示姓名，不加载头像）。

## 9. 响应式

| 宽度 | 表格 | 前三席 | 操作 |
|---|---|---|---|
| ≥1280 | 全列 | 1 行 | 行菜单 |
| 1024–1279 | 横向滚动 | 1 行可省略 | 行菜单 |
| <1024 | 横向滚动 + 提示 | 省略 | 行菜单 |

- 前三席不改为头像卡片；保持文字密度。

## 10. 可访问性

- 表格 `scope="col"`；名称链接键盘可达；排序 `aria-sort`。
- 席位/已占/空席数字有列头；不只靠颜色。
- 待校对 Badge 有文字；删除菜单项有明确名称。
- 对话框焦点陷阱；数字输入有范围说明与错误关联。
- 加载 `aria-busy`；错误 `role="alert"`。
- 对比度按 design-system §8。

## 11. 视觉与原型

- 表格为主；前三席文字紧凑；不使用排行榜卡片或奖杯插画。
- 席位数字等宽；空席在详情页显示，不在列表用红色。
- 原型未覆盖；列表密度与 `#search`/`#trash` 一致。

## 12. 验收标准

- [ ] 新建榜单可设定名称与 1–200 席（默认 100）；创建后进入详情。
- [ ] 榜单名称同作品唯一；英文大小写视为重复。
- [ ] 列表显示席位数、已占、空席、前三席、更新时间、待校对；待校对按 `review_status=pending` 筛选。
- [ ] 搜索/排序/分页可用；筛选 AND 组合。
- [ ] 删除榜单整张进回收站，可 Toast 撤销。
- [ ] 空/加载/错误/筛选无结果状态完整；无英文堆栈。
- [ ] 切换作品数据隔离；无跨作品榜单。
