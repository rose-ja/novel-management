## 1. 页面目标

- 跨作品展示所有软删除对象：作品、人物、势力、地点、榜单、体系类别、体系节点、大事记。
- 清楚显示类型、名称、原作品、删除时间、删除前父级；整本作品/整组类别作为一条记录。
- 提供恢复、永久删除、清空回收站；永久删除与清空前自动快照。
- 恢复必须校验名称冲突、父级存在、引用完整；冲突允许在弹窗内改名。
- 删除请求的引用检查包含「回收站中的记录」；本页提供定位与恢复后解除引用的路径。
- 回收站数据不参与检索与关系跳转；无死链。

## 4. 字段与展示规则

| 列 | 字段 | 规则 |
|---|---|---|
| 类型 | 作品/人物/势力/地点/榜单/体系类别/体系节点/大事记 | 文字 + 中性 Badge；不省略 |
| 名称 | 原名称 | 整组类别显示「类别名（含 N 个节点）」；整本作品显示《作品名》；节点显示节点名 + 类别 |
| 原作品 | 作品名 | 作品本身被删除时显示「—」（父级不存在） |
| 删除时间 | deleted_at | `YYYY-MM-DD HH:mm`；默认倒序；可排序 |
| 删除前父级 | 父级名称/所属 | 势力/地点显示父级；节点显示类别+父节点；人物显示势力（如有）；类别/榜单/作品显示「—」 |
| 操作 | 恢复 / 永久删除 | 每行最多 2 个；永久删除 danger 文字；不提供批量选择（需求未要求） |
| 整组 | 类别+节点 / 整本作品 | 只显示一条记录；其下实体不单独列出（FR-60/AC-13） |
| 待校对 | — | 回收站不显示待校对 Badge；恢复后在原数据中保留/显示 |

**筛选**：

- 搜索名称：当前回收站内过滤；300ms debounce。
- 类型：全部 + 8 类；与原作品 AND 组合。
- 原作品：全部 + 作品名；作品本身被删除时仍可选其名称。
- 活跃筛选 chip 可单独移除；重置清空。
- 排序：删除时间倒序（默认）/名称；不提供每页条数切换。

**分页**：每页 20；显示总数；翻页保留筛选。

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 恢复 | 次操作（行） | 校验 → 成功回原位置；冲突 → 改名牌；父级/引用缺失 → 阻止 |
| 永久删除 | 危险操作（行） | 确认 + 自动快照 → 不可恢复 |
| 清空回收站 | 危险主操作（页头） | 确认数量 + 自动快照 → 全部永久删除 |
| 搜索/筛选/分页 | 次操作 | 过滤；不改变数据 |
| 重置 | 次操作 | 清空筛选 |

- 不提供「批量恢复/批量永久删除」（需求未要求；清空是全局操作）。
- 恢复成功后 Toast「已恢复」；不自动跳转到恢复对象（停在回收站，可点击名称？回收站行名称不做链接，避免指向已删除对象；恢复后 Toast 提供「查看」可选）。
- 永久删除成功后 Toast「已永久删除」；不可撤销。

## 6. 交互细节

### 6.1 恢复

1. 点击「恢复」→ 先请求校验。
2. 无冲突 → RestoreDialog（400px）：「恢复人物「白无咎」到原位置（天枢院）？」；确认 → Toast「已恢复」；行消失。
3. 名称冲突 → RestoreConflictDialog（560px）：
   - 显示冲突对象「同作品已存在同名人物「白无咎」」；
   - 输入「恢复后名称」（预填原名 + `（恢复）` 后缀）；
   - 确认 → 以新名称恢复；Toast；原名称不被覆盖。
4. 父级已删除 → 阻止：「无法恢复：上级势力「旧青丘」已删除。请先恢复上级势力。」；提供「查看回收站中的父级」筛选/定位。
5. 引用缺失 → 阻止：「无法恢复：引用的「人物 X」已删除。请先恢复引用实体。」
6. 整组类别/整本作品 → **整组原子恢复**：
   - 恢复前一次性列出全部子项重名冲突；
   - 弹窗内逐项改名（预填原名 + `（恢复）` 后缀），可「全部采用建议名称」；
   - 一次性提交 `renames[]` 与恢复请求；任一项校验/恢复失败 → 整组不恢复、无部分恢复；
   - 取消 → 整体不恢复。
7. 恢复后回到原父级位置；若原父级已恢复，展开/定位。
8. 「删除时被回收站引用」：若实体因回收站中的记录引用而无法删除，删除入口的引用对话框/错误详情显示「回收站中」徽标 +「查看回收站」链接（`/trash?type=<type>&highlight=<id>`）；恢复该记录后打开其详情解除引用，再重试删除；恢复成功后对应引用阻断自动解除。

### 6.2 永久删除

1. 行「永久删除」→ PermanentDeleteDialog（400px）：
   - 标题「永久删除人物「白无咎」？」
   - 说明「此操作不可撤销。删除前会自动创建快照。」
2. 确认 → 快照成功 → 永久删除 → Toast；行消失。
3. 快照失败 → 阻止；Alert「快照创建失败，未执行删除」+ 重试。
4. 取消 → 不删除。

### 6.3 清空回收站

1. 页头「清空回收站」→ ClearTrashDialog（560px）：
   - 标题「清空回收站？」
   - 说明「将永久删除全部 18 项，包括整本作品与整组类别。此操作不可撤销；删除前会自动创建快照。」
   - 主按钮「清空回收站」danger；次按钮「取消」。
2. 确认 → 快照 → 清空 → Toast「回收站已清空」；空状态。
3. 快照失败 → 阻止；Alert + 重试。
4. 回收站为空 → 页头按钮禁用 + Tooltip「回收站已为空」。

### 6.4 空状态

- 空回收站：图标 + 「回收站是空的」+ 说明「删除的内容会在这里保留，直到你恢复或永久删除。」+「返回检索」。
- 筛选无结果：「没有符合筛选的回收站项」+「清除筛选」。
- 加载：表格 6 行 Skeleton；错误：表体 Alert + 重试。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Empty（无数据） | 空状态 + 返回检索；清空禁用 |
| Empty（筛选无结果） | 清除筛选 |
| Loading | 表头 + 6 行 Skeleton |
| Error | 表体错误 + 重试；保留筛选 |
| Success（恢复） | Toast「已恢复」；行消失；原位置更新 |
| Success（永久删除/清空） | Toast；行消失/空状态 |
| Disabled | 空回收站清空禁用；快照中禁用；提交中禁用 |
| Conflict | RestoreConflictDialog；改名或取消 |
| Blocked（父级/引用缺失） | 阻止 Dialog + 先恢复提示；不删除 |
| Blocked（被回收站引用） | 引用项显示「回收站中」徽标 +「查看回收站」定位；恢复并解除引用后再删除 |
| Snapshot failure | 阻止永久删除/清空；Alert |
| Network | 顶部 Alert + 重试；不进入离线模式 |

## 8. 校验与边界

- 回收站是全局页面；不按当前作品过滤（默认全部作品），可用筛选缩小。
- 整本作品/整组类别只显示一条；其下实体不单独列出。
- 恢复名称冲突允许改名；不允许覆盖现有对象；整组恢复的改名一次性以 `renames[]` 提交，原子生效。
- 父级/引用缺失阻止恢复；不自动创建父级/引用。
- 删除时「回收站中的记录」也属于引用阻断；本页通过 `?type=<type>&highlight=<id>` 定位，恢复后解除引用再删除。
- 永久删除/清空必须二次确认 + 自动快照；快照失败阻止（EX-23）。
- 回收站数据不参与检索与关系跳转（FR-62）；恢复前不显示可点击链接到已删除实体。
- 不提供自动清理；保留至手动清空（FR-58）。
- 权限不足 N/A；不显示内部 ID/堆栈。

## 9. 响应式

| 宽度 | 表格 | 筛选 | 操作 |
|---|---|---|---|
| ≥1280 | 全列 | 单行 | 恢复/永久删除 |
| 1024–1279 | 横向滚动 | 搜索 + 筛选可换行 | 操作列 sticky |
| <1024 | 横向滚动 + 提示 | 同 1024 | 同 |

- 不把回收站行改为卡片；操作按钮不隐藏。

## 10. 可访问性

- 表格 `scope="col"`；类型 Badge 有文字；删除/恢复按钮有明确对象名称（`aria-label`）。
- 危险操作 Dialog `role="alertdialog"`；焦点进入取消或标题；Esc 可取消（提交中除外）。
- 快照提醒 Info Alert 可读；不是唯一风险提示，确认 Dialog 内重复说明。
- 恢复冲突改名输入有标签与错误关联；主按钮在名称为空时禁用。
- 加载 `aria-busy`；错误 `role="alert"`；Toast `aria-live`。
- 对比度按 design-system §8；危险/警告不只靠颜色。

## 11. 视觉与原型

- 原型 `#trash`：展示跨作品列表、类型 Badge、整组类别、快照提醒、恢复/永久删除、清空按钮。
- 视觉基线：表格行高 44px；危险按钮 red 文字；Info Alert 浅蓝；操作列固定右侧。
- 不使用垃圾桶插画、红色大面积背景或「清空」大按钮。

## 12. 验收标准

- [ ] 跨作品列出全部软删除对象；类型、名称、原作品、删除时间、删除前父级正确。
- [ ] 整本作品/整组类别各显示一条；其下实体不单独列出。
- [ ] 搜索/类型/原作品筛选 AND 组合；分页 20；重置可用。
- [ ] 恢复无冲突回原位置；名称冲突可改名；父级/引用缺失阻止并提示先恢复。
- [ ] 整组类别/作品恢复遇子项重名时，可逐项改名并以 `renames[]` 一次性提交，整组原子恢复；取消则整体不恢复。
- [ ] 删除时被回收站引用可定位到 `/trash?type=<type>&highlight=<id>`；恢复并解除引用后再删除。
- [ ] 永久删除二次确认 + 自动快照；快照失败阻止。
- [ ] 清空回收站二次确认 + 自动快照；空回收站禁用。
- [ ] 删除后 Toast 撤销可恢复；回收站数据不参与检索/关系跳转。
- [ ] 空/加载/错误/冲突状态完整；无英文堆栈、无死链。
