## 1. 页面目标

- 首屏回答「这个人是谁、属于哪、境界如何、在哪些榜单」。
- 关系区覆盖势力、地点、榜单、体系引用、担任首领的势力；全部双向可跳转，无死链。
- 大事记按顺序展示，可增删改；简介完整可读。
- 编辑在同一页面内联展开，不跳独立编辑页；保存/取消明确；未保存离开与并发冲突有保护。

## 4. 字段与展示规则

### 4.1 人物字段

| 字段 | 必填 | 多值 | 展示 | 编辑 |
|---|---|---|---|---|
| 主名称 | 是 | 否 | H1 24px；同作品唯一；英文不区分大小写 | 文本输入 |
| 别名 | 否 | 是 | chip 列表；可检索；重复允许 | TagInput；回车/逗号添加；软上限 20 |
| 称号 | 否 | 是 | chip 列表；可检索；重复允许 | TagInput；软上限 20 |
| 境界（内置） | 否 | 否 | `主层级·子层级`；链接到 PG-10 节点 | TreeSelect（主层级 + 子层级，可清空） |
| 其他启用体系类别 | 否 | 各 0..1 | 分组显示类别名 + 节点；停用类别不显示 | 按启用类别动态生成 TreeSelect |
| 所属势力/分支 | 否 | 否 | 完整路径；链接 PG-05（`/factions?id=<id>`）；为空「—」 | TreeSelect（可搜索、可清空） |
| 关联地点 | 否 | 是 | 地点链接（`/locations?id=<id>`）+ 可选备注；为空空状态 | 多选 TreeSelect + 备注输入 |
| 主图 | 否 | 1 | 120×120 详情；40×40 列表；缺失首字占位 | ImageUploader（1:1、≤10MB） |
| 简介 | 否 | 否 | 正文，保留换行；长文可读 | Textarea，最小 120px |
| 大事记 | 否 | 多条 | 时间线；时间标签 + 内容；按 sort_order | 添加/编辑/删除；同级排序 |
| 待校对 | 系统 | 否 | Warning Badge；`review_status=pending` 时显示；确认后刷新 `review_status=confirmed` / `reviewed_at`，Badge 消失 | 「确认已校对」按钮，调用 `POST /characters/{id}/review` |
| 创建/更新时间 | 系统 | 否 | 侧栏档案；`YYYY-MM-DD HH:mm` | 只读 |

- 字段超长：由 P4 数据模型定义上限；UI 在超限时字段级错误，不静默截断。
- 简介纯文本优先，不做富文本编辑器（见 DS-Q5 与需求「架构阶段定」）。
- 图片重新编码/缩略图由实现层处理；UI 只展示结果。

### 4.2 关系区

| 分组 | 内容 | 空状态 | 跳转 |
|---|---|---|---|
| 所属势力 | 节点完整路径 | 「未归属势力」+ 编辑入口 | PG-05（`/factions?id=<id>`） |
| 担任首领 | 该人物为 0..N 个势力首领 | 「未担任首领」 | PG-05（`/factions?id=<id>`） |
| 关联地点 | 地点名 + 备注 | 「未关联地点」 | PG-07（`/locations?id=<id>`） |
| 所在榜单 | 榜单名 + 第 N 席 | 「未上榜」 | PG-09（`/rankings?id=<id>`） |
| 体系引用 | 每个启用类别 0..1 节点；显示类别名 + 节点 | 「未引用体系」 | PG-10 |

- 所有关系为引用，不复制文本；改名后此处自动更新。
- 链接必须可达；目标已删除/跨作品 → 「内容不存在或已删除」。
- 入向关系（担任首领、榜单席位）与出向关系（人物→势力/地点/体系）都要展示（FR-35）。

### 4.3 大事记

| 字段 | 规则 |
|---|---|
| 时间标签 | 自由文本，可空；例「少年时期」「帝境初成」；不排序依据 |
| 内容 | 纯文本；保留换行；必填；上限 2,000 字 |
| 排序 | `sort_order` 手动排序；新增默认末尾；编辑不改变顺序 |
| 操作 | 添加、编辑、删除；删除需行内轻确认 + Toast 撤销（PG03-Q1） |
| 展示 | 时间线：左侧序号（01/02）+ 时间标签 + 内容；最多 4 条后折叠？详情完整展示，列表不展示 |
| 空状态 | 「还没有大事记」+「添加第一条」 |

### 4.4 侧栏档案

- 所属作品；校对状态；创建时间；更新时间；主图状态（已上传/未上传）；快速链接（势力/地点/榜单/体系）。
- 不显示内部 ID、数据库字段名、版本号堆栈。
- 侧栏不超过 320px；1024–1279 移到主栏下方。

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 编辑 | 主按钮（查看态） | 切换为内联编辑；字段变为控件；底部出现保存/取消 |
| 保存 | 主按钮（编辑态） | 校验 → 保存 → Toast「已保存」→ 回到查看态 |
| 取消 | 次按钮 | 有修改 → 确认放弃；无修改直接退出 |
| 确认已校对 | 次按钮（待校对时） | 调用 `POST /characters/{id}/review`；成功后刷新 `review_status`/`reviewed_at`，取消 Badge；Toast；列表/检索同步 |
| 添加大事记 | 次按钮 | 行内新增表单；保存后追加 |
| 更多 → 删除人物 | 危险操作 | 引用检查 → 确认/阻断 |
| 关系链接 | 链接 | 打开对应详情；离开前检查未保存 |

- 每屏最多 1 个实心主按钮；编辑态主按钮为「保存」。
- 删除入口放在「更多」菜单，避免与编辑并列。

## 6. 交互细节

### 6.1 查看态

1. 加载：标题/主图/元信息/关系/时间线 Skeleton；首屏文字优先，图片后加载（AC-33）。
2. 首屏展示主名称、别名/称号、境界、势力、主图（FR-06）。
3. 点击关系链接 → 对应详情；不打开新标签页（保持应用内上下文）。
4. 待校对：Badge + 侧栏状态；点击「确认已校对」调用 `POST /characters/{id}/review`，成功后刷新 `review_status`/`reviewed_at` 并取消 Badge；失败保留 Badge。
5. 大事记删除：行内确认条「删除这条大事记？[取消][删除]」→ Toast 撤销；不弹大对话框。
6. 主图：懒加载；失败显示首字占位；点击可查看原图（可选 lightbox，不新增编辑能力）。

### 6.2 内联编辑

1. 点击「编辑」→ 页面主体切换为表单；页头保持标题与面包屑；底部 sticky 操作栏。
2. 字段按 §4.1 顺序；短字段两列，简介/大事记整行；动态体系字段按启用类别插入。
3. 校验：失焦校验字段；提交校验全部；首个错误滚动并聚焦；字段错误贴近字段。
4. 保存：按钮 loading；成功 Toast + 回到查看态；关系区/榜单/检索同步。
5. 取消：若有修改 → Dialog「放弃未保存的修改？」→ 放弃恢复原值 / 继续编辑。
6. 离开：侧栏跳转、切换作品、打开其他实体 → DirtyGuard；本版无自动保存/草稿恢复。
7. 并发：保存/删除时实体 `version` 与请求头 `If-Match` 不一致 → ConflictDialog「数据已被其他页面修改，请刷新后重试」；页面只提示版本冲突，不展示 `version`、`updated_at` 等内部字段；保留输入，不自动合并。

### 6.3 删除

1. 「更多」→「删除人物」。
2. 入向引用检查：仅「势力首领」「榜单席位」（含回收站中的势力/榜单）阻止删除。
3. 出向关系/附属数据：人物作为「势力成员」、地点关系、体系引用不阻止删除，删除时自动解除或随人物软删除；导入校对状态不是引用关系，不参与删除判定；页面以说明文案提示，不列为阻断项。
4. 有入向引用 → ReferenceDialog 720px；按类型分组；每条可跳转；引用项在回收站时显示「回收站中」徽标 +「查看回收站」链接（`/trash?type=<type>&highlight=<id>`）；主操作禁用。
5. 无入向引用 → ConfirmDialog「删除人物「X」？」+「将进入回收站，可在 8 秒内撤销」；主按钮 danger。
6. 成功 → 返回 PG-02；Toast「已移入回收站」+「撤销」；撤销回到原位置。
7. 失败 → Alert + 重试；不删除。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Loading | 标题/主图/关系/时间线 Skeleton；文字优先 |
| Empty（关系/大事记） | 分组内空状态 + 编辑/添加入口 |
| Success | Toast「已保存」/「已确认校对」/「已移入回收站」 |
| Error（加载） | 页面级错误「人物加载失败」+ 重试/返回列表 |
| Error（保存） | 字段级错误；保留输入；不关闭编辑 |
| Conflict | ConflictDialog；保留输入 |
| Deleted/NotFound | 「内容不存在或已删除」+ 返回检索/人物列表 |
| Disabled | 保存中禁用；被引用删除禁用 |
| Pending | 待校对 Badge + 确认按钮 |
| Network | 顶部 Alert + 重试；未保存编辑保留 |

## 8. 校验与边界

- 主名称空/重复 → 阻止保存；英文大小写视为重复；别名/称号重复允许。
- 势力/境界/地点/榜单引用必须属于当前作品；停用类别不可选；未启用类别不显示。
- 图片格式/大小/中断 → 字段级错误；不写入残缺图片。
- 大事记内容为空 → 阻止保存；时间标签可空；内容上限 2,000 字，超限字段级错误。
- 删除仅被「势力首领」「榜单席位」（含回收站中的引用）阻止；作为势力成员、地点关系、体系引用不阻止，自动解除/随人物软删除；导入校对状态不参与删除判定。
- 字段超长 → 字段级错误；不静默截断。
- 并发修改 → `version`/`If-Match` 冲突；不自动合并；提示刷新。
- 目标实体已删除 → 关系显示「内容不存在或已删除」，不显示死链。
- 权限不足 N/A。

## 9. 响应式

| 宽度 | 布局 | 主图 | 关系 |
|---|---|---|---|
| ≥1280 | 主栏 760 + 侧栏 320 | 120px | 两列分组 |
| 1024–1279 | 主栏在上，侧栏在下 | 96–120px | 单列分组 |
| <1024 | 最小 1024，横向滚动 + 提示 | 96px | 单列 |

- 编辑态字段在窄屏全部单列；sticky 操作栏不遮挡最后一行。
- 长简介允许滚动页面，不设固定高度截断。

## 10. 可访问性

- 页面标题为 H1；区块标题 H2；大事记使用列表语义。
- 主图 `alt="人物主图：{主名称}"`；占位 `role="img"` 同等 alt。
- 关系链接是 `<a>`；键盘可达；焦点可见。
- 内联编辑字段有标签；错误 `aria-describedby`；保存/取消按钮顺序固定。
- 待校对 Badge 含文字；确认按钮有明确 `aria-label`。
- Toast `aria-live`；冲突 Dialog `role="alertdialog"`；焦点陷阱与恢复。
- 对比度按 design-system §8；图片懒加载不改变布局。

## 11. 视觉与原型

- 原型 `#character`：展示首屏身份块、关系分组、大事记、侧栏档案、待校对 Badge。
- 视觉基线：H1 24/32；主图 120px；关系分组标题 15/22 600；大事记序号等宽；侧栏 320px。
- 不以关系图谱替代列表；不使用大面积装饰背景。

## 12. 验收标准

- [ ] 首屏展示主名称、别名/称号、境界、所属势力、主图。
- [ ] 关系区覆盖势力、担任首领、地点（含备注）、榜单席位、体系引用；全部可跳转，无死链。
- [ ] 用别名、称号分别检索均可命中并跳转到本页。

- [ ] 图片懒加载；缺失显示占位；不阻塞文字。
- [ ] 并发冲突提示、错误/空/加载状态完整；无英文堆栈。
