## 1. 页面目标

- 在当前作品内浏览、筛选、排序、新建人物，并快速进入详情。
- 列表必须一眼看出：主名称、别名/称号、所属势力、境界、所在榜单、待校对状态。
- 支持 1000 人物规模；列表 P95 ≤500ms；缩略图懒加载不阻塞文字。
- 不展示无关统计仪表盘；不在列表里展开完整简介或大事记。

## 4. 字段与展示规则

| 列 | 字段 | 展示规则 | 数据来源 |
|---|---|---|---|
| 缩略图 | 主图缩略图 | 40×40，1:1，圆角 8px，`loading="lazy"`；缺失显示姓名首字占位 | 人物主图 |
| 主名称 | 主名称 | 14px/500；链接到 PG-03（`/characters?id=<id>`）；超长省略 + Tooltip | 人物 |
| 别名/称号 | 别名 + 称号 | 最多 3 个 chip（别名优先），其余 `+N`；可点击进入详情；不在此列编辑 | 人物 |
| 势力 | 所属势力/分支 | 显示完整路径中的节点名；链接到 PG-05（`/factions?id=<id>`）；为空显示「—」 | 人物→势力 |
| 境界 | 主境界 + 子层级 | `帝境·五重天`；为空「—」；只读 | 人物→体系节点 |
| 榜单 | 所在榜单 + 席位 | 最多 2 条：`封神榜·第3席`；更多 `+N`；链接到 PG-09（`/rankings?id=<id>`）；为空「—」 | 榜单席位 |
| 待校对 | `review_status` / `reviewed_at` | Badge「待校对」；`review_status=pending` 时显示；确认后刷新为 `reviewed` 并记录 `reviewed_at`，Badge 消失 | 人物 DTO |
| 更新时间 | updated_at | `YYYY-MM-DD HH:mm`；可排序 | 系统 |
| 操作 | 查看 / 删除 | 「查看」链接；「删除」仅在行菜单，需走引用检查 | 操作 |

**排序**：

- 默认按更新时间倒序。
- 主名称、更新时间可排序；升/降箭头可见。
- 势力、境界、榜单不排序（避免多值/关联排序歧义）。

**筛选**：

- 搜索：当前列表内过滤，匹配主名称/别名/称号；300ms debounce；不触发全局检索。
- 势力/分支：树选择，含下级（默认）；选择后显示节点路径。
- 境界：树选择，可按主层级或子层级。
- 待校对：Checkbox；只看未确认，请求参数 `review_status=pending`；DTO 返回 `review_status`、`reviewed_at`。
- 筛选 AND 组合；活跃筛选 chip 可单独移除；「重置」清空。

**分页**：每页 20；显示总数；翻页保留筛选与排序；列表滚动到顶部。

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 新建人物 | 主按钮 | 打开 CharacterCreateDrawer；成功后进入 PG-03 |
| 行「查看」/主名称 | 链接 | 进入 PG-03（`/characters?id=<id>`） |
| 行「删除」 | 危险次操作（菜单） | 走引用检查；无引用确认后软删除 + Toast 撤销 |
| 筛选 / 排序 / 分页 | 次操作 | 刷新列表；不改变数据 |
| 重置 | 次操作 | 清空筛选；保留排序默认 |

- 列表页不提供批量删除（需求未要求）。
- 删除入口收进行尾「更多」菜单，避免误触；有引用时打开 ReferenceDialog。

## 6. 交互细节

1. 新建：Drawer 480/560px；字段见 PG-03 §4.1；保存成功关闭 Drawer → 进入详情；取消有修改时确认放弃。
2. 删除：确认 → 若被入向引用，ReferenceDialog 列出「势力首领」「榜单席位」（含回收站中的势力/榜单）；主操作禁用；可跳转。人物作为「势力成员」、地点关系、体系引用属于出向关系/附属数据，删除时自动解除或随人物软删除，不阻止；导入校对状态不是引用关系，不参与删除判定。无入向引用 → 确认「将进入回收站，可在 8 秒内撤销」。
3. 空列表：显示「还没有人物」+「新建第一个人物」+「从固定模板导入」；筛选无结果时显示「没有符合筛选的人物」+「清除筛选」。
4. 加载：表头保留 + 6 行 Skeleton；筛选与新建按钮可用。
5. 失败：表体内 Alert「人物列表加载失败」+ 重试；保留筛选。
6. 图片：缩略图先占位再加载；失败显示首字占位，不出现破图；不阻塞文字。
7. 切换作品：清空列表与筛选，重新请求；无作品时显示 PG-00 无作品状态。
8. 从详情返回：保留筛选、排序、页码；定位到原行（可选）。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Empty（无人物） | 页面级/表体空状态 + 新建 + 导入 |
| Empty（筛选无结果） | 「没有符合筛选的人物」+ 清除筛选 |
| Loading | 表头 + 6 行 Skeleton；按钮可用 |
| Error | 表体错误 + 重试；保留筛选 |
| Success | 表格 + 总数 + 分页 |
| Disabled | 删除确认中禁用；新建保存中禁用 |
| Pending | 行内 Badge「待校对」；不阻塞操作 |
| Network | 顶部 Alert + 表体错误；不进入离线模式 |

## 8. 校验与边界

- 主名称必填、同作品唯一；别名/称号允许重复；英文不区分大小写（FR-48）。
- 删除仅被「势力首领」「榜单席位」（含回收站中的引用）阻止；不能从列表绕过引用检查。作为势力成员、地点关系、体系引用不阻止，删除后自动解除/随人物软删除；导入校对状态不参与删除判定。
- 主图格式 jpg/png/webp、≤10MB；上传失败不写入。
- 空字段显示「—」，不显示空 chip、不编造文案。
- 1000 人物下列表 P95 ≤500ms；首屏 ≤2s；缩略图懒加载（AC-24/AC-32/AC-33）。
- 跨作品数据不出现；非法 URL 筛选值忽略并提示。
- 无权限状态 N/A。

## 9. 响应式

| 宽度 | 筛选栏 | 表格 | 列策略 |
|---|---|---|---|
| ≥1280 | 单行；搜索 280px | 最小 960px | 全列显示 |
| 1024–1279 | 搜索占一行，筛选第二行 | 横向滚动 | 别名/称号列可隐藏（Tooltip 查看） |
| <1024 | 同 1024 布局 + 桌面提示 | 横向滚动 | 不重排为卡片 |

- 操作列 sticky 右侧；表头与内容一起横向滚动。
- 图片缩略图不因窄屏放大。

## 10. 可访问性

- 表格 `<caption>` 或页面标题 + 总数；表头 `scope="col"`；可排序列 `aria-sort`。
- 主名称链接可键盘到达；行 hover 与 focus 都有可见反馈。
- 筛选 chip 移除按钮有 `aria-label`；Checkbox 有可见标签。
- 缩略图 `alt="人物主图：{主名称}"`；缺失占位 `role="img"` + 相同 alt。
- 加载 `aria-busy="true"`；错误用 `role="alert"`；分页按钮有明确 `aria-label`。
- 对比度按 design-system §8；待校对不只靠颜色。

## 11. 视觉与原型

- 以表格为主，不使用卡片墙；行高 44px；表头浅绿底；hover 行浅绿。
- 主名称与链接为主色；别名 chip 中性色；待校对 Warning Badge。
- 参照 `design-assets/prototype/index.html#search` 的列表密度与配色；本页不单独出原型。

## 12. 验收标准

- [ ] 默认按更新时间倒序；每页 20；总数显示。
- [ ] 搜索可匹配主名称/别名/称号；筛选势力（含下级）、境界、待校对；AND 组合可复现。
- [ ] 列展示主名称、别名/称号、势力、境界、榜单、更新时间；空值显示「—」。
- [ ] 待校对 Badge 按 `review_status=pending` 显示；确认后 `review_status/reviewed_at` 刷新且 Badge 消失。
- [ ] 新建人物 Drawer 可完成；保存后进入详情；取消有修改时确认。
- [ ] 删除走引用检查；仅「势力首领」「榜单席位」（含回收站中的引用）阻止并列出位置；出向关系自动解除；无引用软删除 + Toast 撤销。
- [ ] 缩略图懒加载；加载失败显示占位，不阻塞文字。
- [ ] 1000 人物下列表 P95 ≤500ms；无跨作品数据。
- [ ] 空/加载/错误/筛选无结果状态完整；无英文堆栈、无占位文本。
