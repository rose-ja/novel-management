## 1. 页面目标

- 默认进入、输入框自动聚焦，用户打开即能查。
- 只在当前作品内检索人物、势力、地点、榜单、体系节点；不检索大事记正文、不检索回收站、不跨作品。
- 快速搜索：单输入框，输入即搜；条件检索：关键词 + 条件筛选，AND 组合。
- 结果按类型分组，显示匹配字段摘要、出处与链接；无结果不编造。
- 不做自然语言理解、同义词、拼音、错字容忍、语义生成。

## 4. 字段与展示规则

### 4.1 搜索模式

| 模式 | 控件 | 触发 | 适用 |
|---|---|---|---|
| 快速搜索 | 单输入框 | 300ms debounce 自动检索；Enter 立即 | 日常查名称/别名/称号 |
| 条件检索 | 关键词 + 筛选 | 点击「检索」；Enter 提交 | 组合条件、按势力/境界/地点/榜单缩小范围 |

- 默认快速搜索；输入框自动聚焦。
- 切换模式不自动清空关键词；条件模式切换回快速模式时，筛选条件保留在面板内但不生效（或按 PG01-Q2 决策）。
- 空查询不发起请求；快速搜索允许 1 个字符。

### 4.2 检索字段与语义（对应 FR-28）

| 实体 | 可命中字段 | 关联实体名可命中 |
|---|---|---|
| 人物 | 主名称、别名、称号、简介 | 所属势力/分支、关联地点、所在榜单、体系节点 |
| 势力 | 名称、简介 | 上级势力、首领人物 |
| 地点 | 名称、类型、简介 | 上级地点、关联人物、关联势力 |
| 榜单 | 名称 | 在榜人物名 |
| 体系节点 | 节点名称、类别名称 | 父级节点名称 |

- 空格分词 + AND；每个词必须在同一实体的可命中字段或关联实体名中命中。
- 不做同义词、拼音、错字容忍、语义理解；不检索大事记正文。
- 英文不区分大小写；中文按子串匹配。
- 结果排序：名称命中 > 别名/称号命中 > 简介命中 > 关联实体名命中；同权重按更新时间倒序。
- 别名/称号重复时返回多条，显示实体类型 + 所属势力 + 主名称消歧。

### 4.3 结果行

| 元素 | 规则 |
|---|---|
| 类型分组 | 人物 → 势力 → 地点 → 榜单 → 体系节点；无结果的组不显示 |
| 组标题 | 类型名 + 总数 Badge；当前页内该组条数不单独标注（见 PG01-Q1） |
| 缩略图 | 人物 40×40 懒加载；其他类型使用类型线性图标 20px |
| 名称 | 实体主名称/节点名称；14px/500；可点击整行 |
| 待校对 | 仅人物/势力/地点/榜单/体系节点若未确认，显示 Warning Badge「待校对」 |
| 摘要 | 显示命中字段与片段：`主名称：司空摘天…` / `别名：摘天…` / `简介：…` / `所属势力：山海妖族`；匹配词高亮（浅绿底，不使用黄色荧光） |
| 元信息 | 人物：境界 · 势力 · 榜单；势力：上级 + 首领；地点：类型 + 上级；榜单：席位数 + 在榜人数；体系节点：类别 + 父级 |
| 链接 | 行尾箭头；整行可点击；键盘 Enter 打开 |
| 空字段 | 不显示空标签；不编造摘要 |

### 4.4 条件筛选

| 筛选项 | 控件 | 选项来源 | 生效范围 |
|---|---|---|---|
| 实体类型 | Select（单选） | 全部、人物、势力、地点、榜单、体系节点 | 全部 |
| 势力/分支 | TreeSelect（可搜索） | 当前作品势力树 | 仅人物 |
| 境界 | TreeSelect（可搜索） | 内置「境界」主层级 + 子层级 | 仅人物 |
| 地点 | TreeSelect（可搜索） | 当前作品地点树 | 仅人物 |
| 榜单 | Select（可搜索） | 当前作品榜单 | 仅人物 |

- 实体类型 = 全部时，仅显示关键词；人物相关筛选隐藏并清空生效值。
- 实体类型 = 人物时，显示全部上述筛选。
- 实体类型 = 势力/地点/榜单/体系节点时，仅显示关键词 + 实体类型；其他筛选隐藏。
- 条件 AND 组合；筛选值必须属于当前作品。
- 活跃筛选以 chip 展示，可单独移除；「重置」清空关键词 + 筛选。
- 筛选条件不影响排序规则。

### 4.5 分页

- 每页 20 条，**跨类型合计**；排序后统一分页，再按类型分组渲染当前页（PG01-Q1）。
- 组标题显示该类型的总命中数，便于判断是否还有更多。
- 不提供每页条数切换（Should 未纳入基线）。
- 翻页后保持关键词、模式、筛选；结果区滚动到顶部（不回到页面顶部）。

## 5. 主操作 / 次操作

| 操作 | 类型 | 行为 |
|---|---|---|
| 输入关键词 | 主交互 | 快速模式自动检索；条件模式等待「检索」 |
| 检索 | 主按钮（条件模式） | 提交条件；加载中禁用 + loading |
| 重置 | 次按钮 | 清空关键词与筛选；回到空查询提示 |
| 清除输入 | 图标按钮 | 清空关键词与结果；焦点回到输入框 |
| 结果行 | 链接 | 打开对应实体详情；保留检索状态供返回 |
| 分页 | 次操作 | 翻页；不改变筛选 |

- 每屏只有一个主按钮；快速模式无独立「检索」按钮（Enter 与自动检索即可）。
- 「排序说明」使用 Tooltip 或可展开小面板，不放独立页面。

## 6. 交互细节

1. 进入页面：输入框 autofocus；若从详情返回，恢复上次关键词/筛选/页码并把焦点放回输入框。
2. 输入：300ms debounce；连续输入合并请求；用请求序号丢弃过期响应，避免旧结果覆盖新结果。
3. Enter：立即检索；输入法组合中（`compositionstart`）不触发。
4. 加载：结果区 Skeleton 6 行；输入框可用；保留旧结果时可加轻微透明度，不闪烁空白。
5. 结果点击：整行可点击；鼠标 hover 浅绿；键盘 focus 可见；打开详情前若有未保存编辑（从其他页面返回的情况）先拦截。
6. 无结果：显示「未找到匹配条目」+ 关键词 chip + 建议「减少关键词或清除筛选」；提供「清除筛选」按钮。
7. 失败：结果区 Alert「检索失败，请重试」+ 重试；保留输入与筛选。
8. 空查询：显示提示与示例（如「试试：山海妖族 圣者境」）——示例只作为输入提示，不自动填充、不生成结果。
9. 切换作品：清空结果并重新请求；关键词保留；若新作品无数据，显示空结果提示。
10. 无作品：不显示搜索框？见 PG01-Q4；当前设计显示页面级空状态「先创建一本作品」，不显示结果区。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Empty（无作品） | 页面级空状态 +「新建作品」；搜索框禁用 |
| Empty（空查询） | 提示「输入名称、别名、称号或选择筛选条件」；不显示空表格 |
| Loading | 结果区 6 行 Skeleton；输入可用；按钮 loading（条件模式） |
| Success | 分组结果 + 总数 + 分页；结果行可点击 |
| NoResult | 「未找到匹配条目」+ 关键词/筛选 chip + 清除筛选 |
| Error | Alert「检索失败，请重试」+ 重试；保留输入 |
| Disabled | 空查询时条件「检索」禁用；无作品时搜索框禁用 |
| Network | 顶部 Alert + 结果区错误；不进入离线模式 |

## 8. 校验与边界

- 空查询：不请求；不显示「无结果」误导。
- 1 个字符允许；超长关键词（>200 字符）在输入框下方提示并阻止提交；上限由 P4 数据模型确认。
- 筛选值不属于当前作品：不出现于选项；URL 手改非法值 → 忽略并提示「筛选条件已失效」。
- 结果 ID 不存在/已删除/跨作品：跳转显示「内容不存在或已删除」+ 返回检索。
- 回收站数据不参与检索（FR-62）。
- 性能：1000 人物、本机 Docker、P95 ≤150ms；首屏可交互 ≤2s；UI 不得因图片阻塞文字（AC-23/AC-32/AC-33）。
- 错误文案不显示堆栈、SQL、内部 ID。

## 9. 响应式

| 宽度 | 搜索框 | 条件面板 | 结果 |
|---|---|---|---|
| ≥1280 | 最大 960px，44px 高 | 两列筛选；按钮右对齐 | 分组行；摘要单行省略 |
| 1024–1279 | 100% 宽，44px | 筛选单列；按钮右对齐 | 分组行；摘要最多 2 行 |
| <1024 | 100%，最小 1024 布局 | 单列；横向滚动 | 摘要 2 行；显示桌面端提示 |

- 结果行在窄屏不隐藏元信息，允许换行；不做移动端卡片重排。

## 10. 可访问性

- 搜索框有可见标签「检索关键词」（视觉上可作为标题/说明，不依赖 placeholder）。
- 自动聚焦不跳过 Skip Link；用户按 Tab 可离开。
- 结果组使用 `section` + `aria-labelledby`；结果行是链接而非 `div` 点击。
- 匹配高亮使用 `<mark>`；不只靠颜色，保留原文。
- 筛选 chip 的移除按钮有 `aria-label="移除筛选：势力/分支 山海妖族"`。
- 加载状态 `aria-busy="true"`；结果更新通过 `aria-live="polite"` 播报总数。
- 键盘：Enter 打开结果；Tab 可达分页；Esc 清空输入（焦点在输入框时，需确认不与 IME 冲突）。
- 对比度：摘要高亮底 `--color-brand-100` + 主文字 `#1B2A23`；不使用低对比灰字承载关键信息。

## 11. 视觉与原型

- 原型 `#search`：展示快速搜索、条件模式切换、分组结果、待校对 Badge、分页与当前作品副标题。
- 视觉基线：搜索框 44px；结果行 64px（含摘要两行）；组标题 15/22 600 + 数量 Badge；行 hover 浅绿。
- 不使用卡片包裹每条结果；不使用右侧栏。

## 12. 验收标准

- [ ] 默认进入检索页，输入框自动聚焦；空查询不请求。
- [ ] 输入 1 个字符可检索；300ms 自动检索；Enter 立即检索；IME 组合期间不误触发。
- [ ] 结果按人物/势力/地点/榜单/体系节点分组，显示匹配字段摘要、总数、出处、链接。
- [ ] 排序符合名称 > 别名/称号 > 简介 > 关联实体名；同权重按更新时间倒序。
- [ ] 每页 20 条；翻页保留关键词与筛选；返回检索保留状态。
- [ ] 条件检索 AND 组合；筛选只对人物生效；实体类型切换时非适用筛选隐藏。
- [ ] 无结果提示「未找到匹配条目」并建议减少关键词/清除筛选，不编造结果。
- [ ] 只返回当前作品数据；不检索回收站/大事记正文/其他作品。
- [ ] 加载/错误/空状态完整；错误有重试；无英文堆栈。
- [ ] 1000 人物下检索 P95 ≤150ms，首屏 ≤2s；图片缩略图懒加载不阻塞文字。
