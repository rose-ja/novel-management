## 1. 页面目标

- 将飞书资料一次性迁移到新的空作品：上传固定模板 Markdown + 图片 zip → 解析 → 校验 → 预览 → 确认 → 原子写入 → 导入报告 → 待校对。
- 预览阶段必须看到实体数量、错误清单、图片匹配情况；有错误禁止确认。
- 任一错误整批不写入；失败可修正文件后重跑；不做增量 upsert。
- 导入成功后**可校对实体**（人物、势力、地点、榜单、体系节点）标记「待校对」；提供按类型分组的校对清单，逐条确认或批量确认（需二次确认）。
- 导入只做一次性迁移来源，不依赖飞书、不做双向同步。

## 2. 布局

### 2.1 步骤条

```text
① 上传  →  ② 校验预览  →  ③ 确认导入  →  ④ 导入报告  →  ⑤ 校对清单
```

- 当前步骤主色；已完成步骤主色勾；有错误步骤红色数字；未到达步骤灰色。
- 已完成步骤可点击返回；未完成/有错误不可前进；返回上传会清空后续状态并确认。
- 导入进行中不可切换步骤。

## 4. 字段与展示规则

### 4.1 上传

| 字段 | 规则 |
|---|---|
| Markdown 文件 | `.md`；必须为固定模板；模板版本号必须匹配；单文件建议 ≤?（由 P4 定，UI 只提示） |
| 图片 zip | `.zip`；内的图片按 Markdown 相对文件名匹配；jpg/jpeg/png/webp；单图 ≤10MB；**zip 总大小上限 6GB**，超出在选择/开始校验时阻止 |
| 上传进度 | 上传中显示文件名、已上传/总大小与百分比；可取消；取消后清理临时文件 |
| 上传超时 | 单次导入上传/处理总时长上限 **120 分钟**；超时按失败处理并清理临时文件 |
| 模板版本 | 必须为 v1.0（当前模板）；版本不符进入错误清单 |
| 多文件 | 只接受 1 个 Markdown + 1 个 zip；多选覆盖或提示（PG11-Q1） |
| 拖拽/选择 | 均支持；选择后显示文件名与大小；可移除重新选择 |
| 模板/示例 | 提供下载；示例可被解析；文件来源为项目自产模板 |
| 目标作品 | 新建空作品；作品名来自 Markdown 的「作品信息」；同名全局冲突 → 错误 |

### 4.2 校验预览

| 区块 | 内容 | 规则 |
|---|---|---|
| 错误 Banner | 错误总数 + 「修正后重新上传」 | 有错误时红色；0 错误时绿色「校验通过」 |
| 文件摘要 | 文件名、大小、模板版本、图片数量 | 只读 |
| 实体数量 | 人物、势力、地点、榜单、体系节点、体系类别、大事记、图片、可校对实体合计 | 等宽数字；数量为 0 也显示；类别/大事记/图片不参与校对，但在此校验并在报告注明 |
| 错误清单 | 行号 + 字段/实体 + 原因 | 可滚动；每条定位；不显示堆栈 |
| 图片匹配 | 已匹配 / 缺失 / 多余 / 格式不支持 | 缺失/多余列出文件名；可折叠 |
| 目标摘要 | 新作品名、模板版本、原子写入、失败回滚、自动快照、导入后待校对 | 只读 |
| 确认导入 | 主按钮 | 有错误禁用 + 原因；0 错误可用 |

### 4.3 确认导入

- Dialog（560px）：
  - 标题「确认导入《X》？」
  - 说明「将创建新作品并原子写入 128 人物、22 势力、18 地点、3 榜单、45 体系节点、5 体系类别、210 大事记、96 张图片。任一步失败整批回滚，不留下半成品作品。导入前自动创建快照。」
  - 主按钮「确认导入」；次按钮「返回检查」。
- 提交后 Dialog 关闭或转为进度视图；按钮 loading；不可重复提交。
- 阶段进度：读取 → 解析 → 校验 → 图片匹配 → 写入 → 图片；每阶段 done/active/error；未知进度用不确定条。
- 成功后进入步骤 4；失败留在步骤 3/2，显示错误 + 重试；目标作品无半成品数据；失败清理临时文件与未完成目标作品。
- 磁盘空间不足或 120 分钟超时 → 错误摘要 + 「返回检查」；不自动重试，清理后可由用户重新上传。

### 4.4 导入报告

| 字段 | 规则 |
|---|---|
| 状态 | 成功/失败；成功显示绿色 Banner；失败显示错误摘要 |
| 文件名 | Markdown + zip 文件名；过长中间省略 + Tooltip |
| 模板版本 | v1.0 |
| 实体数量 | 人物/势力/地点/榜单/体系节点/体系类别/大事记/图片/可校对实体 |
| 图片数量 | 与 Markdown 引用一致 |
| 耗时 | 秒；1000 人物 ≤90s（AC-25） |
| 错误数 | 成功为 0；失败显示数量 |
| 时间 | `YYYY-MM-DD HH:mm` |
| 目标作品 | 新作品名；成功后当前作品切换（PG11-Q2） |
| 报告留存 | 页面可查看；导出文件为 Should，不在基线 |
| 校对范围 | 仅可校对实体（人物、势力、地点、榜单、体系节点）参与校对；类别、大事记、图片不参与校对，但已在预览校验并在报告注明 |
| 后续 | 「进入校对」「返回检索」 |

### 4.5 校对清单

| 字段 | 规则 |
|---|---|
| 待校对数量 | 全部未确认的**可校对实体**数（人物、势力、地点、榜单、体系节点）；分组显示 |
| 分组 | 人物、势力、地点、榜单、体系节点；按类型分组 |
| 行 | 名称 + 关键属性（境界/势力/上级/席位数/类别）+ 待校对 Badge + 确认 + 查看 |
| 确认 | 单条确认调用 `POST /{resource}/{id}/review`；成功后刷新 `review_status=confirmed` / `reviewed_at`，取消 Badge；Toast「已确认校对」 |
| 批量确认 | 二次确认「确认当前分组 N 项已校对？」；仅对 `pending` 项调用 `POST /reviews/batch`；成功后刷新对应 `review_status/reviewed_at` 并取消 Badge；已 `confirmed` 的项不重复提交 |
| 查看 | 进入对应详情（人物 `/characters?id=<id>`、势力 `/factions?id=<id>`、地点 `/locations?id=<id>`、榜单 `/rankings?id=<id>`）；详情也可确认；返回清单保留状态 |
| 记录 | 确认时间/操作人（唯一作者）留存；页面可查（PG11-Q3） |
| 未确认提示 | 列表/详情 Badge 持续显示；不阻塞其他操作 |
| 空状态 | 全部确认 → 「全部可校对实体已校对」+「返回检索」 |

## 5. 主操作 / 次操作

| 步骤 | 主操作 | 次操作 |
|---|---|---|
| 1 上传 | 开始校验 | 下载模板、下载示例、移除文件 |
| 2 校验预览 | 确认导入（0 错误） | 重新上传、查看错误、返回上传 |
| 3 确认导入 | 确认导入 | 返回检查 |
| 4 报告 | 进入校对 | 返回检索、查看报告 |
| 5 校对 | 确认当前条目 / 批量确认 | 查看详情、返回报告/检索 |

- 有错误时「确认导入」禁用并显示原因；不隐藏按钮。
- 导入进行中禁用步骤切换与重复提交。
- 「取消导入」在步骤 1/2 可用；步骤 3 进行中不可中断（除失败）。

## 6. 交互细节

### 6.1 上传与校验

1. 选择/拖拽文件 → 显示文件名、大小、类型；不合法类型立即提示；zip >6GB 或单图 >10MB 直接提示并阻止。
2. 上传中显示进度条与已上传/总大小；上传中断可重新选择文件；上传/处理超过 120 分钟 → 超时错误，清理临时文件。
3. 点击「开始校验」→ 步骤 2；显示解析进度（读取 → 解析 → 校验 → 图片匹配）。
4. 校验期间禁用「确认导入」；可返回上传。
5. 有错误：错误 Banner + 清单；确认按钮禁用；「重新上传」清空并提示重新选择（PG11-Q4）。
6. 0 错误：Banner「校验通过」；确认可用；摘要显示目标作品名。

### 6.2 确认导入

1. 点击「确认导入」→ ConfirmImportDialog；展示目标作品与数量。
2. 确认 → 进度视图；步骤条 ③ active；不可返回/关闭。
3. 成功 → 步骤 4；当前作品切换到新作品（PG11-Q2）；Toast「导入完成」。
4. 失败 → 错误摘要 + 「返回检查」/「重试」；原子回滚；目标作品不出现半成品；快照失败则阻止导入；失败后清理临时上传/解析文件。
5. 磁盘空间不足 → 错误摘要「磁盘空间不足，导入未执行/已回滚」；清理空间后可重新上传（可重试）；不自动重试。
6. 120 分钟超时 → 错误摘要「导入超时，已回滚并清理临时文件」；不自动重试；用户可修正后重新上传（可重试）。
7. 网络中断 → Alert + 重试；不重复写入。

### 6.3 校对

1. 步骤 5 分组列表；默认展开全部；显示可校对实体待校对数量 Badge。
2. 单条确认 → 调用 `POST /{resource}/{id}/review`；成功刷新 `review_status/reviewed_at`、Badge 消失；列表/详情同步；Toast。
3. 批量确认 → Dialog 显示分组与 `pending` 数量；仅对 pending 项调用 `POST /reviews/batch`；成功后全部刷新并取消；Toast「已确认 N 项」。
4. 查看 → 对应详情（查询参数路由）；详情页「确认已校对」；返回清单保留展开/滚动。
5. 失败 → 保留 Badge + 重试；并发修改 → ConflictDialog（页面只提示版本冲突）。
6. 全部确认 → 空状态；「返回检索」。

### 6.4 退出与重跑

- 步骤 1/2 离开 → DirtyGuard「导入尚未完成，离开将丢失当前校验结果？」。
- 步骤 3 进行中禁止离开/切换作品；浏览器关闭不可恢复（本版无草稿恢复）。
- 步骤 4/5 已写入成功，离开不丢数据；重新进入导入从步骤 1 开始，不自动续传。
- 修正文件后重新上传：创建新的空作品；不做增量 upsert（FR-42）。

## 7. UI 状态

| 状态 | 表现 |
|---|---|
| Empty（未上传） | 拖拽区 + 模板/示例下载；开始校验禁用 |
| Loading（上传） | 上传进度条 + 已上传/总大小；可取消；开始校验禁用 |
| Loading（解析/校验） | 阶段进度；步骤 2 骨架；确认禁用 |
| Error（校验错误） | 错误 Banner + 清单；确认禁用；重新上传 |
| Error（导入失败） | 失败报告 + 错误摘要 + 重试；原子回滚；临时文件清理 |
| Error（磁盘不足） | Alert「磁盘空间不足，导入未执行/已回滚」；清理空间后可重试；不自动重试 |
| Error（超时） | Alert「导入超时（上限 120 分钟），已回滚并清理」；不自动重试；可重新上传 |
| Success（导入完成） | 绿色 Banner + 报告 + 进入校对 |
| Success（校对完成） | 空状态「全部可校对实体已校对」 |
| Disabled | 有错误/上传中/写入中禁用确认；批量确认中禁用 |
| Network | 顶部 Alert + 重试；保留文件与错误状态 |
| Snapshot failure | 阻止导入；Alert「快照创建失败，未执行导入」 |

## 8. 校验与边界

| 错误 | 触发 | 展示 | 结果 |
|---|---|---|---|
| 模板版本不符 | 版本号缺失/不匹配 | 错误清单 | 禁止确认 |
| 未知区块/字段缺失 | 模板结构不符 | 行号 + 字段 | 禁止确认 |
| 主名称重复 | 同作品同类型重名 | 行号 + 冲突对象 | 禁止确认 |
| 引用无法解析 | 势力/人物/榜单/节点引用不存在 | 行号 + 引用名 | 禁止确认 |
| 图片缺失 | Markdown 引用但 zip 无 | 文件名清单 | 禁止确认 |
| 图片多余 | zip 有但未被引用 | 文件名清单 | 警告或错误？按需求「多余进入错误清单」→ 禁止确认 |
| 图片格式不支持 | 非 jpg/png/webp | 文件名 + 原因 | 禁止确认 |
| 单图 >10MB | 大小超限 | 文件名 + 大小 | 禁止确认；需压缩后重传 |
| zip >6GB | zip 总大小超限 | 文件名 + 大小 + 上限提示 | 禁止上传/确认；需拆分或压缩后重传（不可重试原文件） |
| 作品重名 | 新作品名与现有作品冲突 | 摘要 + 错误 | 禁止确认；改名后重试 |
| 字段超长 | 超过数据模型上限 | 行号 + 字段 | 禁止确认 |
| 写入失败 | 磁盘/权限/并发 | 错误摘要 | 原子回滚；无半成品；清理临时文件 |
| 磁盘空间不足 | 预检或写入时空间不足 | Alert + 错误摘要 | 原子回滚、无半成品残留；清理空间后重新上传（可重试） |
| 120 分钟超时 | 上传/处理超时 | Alert + 错误摘要 | 回滚并清理临时文件；不自动重试；可重新上传 |
| 快照失败 | 导入前快照失败 | Alert | 阻止导入；不自动重试，排查后重试 |
| 网络中断 | 服务不可达 | 顶部 Alert + 重试 | 不重复写入；可重试 |

- 错误不允许静默跳过（FR-51）；每条可定位到行/字段/图片。
- 预览数量必须与写入后报告一致；不一致视为失败。
- 预览/报告包含「体系类别」计数；类别、大事记、图片不参与校对，但在预览校验并在报告注明。
- 1000 人物导入 ≤90s（AC-25）；进度阶段可见；zip 上限 6GB；处理超时上限 120 分钟。
- 权限不足 N/A；不显示堆栈/内部 ID。

## 9. 响应式

| 宽度 | 主栏 | 右侧摘要 | 错误清单 |
|---|---|---|---|
| ≥1280 | 720px | 320px | 最大高 240px，滚动 |
| 1024–1279 | 全宽 | 摘要移到主栏下方 | 同 |
| <1024 | 最小 1024，横向滚动 + 提示 | 同 1024 | 同 |

- Stepper 在窄屏不改为纵向；允许横向滚动。
- 表格/错误清单不改为卡片；文件名可换行。

## 10. 可访问性

- Stepper 使用列表 + `aria-current="step"`；已完成步骤可点击；不可用步骤 `aria-disabled`。
- 拖拽区同时支持键盘点击选择；不能只依赖拖拽。
- 错误清单使用列表语义；每条包含行号/字段/原因的文本，不只靠颜色。
- 进度 `role="progressbar"` + `aria-valuenow`/`aria-valuetext`；阶段文字同步播报。
- 确认 Dialog 焦点陷阱；导入进行中禁止 Esc 关闭；完成后焦点回到主按钮。
- 校对确认按钮有 `aria-label="确认人物 司空摘天 已校对"`。
- 批量确认 Dialog 显示数量；确认后 Toast `aria-live`。
- 对比度按 design-system §8；错误红色不只靠颜色，配图标与文字。

## 11. 视觉与原型

- 原型 `#import`：展示步骤 2 校验预览（含 2 个错误、图片缺失、确认禁用、右侧摘要），用于验证错误阻断态。
- 视觉基线：Stepper 主色/错误色；错误清单浅红底；确认按钮禁用；右侧摘要 320px；数量等宽。
- 不使用进度大圆环、装饰插画或飞书品牌元素。

## 12. 验收标准

- [ ] 上传固定模板 Markdown + 图片 zip；zip 上限 6GB；非模板在预览阶段报错、不导入。
- [ ] 上传显示进度；120 分钟超时、磁盘空间不足有明确错误与重试边界。
- [ ] 预览显示实体数量（含体系类别）、错误清单、图片匹配；有错误时确认禁用。
- [ ] 错误覆盖缺版本、未知区块、字段缺失、重复名称、引用无法解析、图片缺失/多余/格式不支持/超限。
- [ ] 确认后原子写入新作品；任一错误整批回滚；目标作品无半成品。
- [ ] 导入报告显示数量（含体系类别）、图片、耗时、时间、文件名；报告留存。
- [ ] 导入后全部可校对实体（人物、势力、地点、榜单、体系节点）「待校对」；校对清单按类型分组；逐条调用 `POST /{resource}/{id}/review`、批量仅对 pending 调用 `POST /reviews/batch`；Badge 消失并刷新 `review_status/reviewed_at`。
- [ ] 未确认实体在列表/详情有提示；校对记录留存。
- [ ] 导入前自动快照；快照失败阻止导入。
- [ ] 1000 人物导入 ≤90s；进度阶段可见。
- [ ] 退出/返回/网络中断有确认与恢复；不重复写入。
- [ ] 无英文堆栈、无占位文本；步骤条与按钮状态完整。
