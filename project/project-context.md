# Project Context — 小说设定管理系统

> 阶段：P1 资料整理（模板对齐版）
> 日期：2026-11-07
> 用途：跨阶段共享的最小上下文；细节链接到权威文档，不替代 `requirements.md`。

## 项目目标

- 让个人作者在一个本地优先的结构化系统中管理多本小说的独立世界观。
- 做到「输入任意名称、别名或称号即可查到完整设定」与「改一处全局同步」。
- 完成飞书《正文》与文档内现有配图的一次性迁移，并支持人工校对。
- 用本地零成本方式替代飞书日常查阅；本版不做公网、协作、AI 生成或写作功能。

## 目标用户与场景

- 主用户：项目发起人本人；会同时构思多本小说、每本拥有独立世界观的个人作者。
- 使用环境：Windows + Docker Desktop；桌面浏览器最新版 Chrome / Edge；中文界面。
- 核心场景：查人物（S1）、维护一致性（S2）、新建作品（S3）、维护榜单（S4）、迁移校对（S5）、关键词组合检索（S6）、备份恢复（S7）。
- 本版非目标用户：普通读者、协作者、其他公开注册作者。

## 当前 MVP 范围

- 多作品管理；人物、势力与地点、榜单、体系四类对象结构化。
- 当前作品内检索（快速 + 条件）；关系双向跳转；一致性维护。
- 飞书《正文》+现有配图迁移：产品内向导、固定 Markdown 模板 + 图片 zip、校验/预览/原子导入、可校对实体（人物/势力/地点/榜单/体系节点）待校对。
- 全量导出 zip、CLI 还原、自动快照保留 3 份；回收站与撤销。
- 本地 Docker 单用户运行；容器内监听 `0.0.0.0`，宿主发布端口仅绑定 `127.0.0.1`。
- 明细见 `mvp-scope.md` 与 `requirements.md` 第 9 章。

## 当前技术栈

- 已确认（P4，2026-11-07）：Go 1.26 + gin + gorm + Next.js 15 + PostgreSQL 16 + Redis 7（仅缓存）。
- 部署：Docker Compose 三容器（app/db/cache），宿主仅通过 `127.0.0.1:17860` 回环访问（容器内绑定 `0.0.0.0`）。
- 约束：不调用云端大模型；不引入持续付费依赖；Redis 故障自动旁路。
- 详见 `tech-stack.md`、`architecture.md`、`deployment.md` 与 `adr/ADR-001~007`。

## 系统边界

- 产品边界：设定资料库 + 检索与一致性工具；不是写作工具、图谱工具、协作平台或 AI 生成工具。
- 数据边界：作品是数据边界；所有实体只属于一本作品；第一版禁止跨作品引用与跨作品检索。
- 使用边界：单用户、本地、桌面浏览器；本版无登录、无角色、无用户表。
- 迁移边界：飞书仅作一次性迁移来源；不做运行时依赖与双向同步；素材库不纳入本版。

## 已确认约束

- 单用户；本地 Docker；桌面浏览器；未来公网部署必须增加访问控制，本版不实现。
- 零成本优先：不采购云服务器、域名、对象存储或付费 API；不调用云端大模型。
- 数据本地存储，按私密数据处理；必须可导出/备份；全量导出、CLI 还原、快照保留 3 份为 Must。
- 中文界面、浅绿色渐变、简洁、信息优先；不做移动端专门适配。
- 数据规模：单作品 1000 人物、200 势力节点、200 地点、5 榜单 ×100 席、10 类体系、150 体系节点、500 图片；作品 ≤10。
- 性能：检索 P95 ≤150ms、列表 ≤500ms、保存 ≤300ms、导入 ≤90s、图片上传 ≤1s、首屏可交互 ≤2s（硬验收）。
- 体系类别按作品自定义（≤10 类，含内置「境界」）；星曜/星命/圣体等名称不得写死。
- 榜单席位 1–200（默认 100）；不做并列；只扩容、缩容仅尾部全空。
- 英文名称唯一性校验与检索不区分大小写。

## 已知风险

| 备份/恢复失败（R-03） | 数据永久丢失 | 导出 + CLI 还原 + 快照 3 份 + 恢复演练 |

| 模板整理成本（P-03a） | 迁移耗时 | 提供模板/示例/校验预览；不承诺兼容任意排版 |

## 已确认事实

- 飞书《正文》是世界观设定集，包含纪元、地理、体系、三张榜单、万族传、人物与配图。
- 三张榜单在飞书为 1–100 固定席位，目前基本为空；产品支持 1–200 席（默认 100）。
- 人物是多值实体：本名、化名、称号、境界（含重天等子层级）、势力/分支；已有真实人物配图。
- 势力存在层级：万族 → 族 → 分支，分支下有首领与成员。
- 当前资料依靠标题层级、括号备注与列表混合表达，没有统一字段。
- 项目发起人已确认：单用户、本地 Docker、零成本、中文、桌面优先、仅迁移《正文》+现有配图、备份/导出为 Must、体系类别自定义、榜单 1–200、首屏 ≤2s 硬验收。
