## 1. Sitemap

```text
应用壳层（全局）
├─ 顶栏：Logo + 产品名 + 作品切换器 + 本机状态
├─ 侧栏：资料 / 工具两组导航
├─ 全局浮层：作品菜单、确认/引用/冲突对话框、新建抽屉、Toast
│
├─ 检索（PG-01，/search）                 ← 默认首页
├─ 人物
│   ├─ 人物列表（PG-02，/characters）
│   └─ 人物详情（PG-03，/characters?id=<id>）   ← 列表 / 检索结果 / 关系链接
├─ 势力
│   ├─ 势力树/列表（PG-04，/factions）
│   └─ 势力详情（PG-05，/factions?id=<id>）     ← 树 / 检索结果 / 关系链接
├─ 地点
│   ├─ 地点树/列表（PG-06，/locations）
│   └─ 地点详情（PG-07，/locations?id=<id>）    ← 树 / 检索结果 / 关系链接
├─ 榜单
│   ├─ 榜单列表（PG-08，/rankings）
│   └─ 榜单详情（PG-09，/rankings?id=<id>）     ← 列表 / 人物详情
├─ 体系配置（PG-10，/system）
├─ 导入向导（PG-11，/import）
├─ 回收站（PG-12，/trash）
└─ 设置/备份（PG-13，/settings）
```

- **路由约定**：所有详情页使用查询参数 `?id=<id>`；列表、检索结果、关系链接、面包屑与深链统一使用该形式，不出现路径参数动态段。
- 无仪表盘、无独立编辑页、无移动端页面、无用户/角色/权限页面。
- 作品切换器不是独立页面，是顶栏浮层（PG-00）。
- 详情页的「编辑」在同一页面展开内联编辑；新建实体使用右侧 Drawer，不新增路由。
- 回收站是全局页面，跨作品展示；其余内容页面只展示当前作品数据。

- 一级：侧栏 9 个入口（检索、人物、势力、地点、榜单、体系、导入、回收站、设置/备份）。

## 2. 角色与权限

| 角色 | 是否存在 | 可见范围 | 可执行操作 |
|---|---|---|---|
| 作者（唯一用户） | 是 | 全部页面与全部作品 | 全部功能 |
| 只读访客 | 否 | N/A | N/A |
| 协作者 | 否 | N/A | N/A |
| 其他注册作者 | 否 | N/A | N/A |

- 本版无登录页、无用户表、无角色判断、无权限提示。
- 仅本机可访问：`http://127.0.0.1:17860`；局域网其他设备不可访问。
- 「权限不足」状态在本版记为 N/A；页面不设计权限拒绝视图。
- 所有页面默认私有、本地；导出包与快照包含完整内容，由用户自行保管。

## 3. 核心用户流程

> 约定：每个流程包含成功、取消/返回与异常分支。按钮文案与 Page Spec 一致。流程不新增需求中的业务功能。

### UF-01 首次启动与创建第一本作品

**触发**：本地服务启动，浏览器打开应用；当前无作品。

1. 应用进入检索页（PG-01）；因无作品，内容区显示页面级空状态：
   - 标题「先创建一本作品」
   - 说明「作品是数据与检索的边界。每本小说拥有独立的人物、势力、地点、榜单与体系。」
   - 主操作「新建作品」；次操作「查看使用说明」（如无说明页则不出现，见待确认）。
2. 点击「新建作品」→ 打开 `WorkCreateDialog`（560px）：
   - 作品名称（必填、全局唯一、去首尾空格）
   - 简介（可选、纯文本）
   - 主操作「创建作品」；次操作「取消」
3. 成功：Toast「作品已创建」；自动切换到新作品；进入 PG-10 体系配置，并显示一次性提示「已自动创建内置「境界」类别，可继续添加自定义类别」。
4. 取消：关闭对话框，停留空状态；不创建数据。
5. 异常：
   - 名称为空 → 字段错误「请输入作品名称」，主操作保持可用但提交被阻止。
   - 名称重复 → 字段错误「作品名称已存在，请换一个名称」，显示冲突对象名称。
   - 请求失败 → 对话框内 Alert「保存失败，请重试」+ 重试；保留输入。
   - 快照/创建失败 → 不产生半成品作品；显示原因。
6. 返回：创建后可从体系页通过侧栏进入其他页面；不强制完成体系配置。

**对应**：FR-01、FR-02、FR-65；US-001；AC-01。

### UF-02 切换、编辑与删除作品

**切换**

1. 点击顶栏作品切换器 → 菜单列出全部作品（≤10；数量多时可按名称搜索，Should）。
2. 当前作品高亮 + 勾选；菜单底部「新建作品」。
3. 选择另一作品：
   - 若无未保存修改 → 立即切换，Toast「已切换到《作品名》」，当前页面数据刷新；检索页保留关键词但结果重新请求（只查新作品）。
   - 若有未保存修改 → Dialog「放弃未保存的修改？」→「放弃并切换」/「继续编辑」。
4. 取消：关闭菜单，保持当前作品。
5. 异常：作品列表请求失败 → 菜单内错误 + 重试；不显示其他作品数据为当前作品。

**编辑**

1. 作品菜单中「编辑作品」→ `WorkEditDialog`：名称、简介。
2. 名称唯一校验；保存成功 Toast；当前作品名同步到顶栏与页面副标题。
3. 取消：关闭，不保存。
4. 异常：重名、空名称、请求失败；同 UF-01。

**删除**

1. 菜单中「删除作品」→ `DeleteWorkDialog`：
   - 说明「将整本作品及其人物、势力、地点、榜单、体系、大事记移入回收站；删除前会自动创建快照。」
   - 输入作品名称确认；主按钮「删除作品」（danger）。
2. 成功：Toast「已移入回收站」+「撤销」（8s）；若删除当前作品，自动切换到另一作品；无其他作品则进入无作品空状态。
3. 取消：关闭，不删除。
4. 异常：
   - 输入名称不匹配 → 主按钮禁用 + 提示「请输入完整作品名称」。
   - 快照失败 → 阻止删除，Alert「快照创建失败，未执行删除」+ 重试。
   - 删除失败 → 保留作品，Toast/Alert 说明原因。

**对应**：FR-02、FR-55、FR-57~FR-60；US-001、US-011；AC-13。

### UF-03 快速检索并跳转

**触发**：默认进入 PG-01；输入框自动聚焦。

1. 输入关键词（允许 1 个字符）；300ms 后自动检索，或按 Enter 立即检索。
2. 空查询：不发起请求，显示提示「输入名称、别名、称号或选择筛选条件」。
3. 加载：结果区 Skeleton；输入框与按钮保持可用；避免重复提交（同一查询合并）。
4. 成功：结果按实体类型分组（人物、势力、地点、榜单、体系节点）；组头显示**组总命中**，列表只显示当前页切片；每条显示名称、类型、命中字段标签（名称/别名/称号/简介/关联实体）与 `matched_text` 高亮、所属势力（人物）、待校对标记（如有）、链接；分页按 `score DESC, updated_at DESC, id ASC` 稳定排序。
5. 点击结果 → 对应详情页（`/characters?id=<id>` 等查询参数路由）；详情页关系链接可继续跳转。
6. 无结果：显示「未找到匹配条目」+ 当前关键词 + 建议「减少关键词或清除筛选」；不生成不存在的内容。
7. 失败：结果区错误「检索失败，请重试」+ 重试；保留输入。
8. 返回：从详情页返回检索页，保留关键词、模式、筛选与分页；结果可重新请求。
9. 取消：清除输入 → 回到空查询提示；不保留结果。

**关键约束**：只在当前作品内检索；不检索回收站；不检索大事记正文；不做同义词/拼音/错字容忍/语义理解。

**对应**：FR-27~FR-33；US-007；AC-08、AC-23、AC-32。

### UF-04 条件检索

1. 检索页切换「条件检索」；默认关键词为空，实体类型为「全部」。
2. 选择实体类型：
   - 「全部」：只显示关键词；势力/境界/地点/榜单筛选隐藏（只对人物生效）。
   - 「人物」：显示势力/分支、境界、地点、榜单筛选。
   - 「势力 / 地点 / 榜单 / 体系节点」：显示关键词 + 实体类型；非适用筛选隐藏。
3. 输入关键词与筛选（AND 组合）；点击「检索」执行。
4. 成功：结果按类型分组；筛选条件以 chip 显示在结果上方；组头显示组总命中，列表只显示当前页切片。
5. 无结果：提示 + 「清除筛选」；保留关键词。
6. 失败：错误 + 重试；保留筛选。
7. 取消/重置：点击「重置」清空关键词与筛选，回到快速搜索模式（或保持条件模式空状态，见 PG-01 决策）。
8. 返回：详情返回后保留条件检索状态。

**对应**：FR-32；US-007；AC-08。

### UF-05 新建、编辑与删除人物

**新建**

1. PG-02 人物列表 →「新建人物」→ 右侧 Drawer（480/560px）。
2. 字段顺序：主名称（必填）→ 别名 → 称号 → 所属势力/分支 → 境界（主层级 + 可选子层级）→ 其他已启用体系类别（每类 0..1）→ 关联地点 → 主图 → 简介 → 大事记。
3. 保存：
   - 成功 → 关闭 Drawer，Toast「人物已创建」，进入 PG-03 人物详情。
   - 失败 → 字段级错误；保留输入；不关闭 Drawer。
4. 取消/关闭：
   - 无修改 → 直接关闭。
   - 有修改 → Dialog「放弃未保存的修改？」→ 放弃/继续编辑。
5. 异常：主名称为空、同作品重名、图片格式/大小、引用不存在、字段超长；均在字段级提示；不写入半成品。

**编辑**

1. PG-03 详情 →「编辑」→ 页面主体切换为内联编辑（同一路由，不跳独立页）。
2. 修改主名称/势力/境界/其他类别/图片/简介/大事记。
3. 保存成功 → Toast「已保存」；页面刷新；所有关联页面与检索结果同步（改名、换势力、改境界）。
4. 取消 → Dialog「放弃未保存的修改？」→ 放弃恢复原值 / 继续编辑。
5. 并发冲突 → Dialog「数据已被其他页面修改，请刷新后重试」；保留用户输入；刷新后重新编辑。
6. 未保存离开 → 侧栏跳转、切换作品、打开其他实体前均拦截。

**删除**

1. 详情「更多」→「删除人物」。
2. 系统检查入向引用：
   - 仅「势力首领」「榜单席位」（含回收站中的势力/榜单）阻止 → `ReferenceDialog`（720px）列出引用类型、名称、位置；主操作禁用；提供跳转；回收站中的引用显示「回收站中」徽标 +「查看回收站」链接。
   - 人物作为「势力成员」、地点关系、体系引用属于出向关系/附属数据，不阻止删除，自动解除或随人物软删除；导入校对状态不是引用关系，不参与删除判定。
   - 无入向引用 → `DeleteConfirmDialog`「删除人物「X」？」说明「将进入回收站，可在 8 秒内撤销」。
3. 确认 → Toast「已移入回收站」+「撤销」；列表与检索立即隐藏。
4. 撤销 → 回到原位置；Toast「已恢复」。
5. 取消 → 不删除。
6. 异常：删除请求失败 → Alert + 重试；快照失败（如涉及）→ 阻止并说明。

**对应**：FR-04~FR-08、FR-59、FR-60；US-002、US-011；AC-02、AC-03、AC-14、AC-33。

### UF-06 势力树维护

1. PG-04 势力树：默认展开两级；搜索节点名称定位；点击节点 → PG-05。
2. 新建节点：点击「新建势力节点」→ 页内内联新建面板或 Drawer：
   - 上级（可空、树选择、可搜索；禁止选择自身/后代）
   - 名称（必填、同作品唯一）
   - 简介（可选）
3. 保存 → Toast；树刷新并选中新节点；进入详情或停留列表（见 PG-04 决策）。
4. 取消 → 有修改时确认放弃。
5. 详情编辑：名称、上级（移动）、简介；保存后成员展示与关系链接同步。
6. 设置首领：在详情选择当前作品人物（0..1，可空）；保存后首领可点击。
7. 成员：由人物归属自动推导；切换「仅直属 / 含下级」。
8. 删除：
   - 有下级节点或人物归属成员 → ReferenceDialog 列出引用；阻止。
   - 首领人物、地点关联属于出向关系/附属数据，不阻止，随势力删除隐藏或自动解除；导入校对状态不是引用关系，不参与删除判定。
   - 无入向引用 → 确认删除 → 回收站 + Toast 撤销。
9. 移动成环：父级选择自身/后代 → 选项禁用 + 说明「不能移动到自身或自己的后代」。
10. 恢复：回收站恢复时父级已删 → 阻止并提示「请先恢复上级势力」。

**对应**：FR-09~FR-12；US-003；AC-04、AC-14。

### UF-07 地点树维护

1. PG-06 地点树：父子层级；类型筛选；搜索；点击 → PG-07。
2. 新建节点：上级（可空）、名称（必填、唯一）、类型（自由文本 + 已有值建议）、简介（可选）。
3. 详情：上级、下级、关联人物（0..N，带备注）、关联势力（0..N，带备注）、简介；双向可跳转。
4. 删除：有下级地点、人物关联、势力关联 → 阻止 + 引用列表，并提供引用跳转；不级联解除关系；无引用 → 确认 → 回收站。
5. 恢复：父级已删 → 阻止并提示先恢复父级。
6. 本版不做地点图片、地点不引用体系。

**对应**：FR-13~FR-16；US-004；AC-05、AC-14。

### UF-08 榜单与席位维护

**新建榜单**

1. PG-08 榜单列表 →「新建榜单」→ Dialog（560px）：
   - 名称（必填、同作品唯一）
   - 席位数（1–200，默认 100）
   - 主操作「创建榜单」
2. 成功 → Toast；进入 PG-09 详情。
3. 异常：名称为空/重复、席位数越界、请求失败；字段级提示。

**指派人物**

- 席位表每页固定 50 席；请求固定 `page_size=50`；跳席页码按 50 计算。

1. 详情中点击空席「指派」→ `CharacterPickerDialog`：
   - 搜索当前作品人物（姓名/别名/称号）
   - 选中后显示人物摘要（势力、境界）
   - 主操作「指派到第 N 席」
2. 保存 → 席位显示人物；Toast「已指派」。
3. 同一人物已在本榜其他席 → 阻止：「该人物已在第 N 席，请先移出或与目标席位交换」。
4. 取消 → 不改变席位。

**移动 / 交换**

1. 已占席位行操作「调整席位」→ Dialog：
   - 输入目标席位号（1..N）
   - 目标为空 → 显示「移动到第 N 席（空席）」
   - 目标已占 → 显示「与第 N 席「人物名」交换」
2. 确认 → 两席更新；Toast「已调整席位」；人物详情名次同步。
3. 异常：目标越界、目标为自身、同榜重复人物；阻止并提示。
4. 取消 → 不改变。

**移出榜单**

1. 行操作「移出榜单」→ 确认 Dialog「将「人物名」移出第 N 席？该席变为空席。」
2. 确认 → Toast「已移出」+ 撤销（可选）；人物详情不再显示该榜。
3. 取消 → 不改变。

**扩容 / 缩容**

1. 详情「扩容」→ Dialog 输入新增席位数；结果 = 当前 N + 新增，≤200。
2. 「缩容」→ Dialog 输入目标席位数；仅当尾部席位全空。
3. 尾部有人 → ReferenceDialog 列出占用人（席位号 + 人物名 + 链接）；阻止。
4. 成功 → Toast；席位表刷新。
5. 删除榜单 → 确认 Dialog → 整张进回收站；恢复时原席位人物已删除 → 阻止并提示先恢复人物。

**对应**：FR-17~FR-20；US-005；AC-06、AC-14。

### UF-09 体系配置

1. PG-10 左侧类别列表：
   - 内置「境界」固定置顶，标记「必开 / 内置」；不可停用/删除/改名。
   - 自定义类别显示类型（普通/纪元）、启用状态、节点数、被引用数。
   - 顶部显示「x/10 类」。
2. 新增类别 → Dialog：
   - 名称（必填、同作品唯一、英文不区分大小写）
   - 类型「普通 / 纪元」（创建后不可更改）
   - 成功 → 类别列表刷新；人物表单立即出现对应字段。
   - 超过 10 类 → 阻止并提示上限。
3. 改名类别 → 内联/ Dialog；成功 → 所有引用处与检索结果同步。
4. 停用类别：
   - 先查引用；有引用 → ReferenceDialog 列出数量与位置；阻止。
   - 无引用 → 确认「停用后人物表单不再显示该字段，已有数据保留，可重新启用」；成功 → 状态变「已停用」。
5. 删除类别：
   - 有引用 → 阻止 + 引用列表。
   - 无引用 → 确认 Dialog「删除类别「X」及其下 N 个节点？将整组进入回收站，可整组恢复。」
   - 成功 → 类别与节点从列表/表单/检索隐藏；Toast 撤销；回收站显示为一条类别项。
6. 节点树（右侧）：
   - 最多两级；主层级 + 子层级；同级排序（上移/下移）。
   - 新增节点：名称（必填、同一类别+同一父级下唯一）；纪元类型可填起始/结束年份文本（自由文本，不计算）。
   - 改名 → 引用处同步。
   - 体系节点属于可校对实体；导入后 `review_status=pending` 显示 Badge，可「仅看待校对」筛选并确认。
   - 删除节点：被人物引用 → 阻止 + 列出人物；无引用 → 确认 → 回收站。
   - 恢复节点：类别或父级缺失 → 阻止并提示先恢复。
7. 每个节点显示「被 N 人引用」；被引用节点不能删除。
8. 失败/并发/网络：字段级错误、Alert + 重试；不写入半成品。

**对应**：FR-21~FR-26；US-006；AC-07、AC-13、AC-14。

### UF-10 飞书迁移导入

1. PG-11 步骤 1「上传」：
   - 拖拽或选择：固定模板 Markdown（.md）+ 图片 zip（.zip）；zip 上限 6GB，超出阻止
   - 提供「下载模板」「下载示例」；说明模板版本与图片相对路径规则
   - 上传显示进度；上传/处理超过 120 分钟按超时失败并清理临时文件；磁盘空间不足给出错误
   - 主操作「开始校验」；次操作「取消」
2. 步骤 2「校验预览」：
   - 显示模板版本、目标新作品名称、各类实体数量（含体系类别）、图片匹配情况
   - 错误清单按 Markdown 行号/字段定位；图片缺失/多余清单
   - 有错误 → 「确认导入」禁用 + 原因；可重新上传
   - 无错误 → 「确认导入」可用
3. 步骤 3「确认导入」：
   - Dialog 说明「将创建新作品《X》，原子写入；任一步失败整批回滚，不留半成品。」
   - 确认后显示阶段进度：读取 → 解析 → 校验 → 图片匹配 → 写入 → 图片
   - 成功 → 步骤 4；失败 → 留在步骤 2/3，显示错误 + 重试；不创建作品；磁盘不足/超时不自动重试，清理后可重新上传
4. 步骤 4「导入报告」：
   - 文件名、作品名、实体数量（含体系类别）、图片数量、耗时、错误数、时间
   - 类别/大事记/图片不参与校对，但已在预览校验并在报告注明
   - 报告留存可查看
   - 主操作「进入校对」；次操作「返回检索」/「导出报告」（Should，不在基线）
5. 步骤 5「校对清单」：
   - 按人物/势力/地点/榜单/体系节点分组；显示**可校对实体**待校对数量
   - 逐条进入详情确认，调用 `POST /{resource}/{id}/review`；确认后刷新 `review_status/reviewed_at`、Badge 消失
   - 「批量确认」需二次确认，显示将确认的 pending 数量，仅对 pending 调用 `POST /reviews/batch`
   - 全部可校对实体初始为「待校对」；未确认在列表/详情有提示
6. 退出：导入进行中退出/切换作品 → 确认「导入尚未完成，离开将丢失当前校验结果？」；已写入成功后离开不丢数据。
7. 失败重跑：修正 Markdown/zip 后重新上传到新的空作品；不做增量 upsert。

**对应**：FR-39~FR-46；US-009；AC-10、AC-11、AC-18~AC-21、AC-25。

### UF-11 迁移后校对

1. 从 PG-11 步骤 5 或侧栏「导入」进入校对清单。
2. 分组显示待校对数量；点击条目 → 对应详情页。
3. 详情页显示「待校对」Badge；点击「确认已校对」调用 `POST /{resource}/{id}/review`，成功后刷新 `review_status/reviewed_at`、Badge 消失；列表/检索同步。
4. 批量确认 → Dialog「确认 N 个实体已校对？」→ 仅对 pending 调用 `POST /reviews/batch` → 成功刷新状态、Toast；记录留存。
5. 未确认实体在列表/详情持续提示；不阻塞其他操作。
6. 取消：返回清单；不改变标记。
7. 异常：确认请求失败 → 保留 Badge + 重试；并发修改 → 冲突提示。

**对应**：FR-44；US-009；AC-21。

### UF-12 删除、回收站与恢复

1. 任意实体删除 → 先检查引用（UF-05/06/07/08/09 对应分支）。
2. 无引用 → 确认 → 软删除 → Toast 撤销；列表、检索、关系跳转立即隐藏。
3. PG-12 回收站：
   - 全局列表；筛选类型、原作品；列：类型、名称、原作品、删除时间、删除前父级、操作。
   - 整本删除的作品显示为一条作品项；整组删除的体系类别显示为一条类别项；其下实体不单独列出。
4. 恢复：
   - 校验名称冲突、父级存在、引用完整。
   - 名称冲突 → Dialog 内显示冲突对象 + 可编辑新名称 → 恢复。
   - 整组类别/整本作品 → 整组原子恢复；子项重名时逐项改名并一次性提交 `renames[]`；取消则整体不恢复。
   - 父级已删 → 阻止 + 「请先恢复上级势力/地点」；引用缺失 → 阻止 + 「请先恢复引用实体」。
   - 成功 → Toast；回到原父级位置。
5. 永久删除：确认 Dialog + 自动快照；成功不可恢复。
6. 清空回收站：确认 Dialog 显示数量 + 自动快照；成功不可恢复。
7. 快照失败 → 阻止永久删除/清空，Alert 说明。
8. 删除时被回收站引用 → 引用对话框/错误详情显示「回收站中」徽标 +「查看回收站」链接（`/trash?type=<type>&highlight=<id>`）；恢复该记录并解除引用后再删除。
9. 取消 → 不执行；已提交的删除不因取消而撤销。

**对应**：FR-57~FR-63；US-011；AC-13、AC-14、AC-15。

### UF-13 导出、快照与 CLI 恢复

**导出**

1. PG-13 点击「导出全量数据」→ Dialog：
   - Checkbox「包含回收站数据」（默认勾选）
   - 说明「导出包包含全部作品、图片、关系、体系、榜单、大事记；快照文件本身不包含。」
   - 主操作「生成导出包」
2. 生成中：Progress + 阶段（收集数据 → 打包图片 → 生成清单）；禁止重复点击。
3. 成功：卡片显示文件名、大小、生成时间；提供「下载 zip」与「文件路径（可复制）」。
4. 失败：Alert 说明原因（磁盘不足/权限/中断）+ 重试；不提供残缺 zip。
5. 取消：关闭对话框；不生成。

**快照**

1. PG-13 快照列表：时间、大小、路径、来源动作、状态；保留最近 3 份；自动触发矩阵按 FR-55（恢复、导入、删除作品、清空回收站），永久删除按 FR-58。
2. 快照可恢复（CLI `restore-snapshot`）；不提供页面手动快照/页面上传恢复。
3. 快照不可下载/手动创建（Should，不在基线）。

**CLI 恢复**

1. 数据恢复：`docker compose run --rm cli restore <zip>`；快照恢复：`docker compose run --rm cli restore-snapshot <dir>`。
2. 用户按页面命令在终端执行；系统校验版本/完整性 → 自动快照 → 全量覆盖。
3. 失败：不覆盖现有数据；保留快照；外部条件修复后可重试，zip/快照损坏或版本不兼容不可重试。
4. 恢复后 Smoke Test：启动、切换作品、检索、详情、图片。
5. 本版不做页面内恢复入口。

**对应**：FR-52~FR-56；US-010；AC-12、AC-22。

### UF-14 未保存修改与并发冲突

- 触发：人物/势力/地点详情内联编辑、体系节点编辑、导入向导进行中。
- 离开动作：侧栏跳转、切换作品、返回列表、打开其他实体、关闭 Drawer。
- 拦截：Dialog「放弃未保存的修改？」→「放弃并离开」/「继续编辑」。
- 选择放弃 → 恢复原值；选择继续 → 留在当前编辑。
- 并发：保存/删除时实体 `version` 与请求头 `If-Match` 不一致 → Dialog「数据已被其他页面修改，请刷新后重试」；页面只提示版本冲突，不展示内部字段；不自动合并；保留用户输入；刷新后需重新编辑。
- 本版无自动保存、无草稿恢复。

**对应**：FR-67、EX-07、EX-08；US-012；AC-15、AC-16。

### UF-15 网络中断与服务不可达

- 任一请求失败且服务不可达：
  - 页面顶部 Alert：「无法连接本地服务，请确认 Docker 容器正在运行」+「重试」。
  - 列表/详情显示错误状态；保留用户输入与未保存编辑。
  - 不进入离线模式；不显示英文堆栈/内部 ID。
- 服务恢复 → 点击重试 → 重新请求；成功后 Alert 消失。
- 删除/保存等写操作失败 → 明确说明未写入；不产生重复记录。

**对应**：EX-03、EX-06；US-012；AC-15、AC-29。

### UF-16 页面/实体不存在

- 无效 URL、已删除实体、跨作品 ID、`?id=` 为空或非法 → 页面级空状态「内容不存在或已删除」+「返回检索」/「返回列表」。
- 不显示堆栈、内部 ID、数据库错误。
- 回收站中的实体不参与关系跳转；关系链接不会指向回收站数据。

**对应**：EX-26；US-012；AC-15。

## 4. 关键任务步骤

| 任务 | 步骤 | 主要交互 | 成功结果 | 失败/取消 |
|---|---|---|---|---|
| 查人物 | 3 步 | 输入关键词 → 结果 → 详情 | 看到主名称、别名/称号、境界、势力、榜单、图片；可继续跳转 | 无结果提示；失败重试；取消清空 |
| 改一处同步 | 3 步 | 详情「编辑」→ 改字段 → 保存 | 人物页、势力页、榜单页、检索结果同步 | 字段错误/并发冲突；取消确认放弃 |
| 新建作品 | 3 步 | 新建 → 填名称/简介 → 保存 | 自动创建境界；进入体系页 | 重名/空名/快照失败 |
| 维护榜单 | 4 步 | 新建榜单 → 打开详情 → 指派/调整 → 保存 | 席位与人物详情名次同步 | 同榜重复/越界/缩尾有人 |
| 导入迁移 | 5 步 | 上传 → 校验预览 → 确认 → 报告 → 校对 | 原子写入新作品；报告留存；待校对清单 | 错误清单阻止确认；原子回滚 |
| 备份恢复 | 3 步 | 导出 → 空环境 `docker compose run --rm cli restore` → Smoke Test | 数据/关系/图片一致；快照存在；可用 `restore-snapshot` 恢复快照 | 快照/校验失败不覆盖；损坏/版本不兼容不可重试 |
| 删除恢复 | 2 步 | 删除 → 回收站恢复 | 撤销/恢复原位置 | 被引用阻止；冲突改名/先恢复父级 |

**核心路径约束**：查询与新建均不超过三步；导入为五步向导（需求明确）；不把确认、筛选、跳转拆成额外页面。

## 7. 可访问性要求

- 键盘可完成：检索、打开详情、编辑保存、删除确认、切换作品、恢复/永久删除。
- 跳至内容链接；焦点环 2px 可见；对话框焦点陷阱与关闭后焦点恢复。
- 表单标签与错误关联；表格表头 `scope`；图标按钮 `aria-label`；当前导航 `aria-current="page"`。
- Toast `aria-live`；错误 `aria-live="assertive"`；待校对/状态不只靠颜色。
- 对比度：正文 ≥4.5:1；主按钮白字/深绿 ≥6:1；焦点环清晰。
- `prefers-reduced-motion` 关闭 shimmer/滑入/位移。
- 目标为「基本可读、可键盘完成主流程」，不承诺正式 WCAG 认证。
