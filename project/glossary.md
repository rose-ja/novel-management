# Glossary — 术语表

> 阶段：P2 需求基线（模板对齐版）
> 说明：术语以 `requirements.md` v1.1 为准；未确认术语不得自行新增。

| 术语 | 定义 | 不应混淆的概念 | 首次确认来源 |
|---|---|---|---|
| 作品（Work） | 一本小说的独立世界观，是数据与检索的边界 | 不是「文档」「章节」；不是跨作品共享空间 | `requirements.md` FR-03、6.1 |
| 人物（Character） | 角色档案，含主名称、别名、称号、体系引用、势力、主图、简介、大事记 | 不等于「势力成员」列表项；成员由人物归属推导 | `requirements.md` FR-04、6.2 |
| 主名称 | 实体的权威标识，由用户显式指定；同一作品同类型内唯一 | 不是别名/称号；不是系统自动推断的名称 | `requirements.md` FR-04、6.2 |
| 别名 | 人物的其他名称，可多值、可重复；是一等检索入口 | 不等于称号；不存放在备注或简介里 | `requirements.md` FR-04、6.2 |
| 称号 | 人物的称号/尊号，可多值、可重复；是一等检索入口 | 不等于别名；可与别名重叠 | `requirements.md` FR-04、6.2 |
| 势力（Faction） | 种族/势力/分支的单棵树节点；父级可空、深度不限 | 不区分「族/分支」节点类型；不是体系类别 | `requirements.md` FR-09、6.3 |
| 首领 | 势力节点上的 0..1 人物引用 | 不是「成员」；成员由人物归属自动推导 | `requirements.md` FR-10 |
| 地点（Location） | 星域/星城/秘境等树节点；类型为自由文本 | 不是势力；本版不做地点图片 | `requirements.md` FR-13、FR-16 |
| 榜单（Ranking） | 排行榜，数量不限、名称同作品唯一；席位 1–200（默认 100） | 不是自动排名/战力计算；不是体系 | `requirements.md` FR-17、6.3 |
| 席位（Ranking Seat） | 榜单中的一个名次，席位号即名次；可空；同榜一人一席 | 不是「并列」；备注可写「并列」但不单独建模 | `requirements.md` FR-18 |
| 体系（System） | 每作品一套的设定类别与层级集合 | 不是「境界」的同义词；境界只是内置类别 | `requirements.md` FR-21、6.1 |
| 体系类别（System Category） | 每作品自定义的类别，如境界、星命、圣体；≤10 类（含境界）；类型普通/纪元 | 不是固定写死的四类；名称由数据配置驱动 | `requirements.md` FR-21、D-04 |
| 境界 | 内置体系类别，名称固定、必开、不可停用/删除；人物境界可空 | 不是所有体系类别的统称；其他类别可自定义 | `requirements.md` FR-21、FR-05 |
| 体系节点（System Node） | 类别下的层级节点；每类最多两级；同级可排序 | 不是势力节点；不是地点节点 | `requirements.md` FR-22、6.3 |
| 纪元 | 体系类别的一种类型；节点=名称+可选起止年份文本，只排序、不做日期计算 | 不是时间线可视化；不是全局事件库 | `requirements.md` FR-22、6.3 |
| 大事记（Chronicle） | 人物/势力的手工时间线条目：文本 + 可选时间标签 + 排序号 | 不是全局事件库；地点不做大事记 | `requirements.md` FR-04、FR-11、D-13 |
| 引用 | 通过实体 ID/关系表达，不复制文本；改名后自动同步 | 不是文本复制；不是手工超链接 | `requirements.md` FR-34、constitution 第 2 章 |
| 悬空引用 | 指向已删除或不存在实体的引用 | 不是「弱关联」；正常入口不允许制造 | `requirements.md` FR-37、FR-49 |
| 双向跳转 | 详情页展示入向与出向关系，两个方向都可点击到达 | 不是图谱；不是可视化大屏 | `requirements.md` FR-35 |
| 检索 | 当前作品内的关键词/条件查询；空格分词 AND；返回条目、摘要与出处 | 不是自然语言问答；不是 AI 生成；不做语义/同义词/拼音/错字容忍 | `requirements.md` FR-27~FR-33 |
| 快速搜索 | 单输入框检索，300ms 自动或回车立即执行 | 不等于条件检索 | `requirements.md` 5.2.2 |
| 条件检索 | 关键词 + 实体类型、势力、境界、地点、榜单等筛选，AND 组合 | 不是高级搜索语法；筛选只对相应实体类型生效 | `requirements.md` FR-32 |
| 待校对 | 导入成功后实体的初始状态；人工确认后取消 | 不是「未保存」；不是「草稿」 | `requirements.md` FR-44 |
| 回收站 | 软删除实体的全局列表；可撤销、恢复、永久删除、清空 | 不是审计日志；不是版本历史 | `requirements.md` FR-57~FR-63 |
| 软删除 | 通过删除标记隐藏实体，数据仍在回收站 | 不是物理删除；不参与检索与关系跳转 | `requirements.md` FR-57、6.1 |
| 快照 | 破坏性操作前自动生成的本地备份文件；保留最近 3 份 | 不是导出包；不是任意时点回滚 | `requirements.md` FR-55、6.1 |
| 导出包 | 产品内生成的全量 zip，含数据、图片、可选回收站 | 不是快照；不是增量备份 | `requirements.md` FR-52、6.8 |
| 恢复 | CLI 脚本用导出包全量覆盖当前数据；恢复前自动快照 | 不是撤销；不是合并导入 | `requirements.md` FR-54 |
| 导入向导 | 产品内迁移流程：上传→校验→预览→确认→原子写入→报告→校对 | 不是任意飞书排版解析器；不是增量 upsert | `requirements.md` FR-39~FR-45 |
| 固定模板 | 迁移唯一接受的 Markdown 模板，含版本、区块与字段行 | 不是飞书原始排版；不承诺兼容任意文档 | `requirements.md` FR-39、6.6 |
| 原子导入 | 任一错误整批不写入；失败不留下半成品作品 | 不是部分成功；不是逐条跳过错误 | `requirements.md` FR-42 |
| 导入报告 | 迁移结果留存：文件名、作品、实体/图片数量、错误数、耗时、时间 | 不是校对清单；不是快照 | `requirements.md` FR-45、8.8 |
| MVP | 首版必须交付并作为验收阻断的范围 | 不是 V1/V2 候选；不是 Should/Could | `mvp-scope.md`、`requirements.md` 第 9 章 |
| 验收人 | 项目发起人本人；按需求逐项确认并签收 | 不是开发 Agent；不是自动测试 | `requirements.md` 第 10 章、`product-brief.md` |
| 非目标 | 本版明确不做的事项，是硬边界 | 不是「以后可能做」的愿望清单 | `product-brief.md`、`requirements.md` 9.4 |
