- 域状态：`planned`（P6，2026-11-07）
- 目标行为：统一页面壳层与状态语义，保证数据完整性、并发安全、可访问性与本地部署可验证。
- 关联页面：PG-00~PG-13；关联验收：AC-15、AC-27~AC-32。

## SPEC-PLAT-001 应用壳层、导航与页面框架

- 状态：`planned`
- 来源：FR-65；US-012；PG-00 全部；P-001 基线；AC-27
- 行为：
  - 顶栏：作品切换器、全局导航（人物/势力/地点/榜单/体系/检索/导入/回收站/设置备份）、设置入口；侧栏随页面类型；详情页返回。
  - 路由固定：`/characters`、`/factions`、`/locations`、`/rankings`、`/system`、`/search`、`/trash`、`/settings`；详情统一查询参数；产品默认入口为 `/search`。
  - 1280 设计、≥1024 可用；窄屏降级不破坏信息层级。
  - 作品切换后导航状态保持、数据重新加载；无作品时进入引导空状态。
  - 统一空态、加载态、错误态、404 与无权限不适用（单用户）。
- 边界：
  - 不做暗色主题、移动端专属布局、多语言。
  - 不做登录/账号/权限。
- 验收场景：
  1. Given 有作品，When 打开任意主页面，Then 顶栏、导航、当前作品与内容区完整，无布局跳动（E2E-12 / AC-27）。
  2. Given 无作品，When 进入应用，Then 显示创建作品引导，不出现空白页（PG-00）。
  3. Given 1024 宽，When 打开详情，Then 导航可折叠、内容不横向溢出（AC-28）。
  4. Given 访问未知路由，When 加载，Then 显示 404 与返回首页（PG-00）。
- 变更历史：2026-11-07 — P6 新建，状态 `planned`。

## SPEC-PLAT-002 全局异常状态与反馈

- 状态：`planned`
- 来源：EX-01~EX-06、EX-26、EX-27；US-012；PG-00 §6、各页 §6；AC-28
- 行为：
  - 统一文案：加载失败「加载失败，请重试」、保存失败「保存失败，请稍后重试」、网络异常「网络异常，请检查连接」。
  - 加载中 Skeleton（列表/详情/树），不显示无限 spinner；长任务显示进度与可离开提示。
  - 空结果区分「无数据」与「筛选无结果」；错误保留用户输入与筛选条件；无结果不编造内容。
  - Toast 非阻塞，错误可重试；表单错误定位字段，不整页报错。
  - 前端不展示堆栈/SQL/文件路径；后端返回统一 `code/message/details`。
  - 权限不足（EX-05）本版无角色/登录，不实现权限提示，文档明确 N/A。
- 边界：
  - 不做离线模式、不做全局错误上报到云端。
  - 不做自动重试无限循环（最多 1 次手动）。
- 验收场景：
  1. Given 列表请求 500，When 打开页面，Then 显示中文错误与重试，不显示堆栈（EX-03 / AC-28）。
  2. Given 保存失败，When 提交表单，Then 输入保留、错误定位字段、可再次提交（EX-02）。
  3. Given 筛选无结果，When 应用筛选，Then 显示「无匹配结果」与清除条件（EX-01）。
  4. Given 长导入进行中，When 离开页面，Then 提示任务继续并可回到进度页（EX-10）。
- 变更历史：2026-11-07 — P6 新建，状态 `planned`。

## SPEC-PLAT-003 并发控制与未保存保护

- 状态：`planned`
- 来源：EX-07、EX-08、EX-28；US-012；PG-00 §6、PG-03 §6；API `version` + `If-Match`；AC-16
- 行为：
  - 所有可变实体返回 `version`；更新/删除携带 `If-Match`；缺失返回 428/400，版本不符返回 409 `VERSION_CONFLICT`。
  - 前端不自动合并、不覆盖；提示「数据已被其他页面修改，请刷新后重试」。
  - 未保存离开统一守卫：返回、切换作品、打开其他实体、刷新/关闭浏览器。
  - 保存按钮提交期间禁用，防重复提交；撤销/删除也做幂等。
- 边界：
  - 不做自动保存、协作编辑、冲突字段级 diff。
  - 不做多用户锁。
  - 崩溃/断电不提供草稿恢复（EX-28）；已保存数据不受影响，重启后可继续。
- 验收场景：
  1. Given 两标签页编辑同一人物，When 后保存者提交，Then 409 提示，先保存者数据不被覆盖（E2E-12 / AC-16）。
  2. Given 未保存表单，When 切换作品，Then 弹出放弃确认，取消则保留输入（EX-08）。
  3. Given 删除请求重放，When 第二次提交，Then 幂等，不重复删除/不报错堆栈（EX-04）。
  4. Given 保存中重复点击，When 第一次完成，Then 只产生一次更新（EX-04）。
- 变更历史：2026-11-07 — P6 新建，状态 `planned`。

## SPEC-PLAT-004 设计系统、视觉与可访问性基线

- 状态：`planned`
- 来源：FR-64、FR-66、FR-67、FR-68、FR-69；US-012；design-system v1.0；PG-00~PG-13；AC-27、AC-28
- 行为：
  - 设计令牌（色彩/字体/间距/圆角/阴影/动效）统一实现，禁止页面硬编码品牌色；视觉方向为浅绿色渐变、简洁中文、桌面优先。
  - 组件基线：Button、IconButton、Input、FormField、Select、Dialog、Drawer、Toast、Badge、Skeleton、EmptyState、Table、Pagination、FilterBar、Tree、Card、Progress（`design-system.md` 本版不使用 Tabs；F1 裁决以 IconButton 替代。Tree 随 CHG-003 体系配置交付）。
  - 状态完备：default/hover/active/focus/disabled/loading/error/empty；键盘可达、焦点可见；不使用占位符、无意义假数据或空按钮。
  - 对比度 ≥4.5:1（正文）、≥3:1（大字号/图形）；图标有文本替代；动效尊重 `prefers-reduced-motion`。
  - 视觉回归基线覆盖主流程页面。
- 边界：
  - 不做主题定制、品牌换肤、动画库引入。
  - 不做移动端专属组件。
- 验收场景：
  1. Given 主流程 13 页，When axe 扫描，Then 无 serious/critical 问题（AC-28 / V-03）。
  2. Given 键盘操作，When Tab 遍历表单/对话框，Then 焦点顺序正确、Esc 关闭、焦点返回触发元素（AC-28）。
  3. Given 文本与背景，When 检查对比度，Then 正文 ≥4.5:1（AC-27）。
  4. Given loading/error/empty，When 页面切换状态，Then 均有明确视觉与文案，不出现裸白屏（AC-28）。
- 变更历史：2026-11-07 — P6 新建，状态 `planned`。

## SPEC-PLAT-005 本地部署、安全边界与性能基线

- 状态：`planned`
- 来源：MVP-12、NFR 安全/性能；US-012；PG-13；deployment；AC-23、AC-24、AC-26、AC-29、AC-30、AC-32、AC-33、EX-21
- 行为：
  - `docker compose up -d` 一键启动 app/db/cache；固定访问 `http://127.0.0.1:17860`；容器内监听 `0.0.0.0:17860`，compose 仅将宿主端口绑定到 `127.0.0.1`，默认不暴露公网。
  - 唯一性统一由服务端校验：作品全局唯一；同作品实体、体系类别、体系节点同父唯一；英文不区分大小写，冲突返回冲突对象。
  - 安全：参数化查询、输出转义、CSP `frame-ancestors 'none'`、上传 MIME+魔数校验、导入 zip 路径穿越防护、静态文件仅 media。
  - 性能：首屏可交互 ≤2s（1000 人物基线）；列表 P95 ≤500ms；检索 P95 ≤150ms；关系查询 ≤300ms；缩略图懒加载。
  - 健康检查 `/health` 返回依赖状态；迁移由 app 启动或 CLI 统一执行。
  - 公网访问仅预留扩展点，不在本版实现。
- 边界：
  - 不做 HTTPS/反向代理/登录/多租户；不做云部署。
  - 不做性能超过 1000 人物的承诺。
- 验收场景：
  1. Given 全新机器，When `docker compose up -d`，Then 3 服务健康，浏览器可访问固定地址（AC-29）。
  2. Given 1000 人物基线，When 首次打开人物页，Then 可交互 ≤2s，缩略图不阻塞（AC-32 / AC-33）。
  3. Given 恶意 zip 路径或伪造图片，When 上传，Then 拒绝且不写出数据目录（AC-30）。
  4. Given 1000 人物，When 列表与检索压测，Then P95 分别 ≤500ms / ≤150ms（AC-23/24）。
- 变更历史：2026-11-07 — P6 新建，状态 `planned`。
