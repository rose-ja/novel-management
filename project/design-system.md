## 1. 产品视觉定位

### 1.1 产品气质

- 关键词：**清透、沉静、克制、可靠、专注、微暖纸感**。
- 气质描述：像一张整理得当的创作者工作台，而不是数据大屏或写作软件。界面退后，设定内容与关系向前。
- 情绪目标：打开即能查、看到即相信、改一处即同步；不制造「功能很多」的压迫感。

### 1.2 设计原则

| 原则 | 落地规则 |
|---|---|
| 信息优先 | 页面首屏必须出现名称、关键属性与关系；装饰不得挤占内容宽度 |
| 检索先行 | 检索是默认首页；搜索框是页面第一焦点；结果必须可解释、可跳转 |
| 关系可读 | 关系用分组、标签与链接表达；入向/出向关系都可点击，不藏进二级菜单 |
| 克制装饰 | 不使用大面积插画、玻璃拟态、渐变文字、装饰性动画与无意义图表 |
| 一致可预期 | 同类实体使用同一套列表、详情、编辑、删除与状态模式 |
| 边界清晰 | 作品、回收站、危险操作、快照与导入原子性在界面上明确可见 |

### 1.3 明确避免的视觉方向

- SaaS 紫/蓝渐变、发光按钮、玻璃卡片、重阴影与大圆角堆叠。
- 仪表盘式 KPI 大屏、无意义图表、装饰性关系图谱。
- Emoji 作为图标、彩色贴纸风、手账纹理铺满页面。
- 深色优先、霓虹科技风、游戏化战力面板。
- 大面积 Hero、营销式留白、需要滚动才能开始检索的布局。
- 任何会让「检索 → 详情 → 关系跳转」路径变长的视觉结构。

### 1.4 视觉密度与层级

- **密度：中高**。正文 14px / 行高 22px；表格行高 44px（紧凑 40px）；页面区块间距 24–32px。
- **层级**：页面标题（24/32）→ 区块标题（18/26）→ 实体名（15–20）→ 正文 / 表格（13–14）→ 辅助信息（12–13）。
- **主次操作**：每个视图最多 1 个主按钮（实心深绿）；次操作使用描边或幽灵按钮；危险操作使用红色文字按钮，并与常规操作在位置或菜单上分离。
- **品牌识别**：几何「山脊/册页」符号 + 浅绿雾状渐变 + 细雾线分隔；不依赖摄影、插画或复杂 Logo。

### 1.5 品牌资产结论

| 项目 | 结论 |
|---|---|
| Logo | 无现成资产。本阶段生成一个自定义几何标记（见 3.9），可后续替换 |
| 品牌色 | 无现成规范。采用本文件深松绿 + 浅绿渐变 |
| 字体 | 系统字体；不内置 Web Font |
| 图标 | 开源线性图标风格（Lucide，MIT）；以内联 SVG 使用，不引入图标字体 |
| 插画 / 摄影 | 不使用装饰性插画或图库照片；人物主图是用户数据，不作为品牌素材 |
| 参考截图 | 未使用；参考产品仅用于信息架构与交互模式，不复制视觉资产 |

### 3.8 Layout / Breakpoints

| Token | Value | 行为 |
|---|---|---|
| `--breakpoint-md` | 768px | 不作专门适配；仅保证不崩溃 |
| `--breakpoint-lg` | 1024px | **最低保证**；侧栏 208px，页面横向 20px，双栏详情改为单栏 |
| `--breakpoint-xl` | 1280px | 主设计宽度；侧栏 232px，页面横向 24px |
| `--breakpoint-2xl` | 1600px | 内容最大 1200px 居中，侧栏 232px |
| `--grid-columns` | 12 | 主内容栅格 |
| `--grid-gutter` | 24px | 列间距 |
| `--grid-margin` | 32px | ≥1440 页面边距 |

**布局规则**：

- `1280px+`：顶栏 64px + 侧栏 232px + 主内容（最大 1200px）。
- `1024–1279px`：侧栏 208px，页面横向 20px；详情主栏/侧栏改为上下排列；表格允许横向滚动。
- `<1024px`：不做专门适配；布局保持最小 1024px 宽度并允许横向滚动，同时显示一条非阻断提示：「本系统按桌面端设计，建议使用 1024px 以上窗口」。不新增移动端导航、底部操作栏或手势交互。
- 主内容区独立滚动；顶栏与侧栏固定。
- 表格最小宽度：人物/势力/地点列表 960px；榜单席位表 880px；回收站 1040px。

### 3.9 Iconography / Imagery / Logo

**图标**

- 风格：线性、1.5px 描边、圆角端点、24×24 网格；默认 20px，紧凑 16px，大 24px。
- 来源：Lucide（MIT/ISC）；实现时按需内联 SVG，不引入图标字体。若打包使用，需在应用内保留许可证声明。
- 图标只辅助识别，不替代文字；图标按钮必须有 `aria-label` 与 Tooltip。
- 不使用 Emoji、彩色渐变图标、拟物图标。

**Logo（自产）**

- 形态：24×24 圆角方形，深松绿渐变底；内部三条递进横线组成「山脊/册页行」；无文字。
- 使用：顶栏 28px、登录/空状态 40px、favicon 16/32px；不得拉伸、旋转、加投影。
- 文字标：产品全名「小说设定管理系统」，14px / 600；不缩写、不改成「山岚」作为产品名。
- 资产：`project/design-assets/logo-mark.svg`（自产，项目所有）。

**图片**

- 仅人物主图（用户数据）；比例 1:1；详情 88–120px，列表缩略图 40px；圆角 8px。
- 缺失时使用「雾绿渐变 + 姓名首字」占位，不显示破图图标；占位不是图库图片。
- 列表缩略图必须懒加载，不阻塞文字渲染。
- 不使用装饰性插画、库存照片、AI 生成人物图作为品牌素材。

### 3.10 Motion

| Token | Value | 用途 |
|---|---|---|
| `--motion-fast` | 120ms | hover、颜色、边框 |
| `--motion-base` | 180ms | 下拉、Tooltip、标签 |
| `--motion-slow` | 220ms | 对话框、抽屉 |
| `--motion-toast` | 300ms | Toast 进入 |
| `--ease-out` | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 默认缓动 |
| `--ease-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | 展开/收起 |

**规则**：

- 动效只用于状态反馈与空间关系，不做装饰性循环动画。
- 骨架屏 shimmer 1.4s；长任务使用进度条 + 阶段文字，不用无限旋转大图。
- `prefers-reduced-motion: reduce` 时：所有过渡 0.01ms，关闭骨架 shimmer（改为静态浅块），关闭 Toast 滑入与抽屉位移。
- 焦点环不使用动画。

### 3.11 Z-index

| Token | Value | 用途 |
|---|---:|---|
| `--z-base` | 0 | 页面内容 |
| `--z-sticky` | 10 | 表头、页内工具栏 |
| `--z-header` | 20 | 顶栏、侧栏 |
| `--z-dropdown` | 30 | 下拉、菜单、Tooltip |
| `--z-drawer` | 40 | 抽屉 |
| `--z-dialog` | 50 | 对话框 |
| `--z-toast` | 60 | Toast |

### 4.2 顶栏

- 高度 64px；固定；底部 1px `--color-border-subtle` + 2px 雾线渐变。
- 左侧：Logo 28px + 产品全名 14px/600。
- 中部偏左：作品切换器（36px 高，最大 320px，超出省略）。
- 右侧：本机状态胶囊「本机 · 127.0.0.1」——只表达本地私密运行，不是可点击入口；无设置/帮助/通知等额外入口。
- 顶栏不使用大标题、Hero 或彩色背景。

### 4.3 侧栏

- 宽度 232px（1024–1279 为 208px）；固定；背景 `--color-bg-subtle`，右侧 1px 描边。
- 导航分两组：
  - 资料：检索、人物、势力、地点、榜单、体系。
  - 工具：导入、回收站、设置/备份。
- 导航项 40px 高，图标 18px + 文字 14px；选中项：浅绿底 + 左侧 3px 主色指示条 + 深绿文字。
- 不展开二级菜单；详情页通过页面内面包屑与返回链接导航。
- 底部显示版本号与「数据仅存本机」小字；不显示调试入口。

### 4.4 页面框架

- 页面横向内边距：≥1440 为 32px；1280–1439 为 24px；1024–1279 为 20px。
- 页头：面包屑（详情页）+ 标题 24px + 一句说明 + 右侧操作；页头下 24px 间距，细雾线可选。
- 列表页：筛选栏（48px）+ 表格 + 分页；筛选栏与表格之间 16px。
- 详情页：主栏 760px + 侧栏 320px，间距 32px；1024–1279 改为上下排列。
- 表单页/向导：最大 960px；左侧主流程 + 右侧摘要（导入向导）。

### 4.5 响应式行为

| 宽度 | 顶栏 | 侧栏 | 页面 | 表格 | 详情 |

| <1024 | 64px，完整 | 保持 208px，不折叠为移动导航 | 最小 1024，横向滚动 | 横向滚动 | 上下排列 |

- 小于 1024px 显示非阻断提示条，不隐藏核心功能、不新增移动手势。
- 图片缩略图在所有宽度下懒加载；不因窄屏改为大图。

| 内边距 | 横向 12px；带图标时左 36px |
| 字体 | 14px / 22px |
| 标签 | 始终外置；12px/500；必填加「必填」文字或红色星号 + 说明 |
| Placeholder | 只给示例，不替代标签；颜色 `--color-text-tertiary` |

| 禁用 | 底色 `--color-surface-sunken`，文字 disabled；不可只用透明度 |

| 可搜索 | 选项 >8 时显示搜索框；搜索大小写不敏感；中文子串匹配 |
| 树选择 | 势力/地点父级、体系节点使用；显示缩进与展开箭头；禁止选择自身/后代；选中后显示完整路径 |
| 多选 | 筛选项使用 chip；下拉内显示勾选；清除全部 |

| 错误 | 触发按钮边框 danger + 字段错误文字 |
| 禁用 | 不显示下拉；仍显示当前值（如有） |

### 5.5 Checkbox / Radio

- 16×16；点击区至少 32×32；标签可点击。
- Checkbox 用于「包含回收站数据」「批量确认」；Radio 用于体系类别类型「普通 / 纪元」。
- 不使用 Switch 控件启停类别：停用必须先查引用，必须走按钮 + 确认对话框。

### 5.6 Dialog

| 类型 | 宽度 | 用途 | 关键规则 |
|---|---:|---|---|
| Confirm | 400px | 删除、清空、恢复、移出 | 标题 + 后果说明 + 主/次按钮；危险操作主按钮 danger |
| Form | 560px | 新建作品、新建榜单、新增类别、扩容/缩容 | 字段校验；提交后按钮 loading |
| Reference | 720px | 删除/停用被引用对象 | 按类型分组列出引用，链接可跳转；无删除按钮 |
| Conflict | 560px | 恢复名称冲突、并发编辑冲突 | 允许改名或刷新；不自动合并 |

- 遮罩 `--color-overlay`；对话框 `--radius-lg`、`--shadow-lg`；最大高 80vh，内容区滚动，头/脚固定。
- 焦点进入第一个可交互元素或标题；Tab 循环；Esc 关闭（提交中与不可中断操作除外）；关闭后焦点回到触发处。
- 破坏性确认标题必须说明动作与对象，例如「删除人物「司空摘天」？」；正文说明「将进入回收站，可在 8 秒内撤销」。
- 主按钮文案使用具体动词，不写「确定」。
- 提交中禁用关闭与重复提交；失败保留输入并显示错误。

### 5.7 Drawer

- 右侧，480px（复杂表单 560px）；顶部 64px 固定，底部操作栏固定，内容滚动。
- 用于**新建人物**（PG-02）与快速查看引用；榜单/体系的新建使用 Dialog，势力/地点的创建与编辑使用页内内联表单（FR-09 / FR-13）。
- 详情页编辑使用页内内联编辑，不打开独立编辑页。
- 打开时焦点进入第一个字段；Esc/遮罩关闭；有未保存修改时先确认。
- 抽屉不覆盖顶栏；移动端不改为全屏（本版不做移动端）。

### 5.8 Table

| 项目 | 规格 |
|---|---|
| 行高 | 默认 44px；紧凑 40px；表头 40px |
| 字号 | 13px / 20px；实体名可用 14px/500 |
| 表头 | 12px/500；`--color-bg-subtle`；`scope="col"`；可排序列显示方向箭头 |
| 边框 | 横向 1px `--color-border-subtle`；无竖线；无斑马纹 |
| hover | 整行 `--color-brand-50`；可点击行显示指针 |
| 选中 | 左侧 3px 主色条 + 浅绿底（仅批量/当前行） |
| 操作列 | 固定右侧；行内按钮 ≤3 个，其余进「更多」菜单 |
| 空状态 | 表体内显示 EmptyState，不留空白表头 |
| 加载 | 表头保留 + 6 行 Skeleton |
| 排序 | 名称/更新时间；席位表按席位号固定升序 |
| 分页 | 列表每页 20；榜单每页 50 席；显示总数 |
| 横向滚动 | 最小宽度不足时，表头与内容一起滚动；操作列可 sticky |
| 文本 | 名称列最多 2 行；别名/称号最多显示 3 个 chip + `+N`；超长省略并 Tooltip |

### 5.9 Pagination

- 32px 高按钮；上一页/下一页 + 页码 + 总数；当前页主色底。
- 不可用按钮 disabled，不隐藏。
- 列表固定每页 20；榜单固定每页 50 席；本版不提供每页条数切换（Should，未纳入基线）。
- 榜单额外提供「跳至席位」输入；输入越界时提示有效范围。

### 5.10 Badge / Tag

| 变体 | 样式 | 用途 |
|---|---|---|
| Neutral | 灰绿底/文字 | 类型、普通/纪元、内置 |
| Brand | 浅绿底/深绿文字 | 当前、已启用、主名称 |
| Warning | 浅黄底/棕文字 + 圆点 | **待校对** |
| Danger | 浅红底/红文字 | 被引用、删除中、错误 |
| Info | 浅蓝底/蓝文字 | 说明性状态 |

- 高度 20px（表格）/24px（详情）；12px 字；圆角 pill。
- 状态不能只靠颜色：必须同时有文字或图标。
- 「待校对」固定文案与颜色，全站一致；确认后立即消失。
- 数量标签使用 `tabular-nums`；不在标签里放操作按钮。

### 5.11 Toast

- 位置：底部居中，距底 24px；最大宽 480px；`--shadow-md`；`--z-toast`。
- 成功 4s；失败 6s；可撤销 8s；hover/focus 暂停计时。
- 撤销 Toast 同时最多 1 条；新的撤销替换旧的，旧操作仍可在回收站恢复。
- 结构：状态图标 + 一句话 + 可选操作（撤销/重试）+ 关闭。
- 文案示例：`已移入回收站` / `已保存` / `无法连接本地服务，请确认 Docker 容器正在运行`。
- `role="status"` / `aria-live="polite"`；错误使用 `aria-live="assertive"`。
- 不把字段级错误放进 Toast；字段错误必须贴近字段。

### 5.12 Skeleton

- 列表：表头 + 6 行，行高 44px；行内 3 个块（名称 40%、属性 24%、操作 16%）。
- 详情：标题块 240×24、元信息 3 块、图片 88×88、正文 4 行、侧栏 3 块。
- 图片：40×40 或 88×88 圆角块；不显示破图。
- 动画：`--gradient-skeleton` 1.4s；减少动态时静态浅块。
- 骨架屏不阻塞输入；搜索框与按钮保持可用。

### 5.13 EmptyState

- 结构：32px 线性图标 + 标题 16/24 600 + 说明 13/20 + 1 主 1 次操作。
- 页面级空状态上下留白 48px；表体内空状态 32px。
- 文案必须给下一步：`还没有人物` → `新建第一个人物` / `从固定模板导入`。
- 不显示空白表格、空白页或只有一句「暂无数据」。

### 5.14 Alert / Banner

- 四种语义色；左侧图标；标题可选；操作在右侧或下方。
- 用于：网络中断、待校对提示、快照失败/成功、导入错误摘要、回收站快照说明。
- 关键阻断信息不可关闭；一般提示可关闭，但刷新后重新出现。
- 不用于普通段落说明；不堆叠超过 2 条。

### 5.15 Menu / Popover

- 触发器：IconButton「更多」；菜单宽 160–200px；项高 32px；8px 圆角。
- 危险项红色文字并与常规项分隔；最后一项后加分隔线。
- 点击外部/Esc 关闭；焦点回到触发器；键盘 ↑↓ 选择。
- 行操作超过 3 个时必须收进菜单。

### 5.16 Tree

- 行高 36px；缩进 20px/层；展开按钮 24px；节点名 14px；右侧可显示引用数/状态。
- 默认展开两级（势力/地点）；体系树全部展开当前类别两级。
- 选中：浅绿底 + 左侧 3px 主色条；hover 浅绿。
- 搜索：匹配节点高亮，自动展开祖先；无匹配显示 EmptyState。
- 不支持拖拽排序；体系节点用「上移/下移」按钮；势力/地点换父级用编辑表单中的父级树选择。
- 键盘：Tab 可达每个节点与展开按钮；Enter 打开详情；空格切换展开。

### 5.17 Stepper

- 横向 5 步：上传 → 校验预览 → 确认导入 → 导入报告 → 校对清单。
- 状态：done（主色勾）/ active（主色数字 + 下划线）/ error（红色数字）/ disabled（灰）。
- 已完成步骤可点击返回；未完成/有错误的步骤不可前进；返回上传会清空后续状态并确认。
- 移动端不改为纵向（本版不做移动端）。

### 5.18 ImageUploader

- 详情头像 88px；新建表单 88px；列表缩略图 40px（只读）。
- 支持点击选择与拖拽；接受 jpg/jpeg/png/webp；≤10MB；1:1 预览。
- 上传中显示线性进度与百分比；失败显示原因 + 重试；不写入残缺图片。
- 已有图片：替换、移除；移除需确认；移除后显示姓名首字占位。
- 图片 `alt="人物主图：{主名称}"`；缩略图 `loading="lazy"`；不阻塞文字渲染。

### 5.19 SeatCell

- 已占：席位号（等宽数字）+ 40px 头像 + 人物名（链接）+ 势力/境界 + 备注 + 行操作。
- 空席：虚线底 + 「虚位以待」+ 「指派」按钮；不可删除空席。
- 行操作：移动到空席 / 与目标席位交换 / 移出榜单；三个动作走同一「调整席位」对话框，根据目标席位是否为空自动切换模式。
- 同一人物同榜第二席：阻止并提示「该人物已在第 N 席，请先移出或与目标席位交换」。
- 席位号固定升序；不做并列建模；备注可写「并列」。

### 5.20 ReferenceList

- 用于删除/停用/缩容阻断：按实体类型分组，显示数量与位置。
- 每条：类型标签 + 名称 + 关键属性（如势力、榜单席位号）+ 链接。
- 链接可跳转到引用实体；跳转前若当前有未保存修改，先确认。
- 没有引用时显示「无引用，可继续」；有引用时主操作禁用。
- 不显示内部 ID、堆栈或英文错误。

### 5.21 FilterBar

- 列表页：左侧搜索框 280px；右侧筛选 Select + 排序 Select + 「重置」；48px 高。
- 检索页条件模式：筛选面板（可折叠），字段两列；「检索」主按钮 + 「重置」次按钮。
- 活跃筛选以 chip 展示，可单独移除；chip 行在筛选栏下方。
- 筛选后显示结果数量；无结果时提供「清除筛选」。
- 1024–1279：筛选字段改为单列；不隐藏筛选。

### 5.22 SegmentedControl

- 高度 32px；2–3 项；选中项白底 + 主色文字 + 1px 描边；容器浅绿底。
- 用途：快速搜索 / 条件检索；仅直属 / 含下级成员。不用于多级导航或 Tab 内容。

### 5.23 Progress

- 线性进度条 4px 高；主色；轨道 `--color-brand-200`。
- 长任务显示阶段文字：解析 → 校验 → 写入 → 图片；每阶段有独立进度或状态。
- 未知进度使用不确定条，必须有文字说明；不伪装百分比。

### 5.24 Card / Surface

- 白底、1px 边框、12px 圆角、20–24px 内边距；默认无阴影。
- 用于详情侧栏摘要、导入摘要、快照项、作品切换项；不把每个区块都做成卡片。
- hover 只在可点击卡片使用：边框变强 + `--shadow-sm`。

### 5.25 PageHeader

- 标题 24/32 600；说明 13/20 secondary；面包屑 12/18；操作右对齐。
- 详情页标题可带「待校对」Badge；主操作「编辑」；次操作「更多」。
- 页头下边距 24px；可选雾线分隔，不加重阴影。
- 页面标题与当前作品名称必须同时可见（标题或副标题中显示作品名）。

### 5.26 Tooltip

- 12px 字；深色底（`#1B2A23`）白字；4px 圆角；最大宽 240px；`--z-dropdown`。
- hover 400ms 后显示；键盘 focus 立即显示；Esc 关闭。
- 只用于图标含义、截断文本、禁用原因；不承载必读说明。

## 6. 交互反馈

| 场景 | 行为 |
|---|---|
| Loading | 列表/详情用 Skeleton；按钮 loading；长任务用 Progress + 阶段文字；输入框保持可用 |
| Empty | 说明 + 下一步主操作 + 次操作（如导入）；不显示空白页 |
| Error | 中文原因 + 下一步 + 重试；保留输入与未保存编辑；不显示堆栈/内部 ID |
| Success | Toast「已保存」+ 数据刷新；停留当前页；不弹成功对话框 |
| Disabled | 控件禁用 + 可见原因（helper / Tooltip）；不隐藏原因 |
| Confirm | 破坏性操作一律二次确认；说明后果；主按钮具体动词 |
| Undo | 软删除后 toast 8s 可撤销；撤销立即恢复原位置；不依赖刷新 |
| Network | 顶部 Alert + 内容区错误：「无法连接本地服务，请确认 Docker 容器正在运行」+ 重试；无离线模式 |
| Conflict | Dialog：「数据已被其他页面修改，请刷新后重试」；不自动合并；保留用户输入 |
| Duplicate submit | 提交后按钮禁用 + loading；服务端唯一约束兜底 |
| Unsaved leave | Dialog：「放弃未保存的修改？」；放弃/继续编辑；切换作品同样拦截 |
| Delete referenced | Dialog 列出引用（ReferenceList）；主操作禁用；提供跳转 |
| Restore conflict | Dialog 内允许改名；父级缺失提示先恢复父级；引用缺失提示先恢复引用实体 |
| Snapshot failure | 阻止破坏性操作；Alert 说明原因 + 重试 |
| Import errors | 错误清单按行/字段定位；确认导入禁用；不创建半成品作品 |

**文案规则**：

- 中文、具体、可执行；不使用英文报错原文。
- 错误格式：`原因 + 下一步`，例如「人物主名称已存在，请换一个名称」。
- 危险确认：`动作 + 对象 + 后果`，例如「永久删除 12 项？此操作不可撤销，删除前会自动创建快照」。
- 空状态：`没有什么 + 可以做什么`，例如「还没有人物。新建第一个人物，或从固定模板导入。」

## 7. 表单与数据展示

### 7.1 表单布局

- 单列为主；姓名/别名/称号等短字段可两列；简介与大事记整行。
- 字段顺序：主名称 → 别名 → 称号 → 势力 → 体系类别（按启用顺序）→ 关联地点 → 主图 → 简介 → 大事记。
- 字段标签 12/18 500；必填标识；帮助文字 12/18 tertiary；错误文字 12/18 danger。
- 行间距 16px；分组间距 24px；分组标题 15/22 600 + 说明。
- 所有字段必须有标签；占位符不替代标签；只读字段用 `readonly` 样式。
- 保存按钮在表单底部/抽屉底部；取消在左侧；保存中禁用整组操作。
- 校验：失焦校验字段；提交时校验全部；首个错误滚动到可视区并聚焦；错误提示贴近字段。
- 未保存修改：路由离开、切换作品、关闭抽屉、打开其他实体前统一拦截。

### 7.2 列表与筛选

- 列表默认按更新时间倒序；人物可按名称/更新时间；榜单席位固定席位号升序。
- 每页 20；榜单每页 50 席；显示总数。
- 搜索框为当前列表内过滤，不进入全局检索；全局检索只在检索页。
- 筛选条件：人物=势力/分支、境界、待校对；势力/地点=待校对；回收站=类型、原作品。
- 排序控件只在支持多字段的列表出现；不提供每页条数切换（Should）。
- 筛选条件不记忆（Should 未纳入基线）；刷新后回到默认。

### 7.3 数据展示格式

| 类型 | 格式 | 示例 |
|---|---|---|
| 日期时间 | `YYYY-MM-DD HH:mm`，本地时区 | `2026-11-07 14:32` |
| 席位号 | 等宽数字，1..N，不补零 | `第 3 席` / `3` |
| 计数 | 千分位 | `1,024` |
| 文件大小 | 1 位小数 + 单位 | `12.4 MB` |
| 路径 | 等宽字体，可复制，中间省略 | `…/exports/novel-settings-20261107-1432.zip` |
| 版本 | `v` + 语义化版本或构建号 | `v1.0.0` |
| 待校对 | Badge「待校对」+ 圆点 | 表格/详情统一 |
| 空席 | 「虚位以待」+ 指派按钮 | 不显示「无」 |
| 长文本 | 列表 2 行截断；详情全文；搜索摘要 72–90 字 | 保留换行 |

### 7.4 图片

- 列表 40×40，详情 88–120px；1:1；圆角 8px；`object-fit: cover`。
- 缩略图 `loading="lazy"`；不阻塞文字；加载中显示浅色块，不显示破图。
- 缺失显示姓名首字 + 雾绿渐变占位；占位不是外部图片。
- 上传失败不写入；替换/移除需确认。

## 8. 无障碍要求

- **键盘**：Tab 顺序为「跳至内容 → 顶栏 → 侧栏 → 页面主操作 → 内容 → 分页」；所有交互元素可键盘到达；Enter/Space 触发按钮；Esc 关闭浮层。
- **跳至内容**：顶栏提供 Skip Link，聚焦后显示；目标 `main` 可聚焦。
- **焦点**：所有可交互元素使用 2px 可见焦点环；不使用 `outline: none` 无替代；对话框焦点陷阱与恢复。
- **对比度**：正文与背景 ≥4.5:1；大字号 ≥3:1；关键状态不仅靠颜色。推荐组合：主文字 `#1B2A23` on `#FFFFFF`（约 14:1）、主按钮白字 on `#256B4E`（约 6.4:1）、次级文字 `#4B6055` on `#FFFFFF`（约 7:1）。
- **屏幕阅读器**：表单标签 `for/id`；错误 `aria-describedby`；对话框 `role="dialog" aria-modal="true"` + 标题；Toast `aria-live`；表格 `scope`；图标按钮 `aria-label`；当前导航 `aria-current="page"`；待校对用文字而非仅颜色。
- **图片**：人物主图 `alt="人物主图：{主名称}"`；装饰性图标 `aria-hidden="true"`。
- **减少动态**：遵循 `prefers-reduced-motion`；关闭 shimmer、滑入、位移。
- **缩放**：200% 文本缩放不截断关键内容；不使用固定高度锁死文本；表格允许横向滚动。
- **不承诺**正式 WCAG 认证；目标是中文桌面场景下「可读、可键盘完成主流程、焦点可见」。

## 10. 视觉验收基线

### 10.1 全局检查

- [ ] 颜色、字体、间距、圆角、阴影全部引用 Token，无页面级任意色值。

- [ ] 浅绿渐变只出现在背景/Logo/抽屉头/骨架屏，不用于正文或大面积按钮。
- [ ] 中文文案完整；无占位文本、调试入口、未完成按钮、英文堆栈。

| 检查项 | 通过标准 |
|---|---|
