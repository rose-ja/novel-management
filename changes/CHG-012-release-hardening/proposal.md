# CHG-012 关系一致性、异常状态与发布验收

## 1. 背景

CHG-001~CHG-011 已交付全部业务能力。发布前仍需跨页收口：回收站引用的可定位性、表单未保存守卫覆盖、全页状态与可访问性、键盘主流程、1000 人物性能基线、安全与发布演练。

## 2. 目标

1. 跨回收站引用可阻断、可标注、可一键定位并解除（SPEC-TRASH-004，E2E-15）。
2. 全部可编辑表单具备统一未保存守卫（SPEC-PLAT-003）。
3. 13 个主页面 + 详情页具备 loading/empty/error 状态；409/428 文案统一（SPEC-PLAT-002）。
4. axe 全页无 serious/critical；键盘可完成新建/编辑/删除/恢复主流程（SPEC-PLAT-004，E2E-14）。
5. 1000 人物基线：首屏可交互 ≤2s、列表 P95 ≤500ms、检索 P95 ≤150ms（AC-23/24/32）。
6. CSP、上传魔数、zip 路径穿越复测；导出/恢复、快照、迁移回滚演练可复现（AC-29/30）。

## 3. 范围

- 前端：回收站深链与高亮、引用对话框链接、未保存守卫、a11y/键盘/状态修正、E2E 用例。
- 后端：仅测试工具（`cli seed`）与必要的引用/状态校验修正；无表结构变更。
- 文档：README 发布步骤复核、验收/发布记录、Spec/roadmap 回写。

## 4. 非目标

- 不新增业务功能、页面或字段。
- 不做性能优化超出基线（只定位明显回退）。
- 不做登录、权限、HTTPS、公网部署。
- 不引入 k6 依赖；性能使用 CLI seeder + HTTP 采样 + Playwright。

## 5. 验收标准

| # | 标准 | 证据 |
|---|---|---|
| 1 | 删除被回收站榜单席位引用的人物时，引用对话框标注「回收站」并可跳转 `/trash?type=ranking&highlight=<id>`，目标行高亮；恢复榜单→撤席→删除成功 | E2E-15 |
| 2 | 势力/地点/体系/人物/榜单/作品编辑表单在脏状态下关闭或站内跳转均弹出统一确认 | E2E + 代码审计 |
| 3 | 主列表/详情/检索/回收站/设置均有 loading/empty/error；接口失败显示中文并可重试；不泄露堆栈 | E2E-12 扩展 |
| 4 | axe 扫描列表与详情（有数据）及对话框无 serious/critical | `a11y.spec.ts` |
| 5 | 纯键盘完成人物新建、编辑、删除、回收站恢复 | `keyboard.spec.ts` |
| 6 | 1000 人物下首屏 ≤2s、列表 P95 ≤500ms、检索 P95 ≤150ms | `scripts/perf.ps1` 报告 |
| 7 | CSP 生效下检索/详情可用且无控制台 violation；恶意 zip/图片被拒 | E2E-13 + 集成 |
| 8 | 导出→CLI 恢复→计数一致；迁移 Up/Down 通过；快照可创建/恢复 | 发布演练记录 |

## 6. 风险与回滚

- 风险：深链参数与静态导出兼容、全页 axe 暴露大量样式问题、性能基线受本机负载影响。
- 回滚：按任务粒度回退提交；无数据库结构变更；性能脚本与 seeder 可删除。
