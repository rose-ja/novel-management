## 4. 已知遗留（不阻断验收，需知悉）

1. 列表行菜单、sticky 操作列、1024 隐藏别名列、表头排序与筛选 chips 未实现（审查 C-04，UI-05 未勾选）。
2. 版本冲突使用顶部 Alert 而非独立 ConflictDialog（C-03）；字段级错误未定位到字段（C-08）。
3. 删除入口未改为行菜单，删除成功不自动返回列表（C-06）；撤销 Toast 无倒计时（C-07）。
4. 停用类别在编辑态未灰显/清除（C-09）；回收站人物根父名查询未做批量优化（C-12）。
5. 势力/地点/榜单、主图、校对确认分别由 CHG-005～008、CHG-011 承接。
6. 本机 Docker BuildKit 构建与宿主端口转发偶发失败，属环境问题，已在 `verification.md` §6 记录。
