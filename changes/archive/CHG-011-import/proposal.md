# Change Proposal

- ID: CHG-011-import
- Title: 飞书《正文》迁移导入与校对
- Status: Approved（2026-11-15，按实施计划批准）
- Owner: 主 Agent
- Related Spec: SPEC-MIG-001、SPEC-MIG-002、SPEC-MIG-003、SPEC-MIG-004、SPEC-MIG-005
- Related Issue: roadmap §CHG-011；FR-39~FR-46、FR-51；US-009、US-012；PG-11；AC-10、AC-11、AC-18~AC-21、AC-25、AC-31；EX-10~EX-13、EX-22

## Problem / Opportunity

CHG-003~009 已交付体系、人物、势力、地点、榜单与检索，但《正文》仍只能手工录入；SPEC-MIG-001~005 全部为 `planned`，AC-10/11/18~21/25 无法验收。用户需要一次性把飞书导出的固定模板与图片迁移为可用的新作品，并能逐条校对迁移结果。

## User Value

- 上传固定模板 Markdown 与图片 zip，系统解析、校验、预览并提供可定位到行/字段/图片的错误清单。
- 有错误禁止确认；确认后自动快照、原子写入新作品，失败 0 残留。
- 导入图片按 Markdown 相对文件名匹配并生成人物主图。
- 导入报告记录八类计数、图片匹配、耗时与快照；导入后自动切换到新作品。
- 可校对实体标记「待校对」，支持逐条与批量确认，确认后列表/详情 Badge 消失。

## Goal

交付迁移导入垂直切片：迁移 `0011_import_runs`；`internal/imports` 模板/解析/校验/图片匹配；导入服务（上传、后台校验、快照、原子提交、报告、中断清理）；review 单条/批量接口；PG-11 五步向导与设置页入口；单测、集成、E2E-09、视觉与 a11y；文档回写。

## In Scope

- 上传 Markdown（≤20MB）与可选图片 zip（≤6GB）；磁盘预检；120 分钟超时；同一时间仅一个导入。
- 模板 v1.0（作品信息、体系类别、体系节点、势力、地点、人物、榜单、大事记）。
- 校验：模板版本、未知区块/字段、必填、长度、同作品唯一、引用、体系类别/两级、图片缺失/多余/格式/单图超 10MB。
- 预览计数（含体系类别）、错误清单、图片匹配；二次确认 Dialog；阶段进度；失败中文提示。
- 提交前 `Snapshot.Create(reason=import)`；图片落盘 `images/{work_id}/`；单事务写入；检索重建；自动切换当前作品；重复 commit 幂等。
- 导入报告页面与接口；校对清单（5 类）、单条/批量确认、查看详情。
- 迁移、模型、仓储、HTTP、前端页面、集成/E2E/视觉/a11y、Spec/契约/数据模型/roadmap 回写。

## Out of Scope

- 导入《设定集》；飞书原始表格解析；手工字段映射；多包合并；tar。
- 增量导入、重复导入去重、覆盖已有作品。
- 自动校对、校对内容修改、独立校对页面。
- 导入历史清理、报告文件导出（Should，不纳入基线）。
- 运行时依赖飞书或双向同步。

## Acceptance Criteria

1. 合法 Markdown + zip 上传后创建导入记录并进入校验；预览显示人物/势力/地点/榜单/体系类别/体系节点/大事记/图片计数与图片匹配。
2. 非 `.md`/非 zip、zip >6GB、单图 >10MB、磁盘不足、120 分钟超时均有明确中文错误且不写入业务数据。
3. 模板版本不符、未知区块/字段、缺必填、重名、坏引用、类别/节点非法、图片缺失/多余/格式不支持均进入错误清单并禁止确认。
4. 确认导入前自动快照；快照失败阻止导入。
5. 校验通过后原子写入八类实体、关系、图片与检索；成功后自动切换当前作品；报告计数与预览一致。
6. 提交失败（含进程中断）无半成品作品/实体/图片；重复 commit 返回同一结果。
7. 导入实体 `review_status=pending`，列表/详情显示待校对；单条确认与批量确认仅作用 pending，确认后写 `reviewed/reviewed_at/reviewed_by` 并刷新检索。
8. 批量确认已 confirmed 计 skipped，不存在 ID 整批失败。
9. PG-11 五步步骤条、错误清单、右侧摘要、确认 Dialog、报告、校对分组与空状态完整；1024 宽不横向溢出。
10. axe 无 serious/critical；Stepper `aria-current`、进度 `progressbar`、结果 `aria-live`、键盘可选择文件。
11. 全量门禁、集成、前端单测、Docker 构建、Playwright 通过并记录。

## Constraints and Assumptions

- 技术栈不变：Go + Gin + GORM + PostgreSQL 16 + goose；Next.js 静态导出；不新增第三方依赖。
- 上传形态按 api-contract/PG-11：Markdown 与图片 zip 两个 multipart 部分；不接受单 zip 内嵌 Markdown。
- 提交同步执行并返回 `completed + report`（api-contract §3.11）；前端显示不确定进度。
- 模板 v1.0 由本变更定义并内置下载；示例 zip 由服务端生成。
- 校对范围仅人物、势力、地点、榜单、体系节点；类别、大事记、图片不参与校对。
- 用户 2026-11-15 确认：多余图片阻断导入；导入成功后自动切换当前作品。

## Dependencies

- CHG-003~CHG-009（实体、关系、检索、媒体）。
- CHG-002/CHG-010（快照基座与快照记录）。

## Risks

| 风险 | 影响 | 缓解 |
|---|---|---|
| 6GB 流式上传与解析内存 | OOM/超时 | 流式落盘、分块读取、`ReadZipFile` 限额、120 分钟超时 |
| 单事务大批量写入 | 长事务/锁等待 | 批量插入、固定顺序、单作品隔离；1000 人物性能验证 |
| 图片移入后事务失败 | 残留图片 | 记录本次目录，失败删除；集成覆盖 |
| 模板歧义 | 错误定位困难 | 固定模板 + 行号/字段错误 + 示例下载 |
| 进程重启 | 半成品任务 | 启动 `MarkInterrupted`；快照回退 |
| 多余图片阻断误伤 | 用户需重传 | 错误清单列出文件名；文档说明 |
